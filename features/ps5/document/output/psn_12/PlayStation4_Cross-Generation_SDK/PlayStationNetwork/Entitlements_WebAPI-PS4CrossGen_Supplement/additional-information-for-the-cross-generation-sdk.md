# Additional Information for the Cross-Generation SDK

The PlayStation®4 Cross-Generation SDK ("Cross-Gen SDK") is an SDK for making some of the SDK features provided for PlayStation®5 usable on PlayStation®4 Applications.

There are no differences in function between the Cross-Gen SDK and the function described in the [Entitlements Overview](../../../WebAPI/latest/Entitlements-Overview/__document_toc.html). There is no need for additional information in this document.

Refer to the [Entitlements Overview](../../../WebAPI/latest/Entitlements-Overview/__document_toc.html) for details.

For more information about the Cross-Gen SDK as a whole, refer to the [Cross-Generation Overview](../Cross_Generation-Overview/__document_toc.html).

Note:

The PlayStation®5 SDK is a provisional version and may be frequently updated. Make sure to check the SDK documents and release notes whenever the PlayStation®5 SDK is updated. Also note that there may be additions or changes to the restrictions and notes given such updates.
