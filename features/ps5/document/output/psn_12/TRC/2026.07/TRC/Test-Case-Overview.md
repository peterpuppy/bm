Test Case Overview

This Test Case document is a supplement to the TRC; it describes methods to check each TRC item and provides supplementary information.

Preparation for executing test cases

Check the test cases on a Testing Kit and select the following settings. These should remain set as shown at all times during testing unless stated otherwise.

On the home screen, set "★Debug Settings" > "System" > "TRC Check Notifications" to "Enable"
On the home screen, set "★Debug Settings" > "Boot Parameters" > "Release Check Mode" to "Release Mode"
On the home screen, set "★Debug Settings" > "Game" > "Slow SSD Mode" to "On"
TRC Check Notifications

TRC Check Notifications is provided as a feature indicating whether applications conform to the TRC requirements or not. For the texts and the explanation, please refer to the TRC Check Notifications List document.

Features of the ★Debug Settings Menu
TRC Check Notifications

This feature is for enabling or disabling TRC Check Notifications.

Number to Display

This feature is for changing the number of TRC Check Notifications displayed on the screen at a time.

Transparency

This feature is for setting the transparency of the background of TRC Check Notifications.

Test Case Items

Test cases consist of the following items:

General Notes (information that relates to several test cases)
Common procedures
Test case code (see below)
Expected results
Procedures
Notes (information relating to the specific test case)

Each test case is assigned a code consisting of the TRC number and a letter suffix for example R0000A. If several test cases exist, each test case is assigned a different letter, such as R0000A, R0000B, R0000C.
