# Transactions

# listTransactions

Get a users consumption transactions for an entitlement

### Description

Get a user's consumption transactions for an entitlement in reverse chronological order. SIE reserves the right to retain transactions for only two years.

**Examples:**

**Example 1: Get a list of an account's consumption transactions for the entitlement and service label:**

```
curl -X GET 'https://s2s.playstation.net/api/entitlement/v2/users/{accountId}/entitlements/{entitlementLabel}/transactions?serviceLabel={serviceLabel}' -H 'Authorization: Bearer {Bearer}'
```

**Response:**

```
{
    "previous": "e12aac33-467e-3962-804a-bdcd6d4a37e1",
    "transactions": [
        {
            "transactionId": "2019-05-10:008",
            "date": "2019-07-01T18:37:23Z",
            "operation": "CONSUME",
            "count": 1,
            "useCount": 23,
            "useLimit": 387
        },
        {
            "transactionId": "2019-06-12:003",
            "date": "2019-06-12T23:08:12Z",
            "operation": "CONSUME",
            "count": 1,
            "useCount": 22,
            "useLimit": 388
        }
    ]
}
```

### Use Restrictions

| Client | Usable / Not Usable |
| --- | --- |
| Application for PlayStation®4 | Not Usable |
| Application for PlayStation®5 | Not Usable |
| Back office server | Usable |
| Application server | Not Usable |
| Application server (client credential) | Not Usable |
| Authorized App Server | Not Usable |

### Request

```
GET /v2/users/{accountId}/entitlements/{entitlementLabel}/transactions
```

### URI Parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| accountId | **string** | true | The account ID. |
| entitlementLabel | **string** | true | The entitlement label. |

### Query Parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| limit | **integer(int32)** | false | Specify max number of results to return.  **Min Value:** 1  **Default Value:** 100 |
| before | **string** | false | Specifies the end pointer when retrieving the previous page. |
| serviceLabel | **string** | false | The NP service label.  **Default Value:** 0 |

### Responses

| Status | Meaning | Description |
| --- | --- | --- |
| 200 | [OK](https://tools.ietf.org/html/rfc7231#section-6.3.1) | A paged array of consumption transactions for a user's entitlement in reverse chronological order. |
| 400 | [Bad Request](https://tools.ietf.org/html/rfc7231#section-6.5.1) | Error. |
| 404 | [Not Found](https://tools.ietf.org/html/rfc7231#section-6.5.4) | Error. |
| 429 | [Too Many Requests](https://tools.ietf.org/html/rfc6585#section-4) | Rate limit was exceeded. |
| 500 | [Internal Server Error](https://tools.ietf.org/html/rfc7231#section-6.6.1) | Error. |
| default | Default | Error. |

### Status Code 200

### Response Body

**Content-Type:** application/json

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| » previous | **string** | false | Pointer to the first element on this page, if it exists. Pass this as the "before" attribute in the next call. |
| » transactions | **array[any]** | false | Array holding transaction information. |
| »» transactionId | **string** | false | An ID that is unique to this user and entitlement. For CONSUME operation this is generated by the licensee. For REVOKE and GRANT it is generated by SIE.  **Min Length:** 4  **Max Length:** 64 |
| »» date | **string(date-time)** | true | The date for the object. |
| »» operation | **string** | true | Operation type.  **Possible Values:**  - GRANT  - CONSUME  - REVOKE |
| »» count | **integer(int32)** | true | Count of units added or consumed in current transaction. |
| »» useCount | **integer(int32)** | true | Total units consumed for this entitlement up to and including this consumption transaction. |
| »» useLimit | **integer(int32)** | true | Total units remaining to be consumed for this entitlement after this transaction was processed. |

# getTransaction

Get details for a users single consumption transaction

### Description

Gets the transaction details for a user's single consumption transaction specified by the transactionId in the path.

**Examples:**

**Example 1: Get the details for an existing consumption transaction that consumed 1 use of an entitlement:**

```
curl -X GET 'https://s2s.playstation.net/api/entitlement/v2/users/{accountId}/entitlements/{entitlementLabel}/transactions/{transactionId}?serviceLabel={serviceLabel}' -H 'Authorization: Bearer {Bearer}'
```
