# listEntitlements

Get all entitlements for a user

### Description

Gets a list of entitlements for a user filtered based on the query parameters passed in.

**Examples:**

**Example 1: Get a list of service entitlements for a user:**

```
curl -X GET 'https://s2s.playstation.net/api/entitlement/v2/users/me/entitlements?entitlementTypes=service&serviceLabel=1' -H "Content-type:application/json" -H "Authorization:Bearer {Bearer}"
```

**Response:**

```
{
    "nextOffset": null,
    "previousOffset": null,
    "entitlements": [
        {
            "id": "USABLE",
            "activeDate": "2019-02-08T16:50:18Z",
            "inactiveDate": null,
            "entitlementType": "SERVICE",
            "useCount": 12,
            "useLimit": 8,
            "packageType": null,
            "activeFlag": true
        }
    ]
}
```

**Example 2: Get a list of service and unified entitlements for a user:**

```
curl -X GET 'https://s2s.playstation.net/api/entitlement/v2/users/me/entitlements?entitlementTypes=service,unified&serviceLabel=1' -H "Content-type:application/json" -H "Authorization:Bearer {Bearer}"
```

**Response:**

```
{
    "nextOffset": null,
    "previousOffset": null,
    "entitlements": [
        {
            "id": "PSVIRTUALCURRENC",
            "activeDate": "2019-02-08T16:50:15Z",
            "inactiveDate": null,
            "entitlementType": "UNIFIED",
            "useCount": 0,
            "useLimit": 20,
            "packageType": "PSVC",
            "activeFlag": true
        },
        {
            "id": "USABLE",
            "activeDate": "2019-02-08T16:50:18Z",
            "inactiveDate": null,
            "entitlementType": "SERVICE",
            "useCount": 12,
            "useLimit": 8,
            "packageType": null,
            "activeFlag": true
        }
    ]
}
```

# consumeEntitlement

Consume units of a users entitlement

### Description

Consume unit(s) of an entitlement for a user. This method is idempotent. Multiple invocations for the same user, entitlement label and transaction ID will only consume the given amount of units once. After the first successful transaction, subsequent calls with the same entitlement label, use amount, and transaction ID will not consume additional uses of the entitlement and instead return details for the original transaction.

**Examples:**

**Example 1: Consume one unit of an user's entitlement for the provided transactionId:**

```
curl -X PUT 'https://s2s.playstation.net/api/entitlement/v2/users/me/entitlements/{entitlementLabel}?serviceLabel={serviceLabel}' -H 'Authorization: Bearer {Bearer}' -H 'Content-Type: application/json'  -H 'cache-control: no-cache' -H 'clTh: 93905372-1231-2242-1513-352642753344' -d '{ "useCount": 1, "transactionId": {transactionId} }'
```

**Response:**

```
{
    "useLimit": 387,
    "amountConsumed": 1
}
```
