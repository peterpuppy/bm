# Event Feedback

# postEventFeedback

Sends event action data to SIE

### Description

As part of your onboarding, SIE ensures that you have set up the Feedback Reporting Loop, which lets you report the success or failure for each event type (chargebacks, refunds, and chargeback reversals).

The Feedback Reporting Loop keeps track of events you have successfully acted on (revoked or reinstated), as well as events that you were not able to act on, along with status codes depending on the action taken.

You are required to send your feedback event data request to SIE on a daily basis. If you cannot adhere to this advised cadence, inform your SIE onboarding team so both parties can agree on an acceptable cadence.

Each attribute in a request must contain exact values as received for the event in [getStreamEventsV2](0003.html).

**Example: Report of a refund event**

```
curl -X POST 'https://s2s.sp-int.playstation.net/api/partnerEventService/v1/partner-events/PARTNER178046/feedback' -H "Authorization: Bearer {access_token}" -H "PartnerName:PARTNER178046"
```

**Request:**

```
{
       "account":"1244394171740630000",
       "publisherAccountId":"c23273d9fa96460aa4a576f09b5fa3f1",
       "publisherItemId" :"MTX03K",
       "paymentProductSKU":"THAO12-MUSC11111_CM-MUSIC10000000000-EBUB",
       "sourceOrderItemId":"115924118403",
       "eventType":"REFUND",
       "purchaseDate": "2020-11-11 10:15:27.777000",
       "id" : "ad77a4c4-538f-4f79-94eb-e0c6fe0bafaa",
       "status" : "ACCOUNT_NOT_FOUND",
       "errorMessage":""
}
```

**Description of 'status' values in Request**

| Status | Description |
| --- | --- |
| SUCCESS | The partner has successfully taken action on a Chargeback, Refund, or Chargeback Reversal. |
| ACCOUNT\_NOT\_FOUND | The partner was unable to identify the PSN account within their system. |
| TRANSACTION\_NOT\_FOUND | The partner was able to identify the PSN account, but was unable to match the transaction within their system. |
| CLAWBACK\_NOT\_FOUND | The partner was unable to locate the impacted items or currency to take action within their system. |
| SUBSCRIPTION\_NOT\_FOUND | The partner was able to identify the PSN account, but was unable to match the subscription transaction within their system. |
| CLAWBACK\_ALREADY\_UNDO | The partner was unable to take action due to repeat information already actioned in the past. |
| INVALID\_TYPE | The partner was unable to take action due to the impacted items or currency being invalid or ineligible. |
| OTHER\_ERROR | OTHER\_ERROR (No other fields are applicable; insert errorMessage string) |

**Note:** Only send the value for errorMessage when status is set to OTHER\_ERROR. In all the other cases, errorMessage is ignored.

The context listed in this table is to advise our partners to use the following errorMessage String text in the left column when addressing the Use Cases listed in the right column. This is to fill the gap in situations that are not covered within our current postEventFeedback response statuses when filling out the errorMessage string within the OTHER\_ERROR postEventFeedback response status.

| errorMessage String | Use Cases |
| --- | --- |
| Revoking Limitation | Use this value to indicate you could not revoke an item(s) or VC due to the limitations within your revoking process. For example, if a chargeback or refund event is for a game bundle that includes a VC amount, you cannot revoke within the bundle due to the limitation of the revoking process. |
| Missing entitlementId or Client Transaction ID | Use this value to indicate you could not revoke an item(s) or VC as the entitlement or Client transaction ID was not provided. |
| Server Error | Use this value to indicate you were not able to address the CM-API event because of a Server Error. |

**Response:**

```
{
  "status":"SUCCESS"
}
```

### Request

```
POST /v1/partner-events/{partnerName}/feedback
```

### URI Parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| partnerName | **string** | true | SIE creates your Partner Name and provides it to you during the onboarding process. The Partner Name should not include any spaces. |

### Header Parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| Authorization | **string** | true | A valid OAuth JWT token generated using SIE OAuth Service. When requesting the OAuth token please ensure you are passing in the parameter "token\_format=jwt" |
| PartnerName | **string** | true | SIE creates your Partner Name and provides it to you during the onboarding process. |

### Request Body

**Content-Type:** application/json

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| » id | **string** | true | An event's unique identifier. |
| » publisherAccountId | **string** | false | The publisher account ID. |
| » publisherItemId | **string** | false | The publisher item ID. |
| » paymentProductSKU | **string** | true | The PSN SKU of the product. |
| » sourceOrderItemId | **string** | true | A PSN Order Item ID. |
| » account | **string** | true | A PSN Account ID. |
| » purchaseDate | **string** | true | The date of the original purchase. |
| » eventType | **string** | true | The transaction type of the event.  **Possible Values:**  - CHARGEBACK  - REFUND  - CHARGEBACK REVERSAL |
| » status | **string** | true | The status of an event.  **Possible Values:**  - SUCCESS  - ACCOUNT\_NOT\_FOUND  - TRANSACTION\_NOT\_FOUND  - CLAWBACK\_NOT\_FOUND  - SUBSCRIPTION\_NOT\_FOUND  - CLAWBACK\_ALREADY\_UNDO  - INVALID\_TYPE  - OTHER\_ERROR |
| » errorMessage | **string** | false | An error message. |
