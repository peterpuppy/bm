# Subscription Status

# getSubscriptionStatus

Returns the status of a PlayStation®Plus subscription for an account for PlayStation™Network

### Description

Returns the status of a PlayStation™Network user's PlayStation®Plus subscription. Successful requests return an HTTP 200 status code and a subscription status object. If you do not have the required scope for this endpoint, the request returns an HTTP 403 Forbidden error.

**Tier Label**

tierLabel refers to the tier label for the specified subscription, if the subscription is active.

The possible values are:

* TIER\_10: Refers to PlayStation®Plus Essential
* TIER\_20: Refers to PlayStation®Plus Extra
* TIER\_30: Refers to PlayStation®Plus Premium (PlayStation®Plus Deluxe in regions that don't offer cloud streaming)

**Example Request**

```
GET {subscriptionsBaseUrl}/v1/accounts/me/subscriptions/PS_PLUS
```

**Example Response (active PlayStation®Plus subscription)**

```
HTTP 200
{
  "isActive" : true,
  "tierLabel" : "TIER_20"
}
```

**Example Response (inactive or non-existent PlayStation®Plus subscription)**

```
HTTP 200
{
  "isActive" : false
}
```

### Request

```
GET /v1/accounts/me/subscriptions/{membershipType}
```

### URI Parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| membershipType | **string** | true | Membership type of the PlayStation®Plus subscription.  **Possible Values**:  - PS\_PLUS  **Min Length:** 1  **Max Length:** 25 |

### Status Code 200

### Response Body

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| » isActive | **boolean** | true | Returns true if the user's PlayStation®Plus subscription is active. |
| » tierLabel | **string** | false | The tier label for the matching subscription, if the subscription is active.  **Possible Values**:  - TIER\_10  - TIER\_20  - TIER\_30  **Min Length:** 1  **Max Length:** 200 |
