# Blocks

# GetBlockingUsers

Obtains the block list

### Description

This request obtains the block list. Only the block list of the current user can be obtained.

**Response Example**

```
{
  "blocks": [
    "1111",
    "2222",
    "3333",
    ...
  ],
  "totalItemCount": 50,
  "nextOffset": 20,
  "previousOffset": 10
}
```

### Use Restrictions

| Client | Usable / Not Usable |
| --- | --- |
| Application for PlayStation®4 | Usable |
| Application for PlayStation®5 | Usable |
| Back office server | Not Usable |
| Application server | Usable |
| Application server (client credential) | Not Usable |
| Authorized App Server | Usable |

### Request

```
GET /v1/users/me/blocks
```

### Query Parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| offset | **integer(int32)** | false | Relative position from start of list  **Min Value:** 0  **Default Value:** 0 |
| limit | **integer(int32)** | false | Maximum number of items with which to respond at once.  If 0 is specified, it is treated as though the parameter has not been specified, and the default value is applied.  **Min Value:** 0  **Max Value:** 2000  **Default Value:** 100 |

### Responses

| Status | Meaning | Description |
| --- | --- | --- |
| 200 | [OK](https://tools.ietf.org/html/rfc7231#section-6.3.1) | The block list was correctly returned |
| 400 | [Bad Request](https://tools.ietf.org/html/rfc7231#section-6.5.1) | Invalid request |
| 401 | [Unauthorized](https://tools.ietf.org/html/rfc7235#section-3.1) | Authentication error |
| 429 | [Too Many Requests](https://tools.ietf.org/html/rfc6585#section-4) | Frequency limit exceeded |
| 500 | [Internal Server Error](https://tools.ietf.org/html/rfc7231#section-6.6.1) | Internal server error |
| 503 | [Service Unavailable](https://tools.ietf.org/html/rfc7231#section-6.6.4) | Under maintenance, or the service has closed |

| » blocks | **array[string]** | true | Account IDs included in the block list |
| » nextOffset | **integer(int32)** | false | A value that represents the next page's starting position. This parameter does not exist for the last page.  **Min Value:** 0 |
| » previousOffset | **integer(int32)** | false | A value that represents the previous page's ending position. This parameter does not exist for the first page.  **Min Value:** 0 |

# GetBlockUsersStates

Obtains block relationships

### Description

This request obtains the block relationships (blocking or being blocked) between the current user and target users (multiple specification possible). The current user's access token is required for this request.

**Response Example**

```
{
  "blocks": [
    {
      "accountId": "1111",
      "isBlocking": false,
      "isBlocked": false
    },
    {
      "accountId": "2222",
      "isBlocking": true,
      "isBlocked": false
    },
    {
      "accountId": "3333",
      "isBlocking": false,
      "isBlocked": true
    }
  ]
}
```

### Use Restrictions

| Client | Usable / Not Usable |
| --- | --- |
| Application for PlayStation®4 | Not Usable |
| Application for PlayStation®5 | Not Usable |
| Back office server | Not Usable |
| Application server | Usable |
| Application server (client credential) | Not Usable |
| Authorized App Server | Usable |

### Request

```
GET /v1/users/{accountId}/blocks/states
```

### URI Parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| accountId | **string** | true | Account ID  **RegEx Pattern:** "^[1-9][0-9]{2,18}$" |

### Query Parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| accountIds | **string** | true | Account IDs of users targeted for obtaining resources.  If specifying multiple users, separate account IDs with commas but without inserting spaces.  The maximum number of account IDs that can be specified at once is 100 (based on restrictions on URL length).  400 Bad Request will be returned when over 100 account IDs are specified. |

### Responses

| Status | Meaning | Description |
| --- | --- | --- |
| 200 | [OK](https://tools.ietf.org/html/rfc7231#section-6.3.1) | Block relationships were correctly obtained |
| 400 | [Bad Request](https://tools.ietf.org/html/rfc7231#section-6.5.1) | Invalid request |
| 401 | [Unauthorized](https://tools.ietf.org/html/rfc7235#section-3.1) | Authentication error |
| 404 | [Not Found](https://tools.ietf.org/html/rfc7231#section-6.5.4) | Specified resource does not exist |
| 429 | [Too Many Requests](https://tools.ietf.org/html/rfc6585#section-4) | Frequency limit exceeded |
| 500 | [Internal Server Error](https://tools.ietf.org/html/rfc7231#section-6.6.1) | Internal server error |
| 503 | [Service Unavailable](https://tools.ietf.org/html/rfc7231#section-6.6.4) | Under maintenance, or the service has closed |

### Status Code 200

### Response Header

| Header | Type | Format | Description |
| --- | --- | --- | --- |
| X-Content-Type-Options | string |  | Avoid having the client execute operations that do not match the Content-Type in the response |

### Response Body

**Content-Type:** application/json

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| » blocks | **array[object]** | true | Block relationships |
| »» accountId | **string** | true | Account ID of the target user  **RegEx Pattern:** "^[1-9][0-9]{2,18}$" |
| »» isBlocking | **boolean** | true | Whether or not the current user is blocking the target user |
| »» isBlocked | **boolean** | true | Whether or not the current user is being blocked by the target user |
