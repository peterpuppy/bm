# User Profile Web API Reference – WebAPI 1

# Basic Profile

# GetPublicProfile

Obtains a user profile

### Description

This request obtains a user profile, that is, the user's avatar image, self-introduction message, and so forth.

If the current user is included in the target user's block list, fixed values, rather than the actual information, will be set for the parameters listed below and returned. (Other parameters are unaffected regardless of whether there is blocking.)

* *aboutMe*: Blank string

Additionally if the current user does not meet the the release conditions in the target user's real-name privacy settings, a *personalDetail* object will not be returned.

**Response Example**

```
{
  "onlineId": "spiderman",
  "aboutMe": "I'm playing 'Last of Us'. Please play with me!",
  "personalDetail": {
    "firstName": "play",
    "lastName": "station"
  },
  "avatars": [
    {
      "size": "xl",
      "url": "https://avatar-cdn/avatar-cdn-size-xl-path/avatar.png"
    },
    {
      "size": "l",
      "url": "https://avatar-cdn/avatar-cdn-size-l-path/avatar.png"
    },
    {
      "size": "m",
      "url": "https://avatar-cdn/avatar-cdn-size-m-path/avatar.png"
    },
    {
      "size": "s",
      "url": "https://avatar-cdn/avatar-cdn-size-s-path/avatar.png"
    }
  ],
  "languages": [
    "en-US",
    "ja-JP",
    "fr-FR"
  ],
  "isOfficiallyVerified": true
}
```

### Request

```
GET /v1/users/{accountId}/profiles
```

### URI Parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| accountId | **string** | true | Account ID  **RegEx Pattern:** "^[1-9][0-9]{2,18}$" |

### Query Parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| includeFields | **string** | false | Information that can be arbitrarily added to the profile information to be obtained.  If relation is specified, the relationship with the target user as seen from the current user will be returned.  When this parameter isn't specified, the returned response will exclude fields that can be specified with this parameter.  **Possible Values:**  - accountId  - relation |
| languageSet | **string** | false | Language set used in the response's languages (My Languages) field.  set1 will be used if this parameter is not specified or if a value other than those below is specified.  If a language in My Languages of the target user is not included in the language set being used, the language code for that language will be replaced by en-US and returned to languages. (If this replacement causes en-US to be obtained multiple times, they will be handled as one en-US.)  **Possible Values:**  - set1  - set2  The languages and their corresponding language codes for PlayStation™Network per language set are as follows.  **set1**  - Arabic: ar-AE  - Chinese (simplified): zh-Hans  - Chinese (traditional): zh-Hant  - Czech: cs-CZ  - Danish: da-DK  - Dutch: nl-NL  - English (United Kingdom): en-GB  - English (United States): en-US  - Finnish: fi-FI  - French (Canada): fr-CA  - French (France): fr-FR  - German: de-DE  - Greek: el-GR  - Hungarian: hu-HU  - Indonesian: id-ID  - Italian: it-IT  - Japanese: ja-JP  - Korean: ko-KR  - Norwegian: no-NO  - Polish: pl-PL  - Portuguese (Brazil): pt-BR  - Portuguese (Portugal): pt-PT  - Romanian: ro-RO  - Russian: ru-RU  - Spanish (Latin America): es-419  - Spanish (Spain): es-ES  - Swedish: sv-SE  - Thai: th-TH  - Turkish: tr-TR  - Vietnamese: vi-VN  **set2**  All languages included in set1 and the following language  - Ukrainian: uk-UA    **Default Value:** set1 |

# GetPublicProfiles

Obtain multiple user profiles

### Description

Multiple users' profiles can be obtained in one go.

**Response Example**

```
{
  "profiles": [
    {
      "onlineId": "spiderman",
      "aboutMe": "I'm playing 'Last of Us'. Please play with me!",
      "personalDetail": {
        "firstName": "play",
        "lastName": "station"
      },
      "avatars": [
        {
          "size": "xl",
          "url": "https://avatar-cdn/avatar-cdn-size-xl-path/avatar.png"
        },
        {
          "size": "l",
          "url": "https://avatar-cdn/avatar-cdn-size-l-path/avatar.png"
        },
        {
          "size": "m",
          "url": "https://avatar-cdn/avatar-cdn-size-m-path/avatar.png"
        },
        {
          "size": "s",
          "url": "https://avatar-cdn/avatar-cdn-size-s-path/avatar.png"
        }
      ],
      "languages": [
        "en-US",
        "ja-JP",
        "fr-FR"
      ],
      "isOfficiallyVerified": true
    }
  ]
}
```

When an account ID that doesn't exist is included in the request

* When includeFields=accountId is specified, only the accountId field will be returned as profile information of the applicable account.

```
{
  "profiles": [
    {"accountId": "99999999999"} // Account ID that doesn't exist
  ]
}
```

* An empty object will be returned as profile information of the applicable account if includeFields=accountId isn't specified.

```
{
  "profiles": [
    {} // Account ID that doesn't exist
  ]
}
```
