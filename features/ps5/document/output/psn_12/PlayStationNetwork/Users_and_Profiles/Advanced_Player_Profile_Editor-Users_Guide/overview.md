# Advanced Player Profile Editor User's Guide – SDK 12.000

Source: https://game.develop.playstation.net/resources/documents/SDK/12.000/Advanced_Player_Profile_Editor-Users_Guide/overview.html

# Overview

This guide is for those who develop or test online games on PlayStation™Network. This includes:

* Online game developers and network engineers.
* Online game planners and designers.
* QA and production staff managing configuration and testing of online games.

The Advanced Player Profile Editor is used to mock-up data for the Advanced Player Profile. The editor allows you to see the Advanced Player Profile in the context of a specific NP Communication ID for a given account and add fake data to it. The following account properties can be modified or mocked-up:

* Bandwidth
* Connection Quality
* Play
  Style (supported per game, genre, and franchise, as well as
  globally)
* Chat Mute Frequency
* NAT Connectivity
* Match
  Completion Rate (supported per game, genre, and franchise, as well as
  globally)

## Supported Browsers

The Advanced Player Profile Editor currently supports Chrome, Firefox, and Microsoft Edge browsers.
