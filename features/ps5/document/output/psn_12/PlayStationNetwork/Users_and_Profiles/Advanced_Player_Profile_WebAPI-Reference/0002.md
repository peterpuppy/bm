# Advanced Player Profile Web API Reference – WebAPI 1

Source: https://game.develop.playstation.net/resources/documents/WebAPI/1/Advanced_Player_Profile_WebAPI-Reference/0002.html

# Stats

# getStats

Get stats

### Description

This request retrieves the stats of the Advanced Player Profile sorted in ascending alphabetical order.

SIE deprecated the Multiplayer Matchmaking Ranking feature, as well as the mmr parameter and its children, perFranchise and perGenre.

* If fake data is registered, this request returns the fake data. This is only available for the development environment.
* If fake data is not set, the request returns real data, which is aggregated from system software libraries and PlayStation™Network Services.
* If the value of includeFields is set to empty, includeFields, or is not specified, this request returns an empty JSON response ({}).
* If there is no real data and the value of includeFields is set to bandwidth, frequentlyMuted, matchCompletionRate, natConnectivity, or playStyle, the request returns responses containing 0 values.
* If there is no real data and the value of includeFields is set to connectionQuality, the request returns most responses containing 0 values (only jitter value is 0.0).
* If the value of includeFields is set to reputation, regardless of what is stored, the request returns responses containing 0 value.
* If the value of includeFields is set to mmr, the request always returns a response with a value of -1.

**Examples:**

**Example 1: Get advanced player profile stats for a user:**

```
curl -H 'Authorization: Bearer ${Bearer}' 'https://s2s.{env}.playstation.net/api/advancedPlayerProfile/v1/users/me/stats?npServiceLabel=0&includeFields=bandwidth(global)'
```

**Response:**

```
{
 "bandwidth": {
  "global": {
   "downstream": {
    "average": 42,
    "confidenceScore": 75,
    "standardDeviation": 25
   },
   "upstream": {
    "average": 42,
    "confidenceScore": 75,
    "standardDeviation": 25
   }
  }
 }
}
```

**Example 2: Get advanced player profile stats for a user whose data does not exist:**

```
curl -H 'Authorization: Bearer ${Bearer}' 'https://s2s.{env}.playstation.net/api/advancedPlayerProfile/v1/users/me/stats?npServiceLabel=0&includeFields=bandwidth(global)'
```

**Response:**

```
{
 "bandwidth": {
  "global": {
   "downstream": {
    "average": 0,
    "confidenceScore": 0,
    "standardDeviation": 0
   },
   "upstream": {
    "average": 0,
    "confidenceScore": 0,
    "standardDeviation": 0
   }
  }
 }
}
```

```

```

### Query Parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| npServiceLabel | **integer** | true | NP service label. |
| includeFields | **string** | false | The available fields are:    • natConnectivity(global)  • bandwidth(global)  • matchCompletionRate(global)  • matchCompletionRate(perGame)  • matchCompletionRate(perGenre)  • matchCompletionRate(perFranchise)  • frequentlyMuted(global)  • playStyle(global)  • playStyle(perGame)  • playStyle(perGenre)  • playStyle(perFranchise)  • connectionQuality(global)  • mmr(perGenre)  • mmr(perFranchise)  • reputation(global)  • reputation(perGame)  • reputation(perFranchise)    For top-level fields that are the same, you can use comma separated values:    matchCompletionRate(global,perGame)    You can also use multiple fields in a comma separated list:    bandwidth(global),matchCompletionRate(global,perGame,perFranchise),frequentlyMuted(global) |
