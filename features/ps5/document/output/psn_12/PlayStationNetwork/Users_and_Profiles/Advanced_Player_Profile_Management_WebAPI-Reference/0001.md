# Advanced Player Profile Management Web API Reference Summary

Beginning Fall of 2026, support for the Advanced Player Profile Management Web API service will end.

The Advanced Player Profile Management Web API is one of the management features for back office servers. It provides the following abilities in the development environment:

* Register fake data (fake stats).
* Retrieve fake data.
* Delete fake data.

Use these features to test the Advanced Player Profile service.

**Call Rate Limits**

It is recommended that the call rates for the Advanced Player Profile Web API are kept within the following ranges. Note that there is a possibility of rate limits changing without notice. Use the following information as a reference only.

| Request | Recommended Call Rate |
| --- | --- |
| getFakeStats | Within 30 times/15 minutes |
| putFakeStats | Within 30 times/15 minutes |
| deleteFakeStats | Within 30 times/15 minutes |

### Base URLs

### Application for PlayStation®5

For PlayStation®5 applications, there is no need to explicitly construct a base URL. Obtaining an appropriate base URL is automatically processed by calling a PlayStation™Network Web API using either the NpWebApi2 library or the NpCppWebApi library.

### Application Servers or Back Office Servers

For application servers or back office servers, construct the base URL as follows.

* https://s2s.sp-int.playstation.net/api/advancedPlayerProfile (Development environment)
* https://s2s.np.playstation.net/api/advancedPlayerProfile (Production environment)
