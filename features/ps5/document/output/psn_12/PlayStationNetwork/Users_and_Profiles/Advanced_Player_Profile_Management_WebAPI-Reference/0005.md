# Error Codes

| Code (Decimal) | Code (Hex) | Message | Description |
| --- | --- | --- | --- |
| 2310145 | 234001 | Bad request ('reason') | Request is invalid (invalid path parameter value, invalid query string value, no required query string, too large body, etc. ) |
| 2310272 | 234080 | Bad request | Request is invalid and the reason is unknown. |
| 2310275 | 234083 | Forbidden | Details are unknown, but the request was rejected. |
| 2310276 | 234084 | Not Found | URL is invalid (specifying unsupported API version, etc.) |
| 2310656 | 234200 | Authentication required | Access token is not in the request. |
| 2310657 | 234201 | Invalid token | Access token is invalid or is corrupted. |
| 2310662 | 234206 | Insufficient scope | The scope of Access token is invalid (not approved, failed to get access token, specifying unavailable parameter). |
| 2311040 | 234380 | Internal server error | An unexpected error occurred in the server. |
| 2311043 | 234383 | Service Unavailable | Service is not available (under maintenance, server overloaded, service is closed, authentication/authorization server error, etc.) |
| 2310157 | 23400D | Resource not found ('reason') | Requested resource is not found (specified accounts or titles don't exist, client id of access token is wrong, etc. ) |
| 2310158 | 23400E | Not permitted by access control | Not permitted by access control (requester is not resource owner, access to another title's resource, not allowed by privacy settings, etc. ) |
| 2310301 | 23409D | Too Many Requests | API rate limit exceeded. |
| 2310670 | 23420E | Online ID required | Account needs to be upgraded. |
| 2310796 | 23428C | Expired token | Access token expired. |
| 2310797 | 23428D | Np Environment not matched | Np Environment is invalid. |
