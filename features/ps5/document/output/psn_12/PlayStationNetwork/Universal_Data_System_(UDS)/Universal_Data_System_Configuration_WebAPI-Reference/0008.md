# listEvents

List Events

### Description

Returns a list of all currently registered events for the specified NP Service Label.

**Examples**

**Example 1: Get all events**

```
curl -XGET 'https://s2s.sp-int.playstation.net/api/universalDataSystem/v1/events' -H "Content-type:application/json" -H "Authorization:Bearer {Bearer}"
```

**Response**

```
{
  "events": [
    {
      "eventName": "questStarted",
      "eventType": "activityStart",
      "status": "inDevelopment",
      "properties": [
        {
          "property": "$.questId",
          "dataType": "string",
          "mappedProperty": "activityId"
        },
        {
          "property": "$.customLevelId",
          "dataType": "string"
        }
      ]
    },
    {
      "eventName": "questFinished",
      "eventType": "activityEnd",
      "status": "inDevelopment",
      "properties": [
        {
          "property": "$.questId",
          "dataType": "string",
          "mappedProperty": "activityId"
        },
        {
          "property": "$.questStatus",
          "dataType": "string",
          "mappedProperty": "outcome"
        }
      ]
    }
  ],
  "totalItemCount": 2
}
```

# deleteEvents

Delete Events

### Description

Deletes multiple events in a single API call. While you can specify multiple eventTypes, you can only specify a single definitionGroup.

**Examples**

**Example 1: Delete events**

```
curl -XDELETE 'https://s2s.sp-int.playstation.net/api/universalDataSystem/v1/events?eventTypes=activityStart' -H "Content-type:application/json" -H "Authorization:Bearer {Bearer}"
```

**Response**

```
204 No Content
```

| --- | --- |

| Application server (client credential) | Not Usable |
| Authorized App Server | Not Usable |


# putEvents

Put Events

### Description

Creates all events specified in the request. If the event specified in the request already exists, the event will be updated and 204 No Content will be returned. If the event does not exist 201 Created will be returned.

**Examples**

**Example 1: Create or update events**

```
curl -XPUT 'https://s2s.sp-int.playstation.net/api/universalDataSystem/v1/events/_bulk' -H "Content-type:application/json" -H "Authorization:Bearer {Bearer}" -d '
{
  "events": [
    {
      "eventName": "questStarted",
      "eventType": "activityStart",
      "properties": [
        {
          "property": "$.questId",
          "dataType": "string",
          "mappedProperty": "activityId"
        },
        {
          "property": "$.customLevelId",
          "dataType": "string"
        }
      ]
    },
    {
      "eventName": "questFinished",
      "eventType": "activityEnd",
      "properties": [
        {
          "property": "$.questId",
          "dataType": "string",
          "mappedProperty": "activityId"
        },
        {
          "property": "$.questStatus",
          "dataType": "string",
          "mappedProperty": "outcome"
        }
      ]
    }
  ]
}
```

**Response**

```
{
  "errors": [
    {
      "status": 200
    },
    {
      "status": 201
    }
  ]
}
```

**Sample Response in case of errors**

```
{
  "errors": [
    {
      "status": 200
    },
    {
      "eventName": "questFinished",
      "status": 409,
      "code": 1234,
      "message": "An event with the event name already exists"
    }
  ]
}
```
