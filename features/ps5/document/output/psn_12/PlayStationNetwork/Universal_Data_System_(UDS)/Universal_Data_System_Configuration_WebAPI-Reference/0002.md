# listObjects

List Objects

### Description

Returns a list of all currently registered objects for the specified NP Service Label.

**Examples**

**Example 1: Get all activities**

```
curl -XGET 'https://s2s.sp-int.playstation.net/api/universalDataSystem/v1/objects?objectType=activity' -H "Content-type:application/json" -H "Authorization:Bearer {Bearer}"
```

**Response**

```
    {
      "objectId": "mainQuest1",
      "objectType": "activity",
      "status": "inDevelopment",
      "metadata": {
        "type": "activity",

        "name": {
          "en-US": "Sample Activity #1",
          "ja-JP": "サンプル アクティビティ #1"
        },
        "availableByDefault": true,
        "isRequiredForCompletion": true,
        "hidden": false,
        "isOnlineMultiplay": false
      },
      "links": {
        "tasks": [
          {
            "objectId": "task1",

      }
    },
    {
      "objectId": "task1",
      "objectType": "activity",
      "status": "inDevelopment",
      "metadata": {
```

# putObjects

Put Objects

### Description

Updates all objects specified in the request. If the object does not exist, the service will create it and indicate that by returning a "status": 201 in the response. If the object exists and is updated successfully, the service will respond with a "status": 204. If the metadata or links field for an object is not specified, those will not be updated. This can be used to only update the metadata of an object or only the links (or both).

*Note:* All free text inputs submitted by the user (except objectId) will have their leading / trailing whitespace trimmed.

**Examples**

**Example 1: Create an activity**

```
curl -XPUT 'https://s2s.sp-int.playstation.net/api/universalDataSystem/v1/objects/_bulk' -H "Content-type:application/json" -H "Authorization:Bearer {Bearer}" -d '
{
  "objects": [
    {
      "objectId": "mainQuest1",
      "objectType": "activity",
      "metadata": {
        "type": "activity",
        "category": "progress",
        "name": {
          "en-US": "Sample Activity #1",
          "ja-JP": "サンプル アクティビティ #1"
        },
        "availableByDefault": true,
        "isRequiredForCompletion": true,
        "hidden": false,
        "isOnlineMultiplay": false
      },
      "links": {
        "tasks": [
          {
            "objectId": "task1",
            "position": 0
          }
        ]
      }
    }
  ]
}'
```

**Response**

```
{
  "errors": [
    {
      "status": 200
    },
    {
      "status": 201
    }
  ]
}
```

**Sample Response in case of errors**

```
{
  "errors": [
    {
      "status": 200
    },
    {
      "status": 400,
      "code": 1234,
      "message": "Invalid property objects[0].metadata.type"
    }
  ]
}
```

# deleteObject

### Description

Deletes the object specified in the path. If the object does not exist 404 Not Found is returned, if the object is deleted successfully 204 No Content is returned.

**Examples**

**Example 1: Delete an activity**

