# Universal Data System Configuration Web API Reference – WebAPI 1

Source: https://game.develop.playstation.net/resources/documents/WebAPI/1/Universal_Data_System_Configuration_WebAPI-Reference/0015.html

# listUdsConfigurationsDiagnostics

Get a Diagnostic Report

### Description

Returns a diagnostic report of configuration failures found in UDS objects, events, stats, and trophies in your application. Configuration failures fall into three severity levels:

* *error*: The indicated entity has a critical configuration failure. You cannot promote this entity to production or Certification servers until you update the entity's configuration to resolve the error.
* *warning*: The indicated entity has a configuration failure. You cannot promote this entity to production or Certification servers until you either: update the entity's configuration to resolve the warning, or have the entity's configuration approved by SIE.
* *info*: The indicated entity has a configuration that could possibly lead to failure. You can promote this entity to production or Certification servers without updating its configuration.

Reports include the total number of configuration failures detected, the cause of each failure, and suggestions on how to resolve them.

**Examples**

**Example 1: Generate a diagnostic report**

```
curl -X GET 'https://s2s.{env}.playstation.net/api/universalDataSystem/v1/configurations/diagnostics?npServiceLabel={npServiceLabel}' -H "Content-type:application/json" -H "Authorization:Bearer {accessToken}"
```

### Request

```
GET /v1/configurations/diagnostics
```

### Query Parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| npServiceLabel | **integer(int32)** | false | The NP Service label.  **Min Value:** 0  **Max Value:** 99  **Default Value:** 0 |
| target | **string** | false | Allows you to filter results by target. You can specify multiple targets using a comma separated list. When joining multiple targets, do not insert spaces. If you omit this parameter, diagnostic results for all UDS entities are returned.  **Possible Values:**  - object  - eventDefinition  - statsDefinition  - statsExtraction  - trophy |

### Status Code 200

### Response Body (A result of Diagnostics.)

**Content-Type:** application/json

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| » resultsSummary | **object** | true | Summary of the diagnostic report. Includes the total number of errors and warnings. |
| »» totalErrorCount | **integer** | true | Total number of error level failures detected.  **Min Value:** 0 |
| »» totalWarningCount | **integer** | true | Total number of warning level failures detected.  **Min Value:** 0 |
| »» totalInfoCount | **integer** | true | Total number of info level failures detected.  **Min Value:** 0 |
| »» resultsCountGroupByTarget | **array[object]** | true | An array of results per target. Targets include objects, event definitions, stats definitions, stats extractions, and trophies.  **Min Items:** 0 |
| »»» target | **string** | true | Target entity of the diagnostic test.  **Possible Values:**  - object  - eventDefinition  - statsDefinition  - statsExtraction  - trophy |
| »»» errorCount | **integer** | false | Number of error level failures reported for the specified target.  **Min Value:** 0 |
| »»» warningCount | **integer** | false | Number of warning level failures reported for the specified target.  **Min Value:** 0 |
| »»» infoCount | **integer** | false | Number of info level failures reported for the specified target.  **Min Value:** 0 |
| » results | **array[object]** | true | An array of the diagnostic test's results, including details of errors and warnings, and possible resolution steps.  **Min Items:** 0 |
| »» severity | **string** | true | The severity of the reported configuration failure.  **Possible Values:**  - error  - warning  - info |
| »» target | **string** | true | Target entity of the diagnostic test.  **Possible Values:**  - object  - eventDefinition  - statsDefinition  - statsExtraction  - trophy |
| »» compareWith | **array[string]** | false | An array of entities that are compared with one another to highlight the configuration failure. This field only appears when cause is missingReference or dataTypeMismatch.  **Possible Values:**  - statsDefinition  - statsExtraction  - eventDefinition  **Min Items:** 0 |
| »» key | **object** | true | A unique identifier for each target. For example, objectID and objectType. |
| »»» objectId | **string** | false | The object ID. Underscore '\_' prefixes are prohibited. This field only appears when target is object or trophy.  **RegEx Pattern:** "^[0-9a-zA-Z\-\\_]{1,32}$" |
| »»» objectType | **string** | false | The type of object. For example, activity. This field only appears when target is object or trophy. |
| »»» eventName | **string** | false | The event name posted by the game through the SDK. This field only appears when target is eventDefinition.  **RegEx Pattern:** "^(?!\_)[0-9a-zA-Z\-\\_]{1,64}$" |
| »»» eventType | **string** | false | The event type. This field only appears when target is eventDefinition. |
| »»» statId | **integer** | false | Unique identifier of each stat definition. This field only appears when target is statsDefinition.  **Min Value:** 1 |
| »»» ruleId | **integer** | false | Unique identifier of each stats extraction rule. This field only appears when target is statsExtraction.  **Min Value:** 1 |
| »»» jsonPaths | **array[string]** | false | An array containing the JSON paths that lead to the entity that caused the configuration failure.  **Min Items:** 1 |
| »» cause | **string** | true | Cause of the entity's configuration failure. |
| »» details | **string** | true | Description of the entity's configuration failure. |
| »» suggestion | **string** | true | Possible steps to resolve the entity's configuration failure. |
