# listCustomStatsDefinition

Get custom stats definitions

### Description

Returns a list of custom stats definitions.

### Examples

**Retrieve a list of custom stats definitions**

```
GET https://s2s.{env}.playstation.net/api/universalDataSystem/v1/stats/statsDefinition/custom?npServiceLabel={npServiceLabel} Authorization: Bearer {accessToken}
```

**Response:**

```
{
  "schemaVersion": "1.1",
  "statsDefinitionRevision": 1,
  "statDefinitionArray": [
    {
      "statId": 2,
      "statName": "worstDamage",
      "status": "inDevelopment",
      "dataType": "int32",
      "aggregation": "max",
      "maxValue": "9999",
      "minValue": "0",
      "initialValue": "0"
    },
    {
      "statId": 5,
      "statName": "playerCharacter",
      "status": "inDevelopment",
      "dataType": "uint32",
      "aggregation": "max",
      "maxValue": "9999",
      "minValue": "0",
      "initialValue": "0"
    }
  ]
}
```

### Use Restrictions

| Client | Usable / Not Usable |
| --- | --- |
| Application for PlayStation®4 | Not Usable |
| Application for PlayStation®5 | Not Usable |
| Back office server | Usable |
| Application server | Not Usable |
| Application server (client credential) | Not Usable |
| Authorized App Server | Not Usable |

### Request

```
GET /v1/stats/statsDefinition/custom
```

| npServiceLabel | **integer** | false | NP service label  **Min Value:** 0  **Default Value:** 0 |

Max Value has to be greater than Min Value. It's not allowed to be equal ("Min Value < Max Value"). |
| »» minValue | **string** | false | Minimum value.  By default, the minimum of the defined value type will taken.  It can be specified within the range of the minimum value and the maximum value of each data type. # putCustomStatsDefinition

```

  "schemaVersion": "1.1",
  "npServiceLabel": 0,
  "statDefinitionArray": [
    {
      "statId": 5,
      "statName": "playerLevel",
      "dataType": "uint32",
      "aggregation": "max",
```
