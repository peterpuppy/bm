# Universal Data System Management Media Asset Web API Summary

**Introduction**

The Universal Data System Management Media Asset Web API is a management feature for back office servers. It provides abilities to manage media assets used by different UDS objects.

**Note:** The Universal Data System Management Media Asset Web API is not supported in the Sandbox Network Architecture. To upload media assets in Sandbox, you must use the np-service-config CLI tool. For more information, see [NP Service Config User's Guide](../../../SDK/latest/NP_Service_Config-Users_Guide/__document_toc.html).

**Call Rate Limits**

It is recommended that the call rates for this API are kept within the following ranges. Note that there is a possibility of rate limits changing without notice. Use the following information as a reference only.

| Request | Recommended Call Rate |
| --- | --- |
| getAssets | Within 30 times/15 minutes |
| putAssetWithoutID | Within 30 times/15 minutes |
| putAssetWithID | Within 30 times/15 minutes |

**Supported Media Types**

Supported media asset types are txt for tournament rules and png for UDS objects. Do not include additional metadata in image files.

**Supported Image Formats**

| Format | Type | Allow Alpha Channel |
| --- | --- | --- |
| png | 512x512 | Yes |
| png | 864x1040 | No |
| png | 3840x2160 | No |
| png | 944x332 | No |
| png | 944x320 | Yes |

### Base URLs

### Application Servers or Back Office Servers

The base URL to specify for application servers and back office servers depends on whether the client-side application uses the Sandbox network architecture or Legacy network architecture.  
(Refer to [Sandbox Network Architecture Guide](../../../SDK/latest/Sandbox_Network_Architecture-Guide/__document_toc.html) for details about Sandbox. Also refer to this technote regarding migration to Sandbox: <https://game.develop.playstation.net/technotes/view/740>. )

Specify the following base URL if the client-side application uses Sandbox:

* https://s2s.np.playstation.net/api/universalDataSystem

Specify the base URL of the applicable environment indicated below if the client-side application uses Legacy:

* Development environment (sp-int): https://s2s.sp-int.playstation.net/api/universalDataSystem
* Certification environment (prod-qa): https://s2s.prod-qa.playstation.net/api/universalDataSystem
* Production environment (RETAIL): https://s2s.np.playstation.net/api/universalDataSystem

For the purpose of maintaining backward compatibility, the above base URLs for Legacy can also be specified for application servers and back office servers that have migrated to Sandbox. For application servers and back office servers that serve traffic in both the Sandbox and Legacy network architectures, specify the base URL for Sandbox regarding Sandbox requests and specify the base URLs for Legacy regarding Legacy requests.
