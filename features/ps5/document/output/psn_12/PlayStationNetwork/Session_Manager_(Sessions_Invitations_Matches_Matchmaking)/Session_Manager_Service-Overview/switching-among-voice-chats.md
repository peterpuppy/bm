# Session Manager Service Overview – SDK 12.000

Source: https://game.develop.playstation.net/resources/documents/SDK/12.000/Session_Manager_Service-Overview/switching-among-voice-chats.html

# Relationship with the System Software

# Displaying Player Sessions

On the "Control Center" screen of the system software, a user can view the Player Session they are participating in and the Player Sessions their friends are participating in. Regarding the Player Session that a user is participating in, the user can invite other users to join, share the URL for joining it, etc. If the user is the leader of the Player Session, they can kick out other members or appoint another member to be the leader.

Additionally, the user can jump in to join a Player Session they haven't yet joined and perform other actions on the screen.

# Receiving an Invitation to a Player Session

If a user has been invited to a Player Session by another user, the invitation will be displayed on the system software "Notifications" screen. On this screen, the user can check from whom the invitation came, which game the invitation is for, and other details of the invitation. When the user accepts the invitation, the relevant application launches, and a game intent instructing the application to have the user join the Player Session is passed to the application.

# Switching Among Voice Chats

Users can use multiple voice chats simultaneously and can switch among the active voice chat with a system software screen.
