# Session Manager Web API Reference – WebAPI 1

Source: https://game.develop.playstation.net/resources/documents/WebAPI/1/Session_Manager_WebAPI-Reference/0002.html

# Creation of a Player Session

# createPlayerSessions

Creates a Player Session

### Description

This request creates a Player Session.

* If the request is called by a PlayStation™Network user, the user specified by the combination of *accountId* and *platform* joins as a PlayStation™Network player and becomes the leader of the created Player Session.  
  For *accountId*, be sure to specify either me or the *accountId* of the user linked to the access token.  
  For *platform*, specify either me, indicating the platform of the user linked to the access token, or the platform of the user linked to the access token, itself.  
  If the specified user has already joined another Player Session, they will automatically leave that Player Session.  
  Note that when the request is called from an application server, it is not possible to use an access token obtained using the authentication feature for websites.
* If the request is called by a non-PlayStation™Network user, the users specified with *playerId* join as non-PlayStation™Network players.  
  In such cases, it is necessary to use App Server (Client Credential) as the product type and specify the header parameter X-PSN-SESSION-MANAGER-NON-PSN-CALLER-ID. For X-PSN-SESSION-MANAGER-NON-PSN-CALLER-ID, specify the same value as any of the *playerId* specified in the request body. That user will be the leader.  
  *playerId* must be a unique value within the Player Session being created. Players in other Player Sessions with the same *playerId* will not be considered to be the same player.

```
            ],

          }
        ]
      },
      "joinDisabled": false,
      "supportedPlatforms": [
        "PS5"
      ],
      "localizedSessionName": {
        "defaultLanguage": "en-US",
        "localizedText": {
          "en-US": "en-US Session Name",
          "ja-JP": "ja-JPのセッション名"
        }
      },
      "joinableUserType": "FRIENDS",
      "invitableUserType": "MEMBER",
      "exclusiveLeaderPrivileges": [
        "KICK",
        "UPDATE_JOINABLE_USER_TYPE",
        "UPDATE_INVITABLE_USER_TYPE"
      ],
      "disableSystemUiMenu": [
        "PROMOTE_TO_LEADER"
```

```
  ]
}
```

### Use Restrictions

| Client | Usable / Not Usable |
| --- | --- |
| Application for PlayStation®4 | Usable |
| Application for PlayStation®5 | Usable |
| Back office server | Not Usable |
| Application server | Usable |
| Application server (client credential) | Usable |
| Authorized App Server | Not Usable |

### Request

```
POST /v1/playerSessions
```

### Header Parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| X-Psn-Accept-Platform-Name-Ps5 | **string** | false | Specifies the *Platform* name included in the response. If nothing is specified, PS5 will be returned as the *Platform* name.  **Possible Values:**  - PROSPERO |
| X-PSN-SESSION-MANAGER-NON-PSN-CALLER-ID | **string** | false | If the request is called by a non-PlayStation™Network user, specify the player ID defined by the application (not possible to specify more than one).  In such cases, it is necessary to use App Server (Client Credential) as the product type, and it becomes a required parameter. The specified value is used as the "Player ID of the user who called the request" in push notifications.  **RegEx Pattern:** "^[A-Za-z0-9\_-]{1,64}$" |
| X-Psn-Np-Service-Label | **string** | false | NP service label. This is a required parameter if the product type is App Server (Client Credential). It is not possible to specify more than one. |

### Request Body

**Content-Type:** application/json

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| » playerSessions | **array[object]** | true | Array for the Player Sessions to be created. Currently, an error will occur if the array has multiple elements.  **Min Items:** 1  **Max Items:** 1 |
| »» maxPlayers | **integer(int32)** | true | Maximum number of members that can participate as players in a Player Session (the total number of the PlayStation™Network players and non-PlayStation™Network players).  It is not possible to create a Player Session that can be joined by more players than the maximum value that can be specified. In such a case, divide into multiple Player Sessions.    **Min Value:** 1  **Max Value:** 100 |
| »» maxSpectators | **integer(int32)** | false | Maximum number of members who can join the Player Session as spectators.  It is not possible to create a Player Session that can be joined by more spectators than the maximum value that can be specified. In such a case, divide into multiple Player Sessions.    **Min Value:** 0  **Max Value:** 50  **Default Value:** 0 |
| »» member | **object** | true | Information about the users participating in the Player Session |
| »»» players | **array[object]** | false | Information about the users participating in the Player Session as PlayStation™Network players  **Min Items:** 1  **Max Items:** 1 |
| »»»» accountId | **string** | true | Account ID. me is the account ID of the user linked to the access token  **RegEx Pattern:** "^me$|^[1-9][0-9]{1,18}$" |
| »»»» platform | **string** | true | Platform. me is the platform of the user linked to the access token  **RegEx Pattern:** "^me$|^PROSPERO$|^PS4$|^PS5$" |
| »»»» pushContexts | **array[object]** | true | Push context information  **Min Items:** 1  **Max Items:** 1 |
| »»»»» pushContextId | **string** | true | Push context ID  **RegEx Pattern:** "^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$" |
| »»»» customData1 | **string(byte)** | false | Custom data  The maximum size is the size yielded from encoding 1024 bytes in Base64.  **Min Length:** 1 |
| »»» nonPsnPlayers | **array[object]** | false | Information about the users participating in the Player Session as non-PlayStation™Network players  **Min Items:** 1  **Max Items:** 100 |
| »»»» playerId | **string** | true | Player ID (must be a unique ID within the same Player Session ID)  **Min Length:** 1  **Max Length:** 64  **RegEx Pattern:** "^[a-zA-Z0-9\_-]{1,64}$" |
| »»»» playerName | **string** | true | Player name  **Min Length:** 1  **Max Length:** 32 |
| »»»» customData1 | **string(byte)** | false | Custom data  The maximum size is the size yielded from encoding 1024 bytes in Base64.  **Min Length:** 1 |
| »» joinDisabled | **boolean** | false | Flag for temporarily prohibiting joining the Player Session  When true, the Player Session cannot be joined. When false, users who have received invitation notifications or users who can join without such notifications because of the value set for *joinableUserType* can join the Player Session.    **Default Value:** false |
| »» supportedPlatforms | **array[string]** | true | Information about the platforms with which users can join the Player Session  **Possible Values:**  - PROSPERO  - PS4  - PS5  **Min Items:** 1 |
| »» localizedSessionName | **object** | true | Player Session name data object |
| »»» defaultLanguage | **string** | true | Default language code  The localizedText corresponding to this language code will be referenced if there is no localizedText corresponding to the language code specified in the Accept-Language header with the referencing API.  One of the language codes specified with *localizedText* can be specified.    **Min Length:** 1 |
| »»» localizedText | **object** | true | Multilingual JSON object  Specify combinations of language codes and corresponding messages. Multiple combinations can be specified.  For the language codes that can be specified, refer to the "Language Codes" section of the [Session Manager Web API Overview](../Session_Manager_WebAPI-Overview/__document_toc.html) document.  For messages corresponding to language codes, an arbitrary string with a maximum length of 128 characters can be specified for each language code. |
| »» joinableUserType | **string** | false | Users who can join the Player Session without an invitation  - NO\_ONE: No user can join without an invitation  - FRIENDS: Friends of the leader of the Player Session can join  - FRIENDS\_OF\_FRIENDS: Friends of friends of the leader of the Player Session can join  - ANYONE: Anyone can join  - SPECIFIED\_USERS: Users who have been registered on the *joinableSpecifiedUsers* list can join without invitations    **Possible Values:**  - NO\_ONE  - FRIENDS  - FRIENDS\_OF\_FRIENDS  - ANYONE  - SPECIFIED\_USERS  **Default Value:** FRIENDS\_OF\_FRIENDS |
| »» invitableUserType | **string** | false | Information about who can send invitations to the Player Session  **Possible Values:**  - NO\_ONE  - LEADER  - MEMBER  **Default Value:** MEMBER |
| »» leaderPrivileges | **array[string]** | false | Information about the privileges possessed by the leader of the Player Session   If a specification is made with this parameter, the leader will have the specified privileges. If nothing is specified, the leader will have KICK and UPDATE\_JOINABLE\_USER\_TYPE privileges. However, it is recommended that *exclusiveLeaderPrivileges*, rather than this parameter, be used to specify the leader's privileges.  **Possible Values:**  - KICK  - UPDATE\_JOINABLE\_USER\_TYPE  **Min Items:** 0 |
| »» exclusiveLeaderPrivileges | **array[string]** | false | Items excluded from the privileges that the leader has by default  The specified items will become inoperable from both the system software and the game. | »» disableSystemUiMenu | **array[string]** | false | Of the privileges that the leader has by default, items whose operation from the system software UI is to be disabled  The specified items will become inoperable from the system software but will remain operable from the game as long as they are not specified in *exclusiveLeaderPrivileges*.  The same item cannot be specified for *disableSystemUiMenu* and *exclusiveLeaderPrivileges*.  For details about usage, refer to the "Types of Sessions and Their Main Properties" chapter in the [Session Manager Web API Overview](../Session_Manager_WebAPI-Overview/__document_toc.html) document.  **Possible Values:**  - KICK  - UPDATE\_JOINABLE\_USER\_TYPE  - UPDATE\_INVITABLE\_USER\_TYPE  - PROMOTE\_TO\_LEADER  **Min Items:** 0 |
| »» customData1 | **string(byte)** | false | Custom data  The maximum size is the size yielded from encoding 1024 bytes in Base64.  **Min Length:** 1 |
| »» customData2 | **string(byte)** | false | Custom data  The maximum size is the size yielded from encoding 1024 bytes in Base64.  **Min Length:** 1 |
| »» swapSupported | **boolean** | false | Flag indicating whether members who have joined can switch from PlayStation™Network players to spectators without leaving, or from spectators to PlayStation™Network players without leaving  When true, swapping is allowed (users can also swap using the system software UI).  When false, swapping is not allowed.    **Default Value:** false |
| »» expirationTime | **integer(int32)** | false | Expiration time [sec] for the Player Session that non-PlayStation™Network users can join  It can be specified when creating the Player Session and cannot be changed later.  It is required when creating a Player Session that non-PlayStation™Network users can join.  It cannot be specified in a Player Session that only PlayStation™Network users can join.  **Min Value:** 60  **Max Value:** 86400 |
| »» npServiceLabel | **integer(int32)** | false | NP service label  It can only be set when the product type is App Server and will be 0 if a value is not specified. |
| »» nonPsnSupported | **boolean** | false | Flag indicating whether the Player Session can be joined by non-PlayStation™Network users  It can be specified when creating a Player Session and cannot be changed later.  If true, then both PlayStation™Network users and non-PlayStation™Network users will be able to join the Player Session.  If false, then only PlayStation™Network users will be able to join the Player Session.  If the request is executed by a PlayStation™Network user, either true or false can be specified. If nothing is specified, it will be false.  If the request is executed by a non-PlayStation™Network user, only true can be specified. If nothing is specified, it will be true.  [Note] When nothing is specified, the behavior will change depending on the caller of the request. |
