# Searching for and Listing Player Sessions

# getPlayerSessions

Obtains Player Session information

### Description

This request obtains information about the Player Session specified with the X-PSN-SESSION-MANAGER-SESSION-IDS header.  
If a Player Session with the specified *sessionId* does not exist, session information will not be included in the response.

* If the request is called by a PlayStation™Network user and is called from an application server, an access token obtained using the authentication feature for websites cannot be used.
* If the request is called by a non-PlayStation™Network user, App Server (Client Credential) must be used as the product type and that user's player ID must be specified for the X-PSN-SESSION-MANAGER-NON-PSN-CALLER-ID header parameter.

# getJoinedPlayerSessionsByUser

Obtains a list of Player Sessions in which the user is participating

### Description

This request obtains a list of the Player Sessions in which the specified PlayStation™Network user is participating.

For *accountId*, you can specify only either me, indicating the user linked to access token, or the *accountId* of the user linked to the access token.  
If no Player Session in which the specified user is participating exists, an empty Player Session list will be returned.

Note that when the request is called from an application server, it is not possible to use an access token obtained using the authentication feature for websites.  
If calling from an application for PlayStation®4 using the Cross-Generation SDK, PS4 must be specified for the *platformFilter* query parameter.

**Example Response**

```
{
  "playerSessions": [
    {
      "sessionId": "47664463-1040-4d51-bbcd-10179393896e",
      "platform": "PS5"
    }
  ]
}
```

# getFriendsPlayerSessions

Obtains a list of Player Sessions that are joined by friends

### Description

This request obtains a list of the Player Sessions that are joined by the PlayStation™Network user's friends.  
However, if a friend has enabled the Appear Offline feature or has configured title privacy settings to restrict his or her visibility, information concerning that friend cannot be obtained.

When you would like to obtain a list of the Player Sessions in which a particular friend is participating,  
X-PSN-SESSION-MANAGER-ACCOUNT-IDS of the request header can be specified.  
If there are no Player Sessions that are joined by friends, an empty friend object will be returned.

Note that when the request is called from an application server, it is not possible to use an access token obtained using the authentication feature for websites.

**Example Response**

```
{
  "friends": [
    {
      "accountId": "987654321",
      "onlineId": "OnlineID_A",
      "playerSessions": [
        {
          "sessionId": "47664463-1040-4d51-bbcd-10179393896e",
          "sessionName": "en-US Session's name",
          "playerJoinableStatus": "JOINABLE",
          "spectatorJoinableStatus": "JOINABLE",
          "platform": "PS5"
        }
      ]
    }
  ]
}
```

### Request

```
GET /v1/friends/playerSessions
```

### Header Parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| X-PSN-SESSION-MANAGER-ACCOUNT-IDS | **string** | false | Specify multiple account IDs (up to a maximum of 100), separated with commas. |
| Accept-Language | **string** | false | For the language codes that can be specified, refer to the "Language Codes" section of the [Session Manager Web API Overview](../Session_Manager_WebAPI-Overview/__document_toc.html) document. |

### Responses

| Status | Meaning | Description |
| --- | --- | --- |
| 200 | [OK](https://tools.ietf.org/html/rfc7231#section-6.3.1) | Normal termination |
| 400 | [Bad Request](https://tools.ietf.org/html/rfc7231#section-6.5.1) | Error in request |
| 401 | [Unauthorized](https://tools.ietf.org/html/rfc7235#section-3.1) | There is no authentication data, etc. |

### Status Code 200

### Response Body

**Content-Type:** application/json

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| » friends | **array[object]** | true | Friend information  **Min Items:** 0 |
| »» accountId | **string** | false | Account ID  **RegEx Pattern:** "^[1-9][0-9]{1,18}$" |
| »» onlineId | **string** | false | Online ID  **RegEx Pattern:** "^[a-zA-Z][a-zA-Z0-9\_-]{2,15}$" |
| »» playerSessions | **array[object]** | false | Array of Player Sessions in which a friend is participating  **Min Items:** 1 |
| »»» sessionId | **string** | false | Player Session ID. The format is UUID Version 4  **RegEx Pattern:** "^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$" |
| »»» sessionName | **string** | false | Name of the Player Session (based on the settings in the Accept-Language header)  **Min Length:** 1 |
| »»» playerJoinableStatus | **string** | false | Status of whether a user can join the Player Session as a PlayStation™Network player  **Possible Values:**  - JOINABLE  - NOT\_JOINABLE |
| »»» spectatorJoinableStatus | **string** | false | Status of whether the Player Session can be joined as a spectator  **Possible Values:**  - JOINABLE  - NOT\_JOINABLE |
| »»» platform | **string** | false | Platform  **RegEx Pattern:** "^PS4$|^PS5$" |
