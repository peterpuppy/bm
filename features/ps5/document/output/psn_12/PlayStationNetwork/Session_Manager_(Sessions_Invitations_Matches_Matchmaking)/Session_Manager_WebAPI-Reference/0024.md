# Creation and Deletion of Game Sessions

# createGameSessions

Creates a Game Session

### Description

This request creates a Game Session.

*usePlayerSession* can be used to specify whether the Game Session to be created is dependent on a Player Session or not.  
When *usePlayerSession* is not specified or when true is specified for it, a Game Session that is dependent on a Player Session will be created; in such cases, the user linked to the access token must be participating in one of the Player Sessions as a player.  
When false is specified for *usePlayerSession*, a Game Session that is not dependent on a Player Session will be created; it will be possible to create a Game Session even if the user who is linked to the access token is not participating in a Player Session.

Multiple users can be specified as members who can join the created Game Session.  
Specify the following for *joinState* of each user.

* For the user linked to the access token, *joinState*=JOINED
* For users other than the user linked to the access token, *joinState*=RESERVED

me can be specified for *platform* of the user who is linked to the access token.  
The user linked to the access token joins the created Game Session as a player and becomes the representative.

The validity period of a user's reservation, whose *joinState*=RESERVED, can be specified with *reservationTimeoutSeconds*.  
The reservation will automatically be invalidated if the validity period elapses after the Game Session is created without the user joining it.

When *searchIndex* is specified, the Game Session that is created will be included in Game Session search results. For details, refer to the "Basic Usage of Game Sessions" section of "3. Using the Web API" in the [Session Manager Web API Overview](../Session_Manager_WebAPI-Overview/__document_toc.html) document.  
Note that when the request is called from an application server, it is not possible to use an access token obtained using the authentication feature for websites.

# deleteGameSession

Deletes a Game Session

### Description

This request deletes the specified Game Session.  
All members participating in the Game Session will be made to leave it.

Note that when the request is called from an application server, it is not possible to use an access token obtained using the authentication feature for websites.

| Application server (client credential) | Not Usable |
| Authorized App Server | Not Usable |
