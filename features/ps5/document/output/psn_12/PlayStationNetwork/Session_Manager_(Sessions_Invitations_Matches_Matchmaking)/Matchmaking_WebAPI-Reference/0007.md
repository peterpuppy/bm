# Statistics

# listTicketResults

Obtain a list of matchmaking ticket statistics

### Description

This request obtains a list of statistics for a period of one minute from the specified time regarding matchmaking tickets for the specified ruleset.

Statistics of the following tickets are included in the list:  
- completed: Tickets with the COMPLETED status (offer created). If tickets with the COMPLETED status don't exist, statistics regarding the wait time until matchmaking is achieved (time) won't be included in the response.  
- canceled: Tickets canceled by cancelTicket. Old tickets canceled because new tickets were created are excluded.  
- timedOut: Tickets with the TIMED\_OUT status (time limit established in the ruleset elapsed without matchmaking being achieved)  
- failed: Tickets with the FAILED status (failed due to a system failure)

Note that this API feature does not support the Sandbox network architecture. It is not possible to use an access token obtained in Sandbox.

### Request

```
GET /v1/rulesets/ticketResults
```

### Query Parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| rulesetName | **string** | true | Specify the names of rulesets for which you want to obtain statistics.  Up to 10 ruleset names can be specified, separated with commas. |
| startDateTime | **string(date-time)** | false | Specify the start time for obtaining statistics.  A time within the last one week can be specified.  Specification must be in minute units. An error will occur when a value other than 0 is specified for seconds and milliseconds.  When a specification is not made, it will be handled as if "now" has been specified, and statistics will be obtained for the period of one minute immediately before the request call. |
| npServiceLabel | **integer(int32)** | false | NP service label  **Min Value:** 0  **Default Value:** 0 |
