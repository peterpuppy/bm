# Matchmaking Web API Reference Summary

The Matchmaking Web API provides matchmaking features for online competitive play that is linked to a Session Manager Game Session.

**Call Rate Limits**

It is recommended that call rates for the Matchmaking Web API be kept within the following ranges. Note that there is a possibility of rate limits changing without notice. Use the following information as a reference only.

| Request | Recommended Call Rate |
| --- | --- |
| submitTicket | Within 90 times/15 minutes |
| getTicket | Within 90 times/15 minutes |
| cancelTicket | Within 90 times/15 minutes |
| getOffer | Within 90 times/15 minutes |
| listUserTickets | Within 90 times/15 minutes |
| listTicketResults | Within 150 times/15 minutes |

### Base URLs

### Application for PlayStation®5

For PlayStation®5 applications, there is no need to explicitly construct a base URL. Obtaining an appropriate base URL is automatically processed by calling a PlayStation™Network Web API using either the NpWebApi2 library or the NpCppWebApi library.

### Application Servers or Back Office Servers

For application servers or back office servers, specify the base URLs as follows.

* https://s2s.sp-int.playstation.net/api/matchmaking (development environment)
* https://s2s.prod-qa.playstation.net/api/matchmaking (certification environment)
* https://s2s.np.playstation.net/api/matchmaking (production environment)
