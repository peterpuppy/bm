# Error Codes

| Code (Decimal) | Code (Hex) | Message | Description |
| --- | --- | --- | --- |
| 2273281 | 22B001 | Bad request ('reason') | Request is invalid (a required parameter is missing, the value specified for a parameter is invalid, etc.) |
| 2273293 | 22B00D | Resource not found ('reason') | The requested resource could not be found (the specified user or title does not exist, the client ID of the access token is wrong, etc.) |
| 2273294 | 22B00E | Not permitted by access control | Access was denied (not the resource owner, the resource belongs to another title, because of privacy settings, etc.) |
| 2273408 | 22B080 | Bad request | Request is invalid (format is invalid, etc.) |
| 2273411 | 22B083 | Forbidden | Access was denied (details unknown) |
| 2273412 | 22B084 | Not Found | Invalid URL (an unsupported API version was specified, etc.) |
| 2273413 | 22B085 | Method Not Allowed | The request method is not supported by the target resource |
| 2273417 | 22B089 | Conflict | The request is in conflict with a resource |
| 2273437 | 22B09D | Too Many Requests | Request rate limit was exceeded |
| 2273792 | 22B200 | Authentication required | An access token has not been specified |
| 2273793 | 22B201 | Invalid token | The specified access token has an invalid value or is corrupted |
| 2273798 | 22B206 | Insufficient scope | The scope is invalid (authorization has not been obtained, the wrong method of obtaining the access token was used, a parameter that cannot be used with the platform was specified, etc.) |
| 2273806 | 22B20E | Online ID required | The account must be upgraded |
| 2273932 | 22B28C | Expired token | Access token is expired |
| 2273933 | 22B28D | Np Environment not matched | Environment name is invalid |
| 2274176 | 22B380 | Internal server error | An unexpected error occurred on the server side |
| 2274179 | 22B383 | Service Unavailable | Service cannot be used (server is under maintenance, server is overloaded, service has ended, authentication/authorization server error, etc.) |
| 2274304 | 22B400 | Ruleset not found | A ruleset has not been created. Create it using the Matchmaking Tool. |
| 2274305 | 22B401 | Ruleset is not active | A ruleset has not been activated. Activate it using the Matchmaking Tool. |
| 2274306 | 22B402 | Invalid ticket for the ruleset ('reason') | The specified team or attribute value does not match the definition or declaration in the ruleset |
| 2274307 | 22B403 | Attribute type and value mismatch | The type of the attribute value is declared as 'NUMBER', but the attribute value is not a string that represents a Double type. |
| 2274308 | 22B404 | Ticket is already completed | Unable to complete operation because matchmaking has already been achieved |
| 2274309 | 22B405 | natType is required | useNatTypeForTopology is set in the ruleset but each player's nat Type is not specified in the ticket. |
| 2274310 | 22B406 | Invalid natType combination | useNatTypeForTopology is set to 'MESH' in the ruleset but two or more players whose nat Type is 3 are included in the ticket. |
| 2274311 | 22B407 | Game Session not found | The specified Game Session does not exist |
| 2274312 | 22B408 | Invalid Game Session ('reason') | There are inconsistencies between the specified Game Session and the ticket or ruleset |
