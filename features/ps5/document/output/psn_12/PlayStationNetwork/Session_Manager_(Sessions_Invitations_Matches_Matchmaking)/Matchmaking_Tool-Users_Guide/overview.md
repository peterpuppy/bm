# Matchmaking Tool User's Guide

This chapter provides an overview of the Matchmaking Tool.

This guide is for those that need to test and create matchmaking rulesets. This
includes:

* Game developers and network engineers.
* Game planners and game designers.
* Submission managers and operators managing the configuration of the title.

## Features

The Matchmaking Tool allows you to view, create, and manage matchmaking rulesets for
a given NP Communication ID. Rulesets can be created using JSON and then uploaded
through the tool to the developer environment.

## Supported Browsers

The Matchmaking Tool supports Chrome, Firefox, and Microsoft Edge browsers.
