# NpCommerce Library Overview

The NpCommerce library provides features that show or hide PlayStation™Store icons. Applications that implement commerce with an in-game browsing format must use this API to display a PlayStation™Store icon.

## Main Features

The main features provided by the NpCommerce library are:

* Feature for showing or hiding the PlayStation™Store icon.
* Feature for setting the display position of the PlayStation™Store icon.
