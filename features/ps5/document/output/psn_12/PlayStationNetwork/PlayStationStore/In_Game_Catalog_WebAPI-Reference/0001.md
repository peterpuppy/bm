# In-Game Catalog Web API Reference Summary

The In-Game Catalog Web API provides REST resources and requests that allow applications to query for information about store products and categories for use in an in-game store.

### Base URLs

### PlayStation®5 Applications

For PlayStation®5 applications, there is no need to explicitly construct a base URL. Obtaining an appropriate base URL is automatically processed by calling a PlayStation™Network Web API using either the NpWebApi2 library or the NpCppWebApi library.

### Application Servers or Back Office Servers

For application servers or back office servers, construct the base URL as follows.

* https://s2s.sp-int.playstation.net/api/inGameCatalog (Development environment)
* https://s2s.prod-qa.playstation.net/api/inGameCatalog (Certification environment)
* https://s2s.np.playstation.net/api/inGameCatalog (Production environment)

### Authentication

For information about obtaining an access token to authenticate a request, please see [PlayStation™Network Web APIs Overview - Usage - Obtaining Access Tokens](../../../SDK/latest/PSN_WebAPI-Overview/obtaining-access-tokens.html).
