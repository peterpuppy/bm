# sceNpCommerceShowPsStoreIcon

Shows the PlayStation™Store icon.

### Definition

```
#include <np.h>
typedef enum {
    (Omitted: see details below)
} SceNpCommercePsStoreIconPos;

int sceNpCommerceShowPsStoreIcon(
    SceNpCommercePsStoreIconPos pos
);
```

### Arguments

|  |  |
| --- | --- |
| pos | Position to place the PlayStation™Store icon. |

### Return Values

Returns SCE\_OK (=0).

### Description

This function displays the PlayStation™Store icon on the screen as an overlay.

For pos, specify one of the following values that determine the position of the PlayStation™Store icon.

|  |  |
| --- | --- |
| Value | Description |
| SCE\_NP\_COMMERCE\_PS\_STORE\_ICON\_CENTER | Screen lower center |
| SCE\_NP\_COMMERCE\_PS\_STORE\_ICON\_LEFT | Screen lower left |
| SCE\_NP\_COMMERCE\_PS\_STORE\_ICON\_RIGHT | Screen lower right |

However, the value specified to pos is ignored during 3D VR (3D display in the VR output mode) and the PlayStation™Store icon is positioned at the lower center of the overlay area of the system screen.

To hide a PlayStation™Store icon that was displayed with sceNpCommerceShowPsStoreIcon(), use [sceNpCommerceHidePsStoreIcon()](0002.html#0sceNpCommerceHidePsStoreIcon).

# sceNpCommerceSetPsStoreIconLayout

Sets the layout area of the PlayStation™Store icon.

### Definition

```
#include <np.h>
typedef enum {
    (Omitted: see details below)
} SceNpCommercePsStoreIconLayout;

int sceNpCommerceSetPsStoreIconLayout(
    SceNpCommercePsStoreIconLayout layout
);
```

### Arguments

|  |  |
| --- | --- |
| layout | Layout area for positioning the PlayStation™Store icon. |

### Return Values

Returns SCE\_OK (=0).

### Description

This function sets the layout area of the PlayStation™Store icon. Specify one of the following values to layout.

|  |  |
| --- | --- |
| Value | Description |
| SCE\_NP\_COMMERCE\_PS\_STORE\_ICON\_LAYOUT\_DEFAULT | Fix the layout area to the entire screen (100%). |
| SCE\_NP\_COMMERCE\_PS\_STORE\_ICON\_LAYOUT\_FOLLOW\_DISPLAY\_SAFE\_AREA\_INFO | Change the layout area pursuant to the safe area (90% to 100%). |
| SCE\_NP\_COMMERCE\_PS\_STORE\_ICON\_LAYOUT\_FIXED\_SCALE\_90PERCENT | Fix the layout area to 90% of the entire screen. |

SCE\_NP\_COMMERCE\_PS\_STORE\_ICON\_LAYOUT\_DEFAULT sets the entire display screen (100%) as the layout area. This layout area is the same as that used by system software earlier than 3.00. This value is set upon application startup.

SCE\_NP\_COMMERCE\_PS\_STORE\_ICON\_LAYOUT\_FOLLOW\_DISPLAY\_SAFE\_AREA\_INFO sets the display's safe area as the layout area. The layout area is adjusted accordingly when the display's safe area changes. The current value of the display's safe area can be obtained with [sceSystemServiceGetDisplaySafeAreaInfo()](../SystemService-Reference/ps5-sce-system-service-get-display-safe-area-info.html).

SCE\_NP\_COMMERCE\_PS\_STORE\_ICON\_LAYOUT\_FIXED\_SCALE\_90PERCENT sets an area that is 90% of the entire display screen as the layout area.

Once the layout area is set, it does not change unless the application is restarted or another setting is applied using this API.

The setting made by this API is ignored during 3D VR (3D display in the VR output mode) and the PlayStation™Store icon is displayed at the lower center of the overlay area of the system screen.
