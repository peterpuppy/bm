# Title Cloud Storage Web API Reference Summary

By using the Title Cloud Storage service, you can save 64-bit integers (TCS variables) and binary data (TCS data) to PlayStation™Network servers; by default each user can have 64 TCS variables and 16 pieces (8 MiB in total) of TCS data. Separately from the user level, at the title level, you can use 2,048 TCS variables and 512 pieces (64 MiB in total) of TCS data. Access privileges can be set for each TCS variable or piece of TCS data to determine whether other users are allowed to read from, or write to, it.

In addition to simple read and write operations, atomic additions and conditional writes can be performed on a TCS variable. It is also possible to operate on multiple TCS variables belonging to a single user at the same time, as well as to operate on specific TCS variables of multiple users at the same time.

**Call Rate Limits**

It is recommended that the call rates for the Title Cloud Storage Web API are kept within the following ranges. Note that there is a possibility of rate limits changing without notice. Use the following information as a reference only.

| Request | Recommended Call Rate |

| deleteMultiDataByUser and deleteMultiDataBySlot | Within 300 times/15 minutes |

### Base URLs

### PlayStation®5 Applications

For PlayStation®5 applications, there is no need to explicitly construct a base URL. Obtaining an appropriate base URL is automatically processed by calling a PlayStation™Network Web API using either the NpWebApi2 library or the NpCppWebApi library.

### Application Servers and Back Office Servers

The base URL to specify for application servers and back office servers depends on whether the client-side application uses the Sandbox network architecture or Legacy network architecture.  
(Refer to [Sandbox Network Architecture Guide](../../../SDK/latest/Sandbox_Network_Architecture-Guide/__document_toc.html) for details about Sandbox. Also refer to this technote regarding migration to Sandbox: <https://game.develop.playstation.net/technotes/view/740>.)

Specify the following base URL if the client-side application uses Sandbox:

* https://s2s.np.playstation.net/api/titleCloudStorage

Specify the base URL of the applicable environment indicated below if the client-side application uses Legacy:

* Development environment (sp-int): https://s2s.sp-int.playstation.net/api/titleCloudStorage
* Certification environment (prod-qa): https://s2s.prod-qa.playstation.net/api/titleCloudStorage (to be supported later)
* Production environment (RETAIL): https://s2s.np.playstation.net/api/titleCloudStorage (to be supported later)

For the purpose of maintaining backward compatibility, the above base URLs for Legacy can also be specified for application servers and back office servers that have migrated to Sandbox. For application servers and back office servers that serve traffic in both the Sandbox and Legacy network architectures, specify the base URL for Sandbox regarding Sandbox requests and specify the base URLs for Legacy regarding Legacy requests.
