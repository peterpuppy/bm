# Title Cloud Storage Management Web API Reference Summary

The Title Cloud Storage (TCS) Management Web API is a management feature for back-office servers. Its main purposes are uploading data for distribution to a production environment and correcting/deleting improper data uploaded to title cloud storage. Anticipated situations in which the latter purpose might come into play include responding to broken game-balance resulting from improper data uploaded from an improper companion application.

**Call Rate Limits**

It is recommended that the call rates for the Title Cloud Storage Management Web API are kept within the following ranges. Note that there is a possibility of rate limits changing without notice. Use the following information as a reference only.

| Request | Recommended Call Rate |
| --- | --- |
| deleteMultiDataByUser | Within 50 times/15 minutes |
| deleteMultiVariablesByUser | Within 50 times/15 minutes |
| downloadData | Within 50 times/15 minutes |
| getMultiDataStatusesByUser | Within 50 times/15 minutes |
| getMultiVariablesByUser | Within 50 times/15 minutes |
| setMultiVariablesByUser | Within 50 times/15 minutes |
| uploadData | Within 30 times/15 minutes |

### Base URLs

### Application Servers and Back Office Servers

The base URL to specify for application servers and back office servers depends on whether the client-side application uses the Sandbox network architecture or Legacy network architecture.  
(Refer to [Sandbox Network Architecture Guide](../../../SDK/latest/Sandbox_Network_Architecture-Guide/__document_toc.html) for details about Sandbox. Also refer to this technote regarding migration to Sandbox: <https://game.develop.playstation.net/technotes/view/740>.)

Specify the following base URL if the client-side application uses Sandbox:

* https://s2s.np.playstation.net/api/titleCloudStorage

Specify the base URL of the applicable environment indicated below if the client-side application uses Legacy:

* Development environment (sp-int): https://s2s.sp-int.playstation.net/api/titleCloudStorage
* Certification environment (prod-qa): https://s2s.prod-qa.playstation.net/api/titleCloudStorage
* Production environment (RETAIL): https://s2s.np.playstation.net/api/titleCloudStorage

For the purpose of maintaining backward compatibility, the above base URLs for Legacy can also be specified for application servers and back office servers that have migrated to Sandbox. For application servers and back office servers that serve traffic in both the Sandbox and Legacy network architectures, specify the base URL for Sandbox regarding Sandbox requests and specify the base URLs for Legacy regarding Legacy requests.
