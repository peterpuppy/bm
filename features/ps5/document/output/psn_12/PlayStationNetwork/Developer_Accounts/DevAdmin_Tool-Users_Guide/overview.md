# DevAdmin Tool Overview

This chapter provides an overview of the DevAdmin tool and the features it provides.

The DevAdmin Tool allows publishers and first and third-party developers to modify an account and its properties in a development environment to see the effects of service implementations on the account and its entitlements based on the changes a typical user would make.

## Features

The main screen of the DevAdmin Tool displays a list of all the entitlements associated with the account along with the DRM ID, Active date, Inactive Date, and Entitled Days. From this screen you can perform the following tasks related to an account:

* Clear Entitlements
* Reset Password
* Change Online ID and Online ID History
* Age Account
* Verified Account Management and setting Display Name
* Testing Account Closure
* Testing Account Social Feature Restriction

## Supported Browsers

The tool is currently supported on Safari, Chrome, and Firefox.
