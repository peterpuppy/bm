# Profanity Filter Web API Reference Summary

The Profanity Filter Web API is a multi-lingual profanity filter for censoring or detecting profanity. It contains locale-specific dictionaries that provide high quality filtering. This service is based on a dictionary maintained by the Sony Global Moderation team.

There are two modes that can be used:

* **filter**: The submitted string is returned with profanity censored with asterisk "\*" characters.
* **test**: The submitted string is returned with profanity marked with square brackets "[]".

**Prerequisites**

You must have an NP Title ID and at least one NP Communication ID registered with PlayStation Network.

**Reducing Server Load**

There are a few practices you can use to reduce server load when using the Profanity Filter Web API:

* Avoid filtering static text or known safe text that is generated by your title. Only filter text that may contain user profanity.
* You are not required to re-filter content that has previously been filtered or moderated by other systems. This includes strings from other major game platforms.
* If you are filtering several small strings, concatenate them using a separator and submit them in one call to improve performance.

Ensure you are not using the Profanity Filter Web API excessively. SIE may throttle clients if traffic levels threaten the stability of other titles.

**Call Rate Limits**

It is recommended that the call rates for the Profanity Filter Web API are kept within the following ranges. The listed call rates are for all Profanity Filter API calls combined. Note that there is a possibility of rate limits changing without notice. Use the following information as a reference only.

| Request | Recommended Call Rate |
| --- | --- |
| POST /v2/profanity/filter/{locale}/{serviceLabel} | 300 req/minute all calls combined |
| POST /v2/profanity/test/{locale}/{serviceLabel} | 300 req/minute all calls combined |

### Base URLs

### PlayStation®5 Applications

For PlayStation®5 applications, there is no need to explicitly construct a base URL. Obtaining an appropriate base URL is automatically processed by calling a PlayStation™Network Web API using either the NpWebApi2 library or the NpCppWebApi library.

### Application Servers or Back Office Servers

The base URL to specify for application servers and back office servers depends on whether the client-side application uses the Sandbox network architecture or Legacy network architecture.  
(Refer to [Sandbox Network Architecture Guide](../../../SDK/latest/Sandbox_Network_Architecture-Guide/__document_toc.html) for details about Sandbox. Also refer to this technote regarding migration to Sandbox: <https://game.develop.playstation.net/technotes/view/740>. )

Specify the following base URL if the client-side application uses Sandbox:

* https://s2s.np.playstation.net/api/profanityFilter

Specify the base URL of the applicable environment indicated below if the client-side application uses Legacy:

* Development environment (sp-int): https://s2s.sp-int.playstation.net/api/profanityFilter
* Certification environment (prod-qa): https://s2s.prod-qa.playstation.net/api/profanityFilter
* Production environment (RETAIL): https://s2s.np.playstation.net/api/profanityFilter

For the purpose of maintaining backward compatibility, the above base URLs for Legacy can also be specified for application servers and back office servers that have migrated to Sandbox. For application servers and back office servers that serve traffic in both the Sandbox and Legacy network architectures, specify the base URL for Sandbox regarding Sandbox requests and specify the base URLs for Legacy regarding Legacy requests.
