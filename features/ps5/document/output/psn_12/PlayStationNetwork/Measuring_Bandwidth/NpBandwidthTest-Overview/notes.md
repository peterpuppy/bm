# Notes

# Limitations

* In order to reduce the load on the PlayStation™Network server, avoid unnecessary repetition of bandwidth measurement.
* Bandwidth measurement is calculated based on the time taken for HTTP-based file transfer. Since calculation is made based on a limited number of trials, it is possible that results may vary widely.
