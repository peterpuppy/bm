This section provides details on libraries and development resources you might use when developing with PlayStation™Network.

# Development Resources Provided by PlayStation™Network

This topic highlights different development resources provided by
PlayStation™Network.

The following development resources are provided for developing applications that use PlayStation™Network.

## PlayStation®5 Programmer Tool Runtime Library SDK

The standard SDK includes libraries that enable applications for PlayStation®5 to use PlayStation™Network. The SDK includes updates to the system software, the SDK body, and its documentation, including specification documents for the PlayStation™Network Web APIs.

## Content Pipeline

You can use Content Pipeline to register and publish new digital content and to submit
supporting data (including assets and wholesale pricing offers) to SIE. In Content
Pipeline, you can create concepts, which are groupings of related product groups and
content. Product groups within a concept may be related in several ways. For example, a
concept may contain all the product groups (full games, demos, add-ons, etc.) related to
a specific full game. Alternatively, it may contain a range of different non
game-related avatars or themes sold by a single publisher. For more information, refer
to the
Content
Pipeline documentation, located at <https://learn.playstation.net/bundle/content-pipeline/page/Getting_Started.html>.

## DevAdmin Tool

The DevAdmin Tool allows developers to modify accounts and their properties in the development environment. This can be used to simulate the changes a user might make in the live environment, and to test the effects of such changes on the account and its entitlements.

## Development Accounts

Development Accounts provides partners with a set of functions to manage accounts on PlayStation™Network in the development environment. This tool can be used as a more convenient and more feature-rich alternative to DevAdmin Tool for users who have PlayStation®5 DevNet access. For additional details, see the [Development Accounts User's Guide](../Development_Accounts-Users_Guide/__document_toc.html).

## DevNet

To support applications that use PlayStation™Network services, DevNet provides functionality for requesting and managing PlayStation™Network services, managing the NP Title Secret and Client Secret, and managing which developers have Title Dev and Title Admin roles.

## System Software

The system software provides functionality for PlayStation™Network configuration and debugging. For details, refer to the following document:

* [System Software User's Guide (Settings)](../System_Software-Users_Guide_for_Settings/__document_toc.html)

## Technical Notes

The "Technical Notes" section on the PlayStation®5 Developer Network contains bug reports, notes, restrictions, and announcements of library specification modifications that are required between SDK releases. Refer to them together with the SDK documents.
