# UDS Workflow

This section provides a workflow that you can follow for designing, configuring, and delivering data-driven experiences.

The workflow contains general phases, which are shown on the left side of the graphic
below. These phases are sequential and must be performed in order. The individual tasks to
the right of each workflow phase are listed in a recommended order, but in practice you can
accomplish them in an order that reflects your team's workflow. Consider these tasks as
check boxes to complete before moving on to the next phase.

Data-Driven Experiences Workflow

\* UDS Events and UDS Stats required for progressive trophies

\*\* UDS Activities required for Game Help and challenge activities

For more information about each task, reference the matching section for each task.

Note:
This document uses "you" to indicate who performs the various tasks outlined in the graphic. The usage of
"you" should be interpreted as the relevant individuals who are responsible for accomplishing
that specific task.
