# Debugging Support Provided by the System Software

This topic describes the debugging support features provided by the system software that are related to trophies.

# Online Mode and Offline Mode

There are two modes in which trophy configuration data and trophy records are displayed via the system software: Online Mode and Offline Mode. Online Mode references the data on the trophy server, while Offline Mode references installed data.

## Behavior on Retail Units

On retail units, the system software will run in Online Mode if the user is signed in to the PlayStation™Network and connected to a network. The system software will run in Offline Mode if the user is not signed in to the PlayStation™Network or not connected to a network.

In Online Mode, the list of trophy sets displayed in "Trophies" of the system software is a list of trophy sets for which trophy configuration data and the user's trophy records exist on the trophy server. Conversely, in Offline Mode, only trophy sets installed on the console will be listed. Note that a retail unit will not indicate which Mode it is currently in.

## Behavior on a Development Kit/Testing Kit

On a Development Kit/Testing Kit, the system software provides essentially the same user experience as on a retail unit. However, a Development Kit/Testing Kit allows you to freely switch between Online Mode and Offline Mode exclusively within "Trophies" of the system software. You can switch between these two modes by launching "Trophies" and then selecting "★Switch to Offline Mode" or "★Switch to Online Mode".

The system software on a Development Kit/Testing Kit also provides other debugging features such as the Preview Trophy UI and features for deleting trophy data.

# Local Mode

When the Universal Data System Development Mode on a Development Kit/Testing Kit is set to Local Mode, the system software references and displays trophy configuration data and trophy records that have been installed on the console for use with Local Mode. However, screens supported by Local Mode are the system software's trophy collection Local Mode screens ([Trophy Title List](trophy-title-list-screen.html#trophy-system-overview_7_2__fd8f606e-e267-11ee-bd3d-0242ac120002), [Trophy Group List](trophy-group-list-screen.html#trophy-system-overview_7_3__fd8f6212-e267-11ee-bd3d-0242ac120002), [Trophy List Screen](trophy-list-screen.html#trophy-system-overview_7_4__fd8f63ca-e267-11ee-bd3d-0242ac120002), [Trophy Details (Activity Card)](trophy-details-activity-card.html#trophy-system-overview_7_6__fd8f6960-e267-11ee-bd3d-0242ac120002)) and Preview Trophy UI screen. Screens such as the Control Center screens ([Example of Trophies Being Displayed on the Control Center Screen](control-center-screen.html#trophy-system-overview_7_5__fd8f664a-e267-11ee-bd3d-0242ac120002), [Example of Trophies Being Displayed on an Activity Card](control-center-screen.html#trophy-system-overview_7_5__fd8f67ee-e267-11ee-bd3d-0242ac120002)) are not supported.

For details about Local Mode, refer to [Universal Data System Guide - Local Development Workflow](../Universal_Data_System-Guide/local-development-workflow.html).

# Preview Trophy UI

The Preview Trophy UI can be used when in Online Mode. After the trophy configuration data has been configured using the UDS Management Tool, the Preview Trophy UI will allow you to meticulously check in various formats such as list and card display how each trophy will be displayed according to whether it is locked or unlocked, even at stages prior to the actual implementation of the application where the trophies will be unlocked.

The Preview Trophy UI can be launched from "Trophies" of the system software. Select "★Preview Trophy UI" from the options menu of the trophy set list. If necessary, you can check the trophy set of a specific title by entering the NP Title ID in the upper-right "★NpTitleId" field after startup.

Once the trophies are displayed, you can press the square button or select the "★Trophy List" tab to switch between display methods. You can also use the "★Unlock All" switch to switch between the displays before and after trophies are earned. Note that the trophy record displayed here, such as rarity and the earned date, is automatically generated by the system software and is not in any way related to the user's record.

Note:

If an NP Title ID of a title that is not running and for which the user does not have Title Dev/Title Admin privileges is specified, then "Can't access the title" will be displayed.

# Features for Deleting Trophy Data

## Deleting Trophy-Related Information for All Users on the Console

This feature is available in Offline Mode. Display the screen that lists trophy sets by selecting "Trophies" of the system software, and then select "★Delete All Users' Trophies (Console)" from the options menu. Alternatively, you can run prospero-ctrl as follows:

```
prospero-ctrl application delete-data trophy console
```

Trophy configuration data for all titles, trophy records for all users, and all other trophy-related information will be deleted from console storage. This will prevent trophy sets from being displayed in Offline Mode unless all users on the console install trophy-related information once again. This does not affect the trophy sets from being displayed in Online Mode.

Additionally, note that this action does not affect UDS Stats. If trophy unlocking data is deleted using this feature, inconsistencies between UDS Stats data and trophy unlocking data may arise. Such inconsistencies can be avoided by deleting UDS Stats from the console storage along with the trophy records. For how to delete UDS Stats from the console storage, refer to [NpUniversalDataSystem Library Overview - Using the Library - Debug Support Through the System Software](../NpUniversalDataSystem-Overview/debug-support-through-the-system-software.html).

## Deleting Trophy-Related Information for Specific Users on the Console

This feature is available in Offline Mode. Display the screen that lists trophy sets by selecting "Trophies" of the system software, and then select "★Delete This User's Trophies (Console)" from the Options menu. Alternatively, you can run prospero-ctrl as follows:

```
prospero-ctrl application delete-data trophy console /user:<User>
```

Select trophy-related data for the user in question, such as trophy record files for all titles, will be deleted from the console storage. This will prevent trophy sets from being displayed in Offline Mode unless that user on the console installs trophy-related information once again. This does not affect the trophy sets from being displayed in Online Mode.

Additionally, note that this action does not affect UDS Stats. If trophy unlocking data is deleted using this feature, inconsistencies between UDS Stats data and trophy unlocking data may arise. Such inconsistencies can be avoided by deleting UDS Stats from the console storage along with the trophy records. For how to delete UDS Stats from the console storage, refer to [NpUniversalDataSystem Library Overview - Using the Library - Debug Support Through the System Software](../NpUniversalDataSystem-Overview/debug-support-through-the-system-software.html).

This feature does not delete trophy configuration data from the console storage. Because trophy configuration data is installed on the console storage when a game package is installed or when a game is launched, it may be installed even if it is not apparent from the trophy collection displayed in the system software. If you would like to delete all trophy data, including trophy configuration data, use the aforementioned option "★Delete All Users' Trophies (Console)".

## Deleting Trophy-Related Information for Specific Users on the Console and Server

This feature is available in Online Mode. Display the screen that lists trophy sets by selecting "Trophies" of the system software, and then select "★Delete This User's Trophies (Console and Server)" from the options menu. Alternatively, you can run prospero-ctrl as follows:

```
prospero-ctrl application delete-data trophy all /user:<User>
```

Select trophy-related data for the user in question, such as trophy record files for all titles, will be deleted from the console storage and from the trophy server. This will prevent trophy sets from being displayed regardless of mode, unless that user on the console installs trophy-related information once again.

Additionally, note that this action does not affect UDS Stats. If trophy unlocking data is deleted using this feature, inconsistencies between UDS Stats data and trophy unlocking data may arise. Such inconsistencies can be avoided by deleting UDS Stats from the console storage along with the trophy records. For how to delete UDS Stats from the console storage, refer to [NpUniversalDataSystem Library Overview - Using the Library - Debug Support Through the System Software](../NpUniversalDataSystem-Overview/debug-support-through-the-system-software.html).

This feature does not delete trophy configuration data from the console storage. Because trophy configuration data is installed on the console storage when a game package is installed or when a game is launched, it may be installed even if it is not apparent from the trophy collection displayed in the system software. If you would like to delete all trophy data, including trophy configuration data, use the aforementioned option "★Delete All Users' Trophies (Console)".

# Notes on Trophy-Related Debug Support Features

Note:

If you encounter a problem that isn't described below, contact us via "Post new issue" of Private support (<https://game.develop.playstation.net/support/>).

## Trophy Viewing Restrictions on a Development Kit/Testing Kit

In Online Mode, trophy data for titles that meet both of the following conditions cannot be viewed:

* The user does not have Title Dev/Title Admin privileges
* The application is not running

For details, refer to [PlayStation™Network Overview - Reference Information - Features Restricted by Title Dev/Title Admin Roles During Development](../PSN-Overview/features-restricted-by-title-dev-title-admin-roles-during-de.html).

**When the WS-119703-1 Error Code "Something went wrong." Occurs**

When an attempt is made to synchronize trophy records by selecting "Sync with PlayStation Network" from the Options menu on the "Trophies" screen of the system software in a state where one or more titles that meet both the above conditions exist, the WS-119703-1 error code sometimes occurs and "Something went wrong." is displayed.

In such cases, grant the user with Title Dev/Title Admin privileges for all titles for which trophy records exist. Alternatively, if there is only one title for which the user does not have Title Dev/Title Admin privileges, the problem can be resolved by running that application.

## Inconsistencies Displayed on the Console That May Occur When Trophy Configuration Data Has Been Changed

When trophy configuration data is changed using the UDS Management Tool, inconsistencies may arise between the trophy data on the server and the trophy data on the console, resulting in incorrect data being displayed. To avoid such inconsistencies, it is recommended that you delete the trophy records and UDS Stats data from the server and console after changing the trophy configuration data.

## Displaying Trophy Sets for PlayStation®4

On a Development Kit/Testing Kit, trophy sets for PlayStation®4 titles can only be viewed in Offline Mode. They cannot be viewed in Online Mode, and the Preview Trophy UI is not available.

To display trophies for PlayStation®4 titles, check individual trophies by locking and unlocking them in Offline Mode. You can also use this method to test the behavior of the title in states with trophies either locked or unlocked. To unlock a trophy, select the trophy that you want to unlock, and choose "★Unlock" from the options menu. If you want to return a trophy to the locked state, select the trophy and choose "★Lock" from the options menu.

Note that it is not possible to lock or unlock platinum trophies directly. Platinum trophies are locked and unlocked automatically by the system when all trophies with the platinum link attribute are locked or unlocked.

It is also possible to unlock all trophies included in a specific trophy set or trophy group in one go. Select the trophy set or trophy group that you want to unlock all at once and choose "★Unlock All" from the options menu.
