Source: https://game.develop.playstation.net/resources/documents/SDK/12.000/PlayStation_Network/PlayStation_Network_Landing.html

### PlayStation(TM)Network

* #### Category Overview

  + [PlayStation™Network Overview](../PSN-Overview/__document_toc.html)

  #### Summary

  This category contains documentation for the PlayStation™Network Web APIs and client SDK libraries.

  The Web APIs are a collection of REST APIs that implement a wide range of PlayStation™Network features, such as the Universal Data System, In-Game Catalogs, Session Manager, and so on.

  The NpCppWebApi and NpWebApi2 libraries are part of the SDK. The NpWebApi2 library is required for accessing PlayStation™Network Web APIs from PlayStation®5, and the NpCppWebApi library provides a C++ language binding for features of the PlayStation™Network Web APIs.

  #### Related Information

  For information on basic networking features (such as HTTP, SSL, and RUDP), and network functionality that does not rely on the PlayStation™Network (such as Remote Play and Share Play), see the Network category.

  For restrictions and other notes on cross-generation PlayStation™Network APIs that work on both PlayStation®4 and PlayStation®5, see the PlayStation®4 Cross-Generation SDK > PlayStation™Network sub-category.
