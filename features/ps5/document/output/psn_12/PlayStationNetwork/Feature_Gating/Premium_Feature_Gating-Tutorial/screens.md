This chapter provides an overview of how the tutorial game application is designed.

# Tutorial Application Screens

This topic lists and describes the different screens available in the tutorial game application.

The tutorial game consists of the following screens.

## Menu

This is the first screen that is displayed on launch. From this screen the player can start a multiplayer game as well as toggling Cross Platform Play On and Off.

Menu

## Check Feature

This screen triggers the premium check for all users and upsells the subscription for any unauthorized user.

Check Feature

## Upsell Screen

This screen displays the upsell option for any unauthorized user.

Upsell Screen

## Message Screen

The Message screen is displayed when one or more users fail to pass the feature check.

Message Screen

## Online Multiplayer Screen

This screen is displayed when all users pass the feature check. From this screen the user can toggle each user between Playing or Spectating.

Online Multiplayer Screen
