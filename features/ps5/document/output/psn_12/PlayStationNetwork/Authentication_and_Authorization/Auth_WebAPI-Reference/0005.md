# getAccessTokenWithAuthorizationCode

Get an access token using an authorization code

### Description

Get an access token using an authorization code obtained from NpAuth library or PlayStation™Network authorization server in the case of authentication for Websites.

**Examples:**

**Example 1: Get an access token using an authorization code**

```
curl -X POST \
    -H "Authorization: Basic {base64encode({clientId} + ':' + {clientSecret})}" \
    'https://s2s.sp-int.playstation.net/api/authz/v3/oauth/token' \
    --data-urlencode "grant_type=authorization_code" \
    --data-urlencode "redirect_uri={redirectUri}" \
    --data-urlencode "code={authorizationCode}"
```

# refreshAccessToken

Refresh an access token

### Description

Get an access token using a refresh token. The client must authenticate to the server using client id and client secret and the refresh token must be one issued to the same client.

A new refresh token may be issued in the token response, in which case the client must discard the old refresh token and replace it with the new refresh token. The authorization server will revoke the old refresh token after issuing a new refresh token to the client. When a new refresh token is issued, it will have identical scope to that of the refresh token in the refresh request.

**Examples:**

**Example 1: Refresh an access token**

```
curl -X POST \
    -H "Authorization: Basic {base64encode({clientId} + ':' + {clientSecret})}" \
    'https://s2s.sp-int.playstation.net/api/authz/v3/oauth/token' \
    --data-urlencode "grant_type=refresh_token" \
    --data-urlencode "refresh_token={refreshToken}" \
    --data-urlencode "scope=psn:s2s"
```

**Response**

```
HTTP/1.1 200 OK
Content-Type:"application/json;charset=UTF-8"
Cache-Control:"no-store"
...

{
    "access_token": "2b6d6d8d-622d-4392-a33a-5874a83c7463",
    "refresh_token": "{currentOrNewRefreshToken}",
    "token_type": "bearer",
    "expires_in": 1199,
    "scope": "psn:s2s"
}
```
