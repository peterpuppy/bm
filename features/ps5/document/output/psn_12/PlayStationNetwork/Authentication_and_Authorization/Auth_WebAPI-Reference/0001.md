# Auth Web API Reference Summary

The Auth Web API is an OAuth 2.0 framework implementation that licensee application servers, websites, and back office servers use to obtain authorization for accessing user information (such as friends lists or trophies) managed on PlayStation™Network servers. It also provides integration to PlayStation™Network user authentication and ID tokens that contain user and authentication information.

### Base URLs

### PlayStation®5 Applications

PlayStation®5 applications must not use Auth Web API directly. Please refer to the [NpAuth Library Overview](../../../SDK/latest/NpAuth-Overview/__document_toc.html) document.

### Application Servers or Back Office Servers

The base URL to specify for application servers and back office servers depends on whether the client-side application uses the Sandbox network architecture or Legacy network architecture.  
(Refer to [Sandbox Network Architecture Guide](../../../SDK/latest/Sandbox_Network_Architecture-Guide/__document_toc.html) for details about Sandbox. Also refer to this technote regarding migration to Sandbox: <https://game.develop.playstation.net/technotes/view/740>. )

Specify the following base URL if the client-side application uses Sandbox:

* https://s2s.np.playstation.net/api/authz

Specify the base URL of the applicable environment indicated below if the client-side application uses Legacy:

* Development environment (sp-int): https://s2s.sp-int.playstation.net/api/authz
* Certification environment (prod-qa): https://s2s.prod-qa.playstation.net/api/authz
* Production environment (RETAIL): https://s2s.np.playstation.net/api/authz

For the purpose of maintaining backward compatibility, the above base URLs for Legacy can also be specified for application servers and back office servers that have migrated to Sandbox. For application servers and back office servers that serve traffic in both the Sandbox and Legacy network architectures, specify the base URL for Sandbox regarding Sandbox requests and specify the base URLs for Legacy regarding Legacy requests.

### Authentication

Refer to [Auth Web API Overview](../Auth_WebAPI-Overview/__document_toc.html) to see the process flows for providing access privileges to an application server or back office server. To obtain an access token using the Auth Web API, you will need to provide a Client ID and Client Secret. The Client ID and Client Secret are issued upon requesting the "Client ID" service. For information about requesting the "Client ID" service, see the [PlayStation™Network Service Setup Guide](../../../SDK/latest/PSN_Service_Setup-Guide/__document_toc.html).
