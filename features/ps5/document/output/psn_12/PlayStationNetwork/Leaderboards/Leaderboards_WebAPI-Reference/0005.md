# getLargeDataByObjectId

Obtains large-volume attachment data

### Description

This request obtains the large-volume attachment data specified with objectId.

By specifying a Range request header, you can obtain a part of the large-volume attachment data. Range: Specify the range you intend to obtain in the following format: bytes={Start Position}-{End Position}. Other description formats and the specification of multiple ranges at once are not supported. By changing Range as you call the request described in this section multiple times, you can receive large-volume attached data in parts over multiple transmissions.

When receiving parts of data over multiple transmissions, you can specify the ETag obtained as the response from the first transmission received in the If-Match headers when receiving the second and subsequent parts. The ETag value will be modified along with any updates to the large-volume attachment data. If you specify the ETag value in the If-Match headers, you will then be able to receive Error (416) if there is any change to the data while receiving it split over multiple transfers.

The *objectId* can always be obtained when [recordLargeData](0003.html) is used to recored large-volume attachment data. Additionally, ranking information can be obtained along with the *objectId* using [getRanking](0005.html). Therefore, there is no need for the user who is recording the data to remember the *objectId*.

**Example Request**

```
GET leaderboardsBaseUrl/v1/apps/myApp/objects/046b6c7f-0b8a-43b9-b35d-6489e6daee91/largeData
```

**Example Response**

```
Content-Type:application/octet-stream

XXXXXXXXXXXXXXXXX(Binary Data)
```

# getRanking

Obtains ranking data

### Description

This request obtains official ranking data from the leaderboard specified with *boardId*. Comments relating to the scores (*comment*), small-volume attachment data (*smallData*), and IDs for obtaining large-volume attachment data (*objectId*) can be obtained at the same time. Both rankings where if multiple players have the same number of points, the player who scored first is ranked ahead (*serialRank*) and rankings where all players with the same number of points are tied (*rank*) can be obtained. You can also obtain date and time information concerning when the rankings were calculated and the total number of scores on the specified leaderboard. The date and time when scores were recorded (*recordedDateTime*) can be obtained by specifying *needsRecordedDateTime*=true.

Ranking data displaying various aspects of all the data available can be obtained, as shown below:

1. If there are no particular specifications, obtain the scores from first place down through the *limit*
2. Obtain the scores of multiple users (*users*) specified with account IDs (*accountId*) and player character IDs (*pcId*)  
   In this case, the current user can be specified as *accountId*=me
3. Obtain *limit* instances of score data, targeting only friends, by specifying *group*=friends
4. Obtain *centerToEdgeLimit*-number of scores ranked (where the player who scored first is ranked higher if there is a tie in terms of points) above and below the ranking of the user (*userCenteredAround*) specified by their account ID (*accountId*) and player character ID (*pcId*).  
   In this case, the current user can be specified as *accountId*=me  
   When used in combination with *group*=friends, among the current user's friends' rankings, *centerToEdgeLimit*-number of scores above and below the ranking of the specified user can be obtained.

Be aware that if *group*=friends is specified, only the scores of users whose player character ID (*pcId*) is 0 will be subject to being obtained.

Note that when *userCenteredAround* is specified, *centerToEdgeLimit* must be specified; in addition, an error will occur if *limit* or *startSerialRank* is specified.

**How to specify the range of ranking information to obtain (for example 1 to 3)**

For the above 1 to 3 examples, ranking information can be extracted and obtained by using the *offset*, *limit*, and *startSerialRank* parameters. You can specify from which ranking (where the player who scored first is ranked higher if players are tied in terms of points) to start obtaining results using *startSerialRank*. If nothing is specified, the default is 1. You can specify the number of scores to obtain using *limit*. You can specify from which score, out of the range of scores that starts with the score specified with *startSerialRank*, to include in the scores to extract using *offset*. The lowest possible value and default for *offset* is 0.

A few examples are given below: Also refer to the example request and example responses a to c.

1. If *startSerialRank*=1, *offset*=0, and *limit*=10 (all values set to their defaults), ranking data from 1st place through 10th place will be returned.
2. If *startSerialRank*=1, *offset*=10, and *limit*=20, ranking data from 11th place through 30th place will be returned.
3. If *startSerialRank*=5, *offset*=10, and *limit*=10, ranking data from 15th place through 24th place will be returned.

**How to specify the range of ranking information to obtain (for example 4)**

For the above example 4, ranking information can be extracted and obtained by using the *offset* and *centerToEdgeLimit* parameters. Centered around the ranking of the user specified in *userCenteredAround*, specify the number of scores above and below that ranking (where the player who scored first is ranked higher if players are tied in terms of points) to obtain using *centerToEdgeLimit*. Starting from the ranking of the user specified in *userCenteredAround*, you can specify from which score to extract *centerToEdgeLimit*-number of scores (above and below the specified user's ranking) using *offset*. The lowest possible value and default for *offset* is 0.

Examples are given below for when the ranking of *userCenteredAround* is 11th place. Also refer to the example requests and example responses d to e.

4. If *offset*=0, *centerToEdgeLimit*=10, ranking information from 1st place to 21st place will be returned.
5. If *offset*=10, *centerToEdgeLimit*=10, ranking information from 11th place to 31st place will be returned.
