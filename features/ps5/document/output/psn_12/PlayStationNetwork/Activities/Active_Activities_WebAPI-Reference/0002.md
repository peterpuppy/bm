# Activity

# getUserActivities

Obtain a list of activities for each user

### Description

**Example Request**

```
GET {baseUrl}/v1/users/activities?accountIds=1234567891,1234567892,1234567893&limit=3
```

**Example Response**

```

        },

        },
```

### Request

```
GET /v1/users/activities
```

### Query Parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| npServiceLabel | **integer(int32)** | false | NP service label  **Min Value:** 0  **Default Value:** 0 |
| accountIds | **array[string]** | true | List of account IDs  **Min Items:** 1  **Max Items:** 100 |
| limit | **integer(int32)** | false | Maximum number of activities that can be obtained for any one user  **Min Value:** 1  **Max Value:** 10  **Default Value:** 1 |

### Header Parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| Accept-Language | **string** | false | For the language codes that can be specified, refer to the "Supported Languages and Language Codes" section of the [PlayStation™Network Web APIs Overview](../../../SDK/latest/PSN_WebAPI-Overview/__document_toc.html) document. |

### Status Code 200

### Response Body

**Content-Type:**application/json

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| » users | **array[object]** | true | List of active activities for each user  **Min Items:** 0 |
| »» accountId | **string** | true | Account ID of the user  **Min Length:** 1 |
| »» activities | **array[object]** | true | List of activities  Activities are sorted with the following priority:  - Activities that use matches  - Activities necessary to completing the main campaign  - Activities whose update dates and times are more recent  **Min Items:** 0 |
| »»» activityId | **string** | true | Activity ID  **Min Length:** 1  **Max Length:** 32 |
| »»» name | **string** | true | Activity name  **Min Length:** 1  **Max Length:** 128 |
| »»» hidden | **boolean** | true | Whether to apply Spoiler Block to the activity |
| »»» matchId | **string** | false | Match ID  Returned if the activity uses matches.  **RegEx Pattern:** "^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$" |
