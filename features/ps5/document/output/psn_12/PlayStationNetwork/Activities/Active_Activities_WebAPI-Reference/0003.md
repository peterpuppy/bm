# Error Codes

# Error Codes

| Code (Decimal) | Code (Hex) | Message | Description |
| --- | --- | --- | --- |
| 2351105 | 23E001 | Bad request ('reason') | The request is invalid (the parameters section of the URL is invalid, the query parameters are invalid, required query parameters are absent, the body is too long, etc.) |
| 2351117 | 23E00D | Resource not found ('reason') | The requested resource could not be found (the specified user or title does not exist, the client ID of the access token is incorrect, etc.) |
| 2351118 | 23E00E | Not permitted by access control | Access was denied (not the resource owner, resource of another title, because of privacy settings, etc.) |
| 2351235 | 23E083 | Forbidden | Access denied (details unknown) |
| 2351236 | 23E084 | Not Found | URL is invalid (an unsupported API version was specified, etc.) |
| 2351261 | 23E09D | Too Many Requests | The rate limit for requests has been exceeded |
| 2351616 | 23E200 | Authentication required | An access token has not been specified |
| 2351617 | 23E201 | Invalid token | The specified access token has an invalid value or is corrupted |
| 2351622 | 23E206 | Insufficient scope | The scope is invalid (authorization has not been received, the method of obtaining an access token was incorrect, a parameter that cannot be used with this platform was specified, etc.) |
| 2351630 | 23E20E | Online ID required | Account must be upgraded |
| 2351747 | 23E283 | Service not configured | Service configuration has not been performed for the title (processing of a request for the service is still underway, etc.) |
| 2351756 | 23E28C | Expired token | Access token is expired |
| 2351757 | 23E28D | Np Environment not matched | Environment name is invalid |
| 2352000 | 23E380 | Internal server error | An unexpected error occurred on the server |
| 2352003 | 23E383 | Service Unavailable | The service cannot be accessed (the server is under maintenance, the server is overloaded, the service has been discontinued, there is an error in the authentication or authentication server, etc.) |
