# Configuring Activities for User Generated Content

This topic provides guidance on creating activities for user generated content

As activities are defined based on the design of your game, SIE does not support or recommend the programmatic creation of activities based on user generated content. Additionally, there is a limit of 2560 PlayStation™Network Objects (activities, tasks, and sub-tasks) that you can create per game, which you can’t delete after they are published.

Instead, SIE recommends that you [follow the general guidance for repeatable game modes to create an activity that represents a generic community level/mode that is displayed to players when they engage in user generated content](configuring-repeatable-or-endless-modes.html "This chapter provides guidance on configuring activities for games that feature repeatable or endless modes.").

If you want to configure activities for specific user generated content, [create a custom activity that represents the specific levels or modes you want to promote using the guidance that most applied to the design of the content](configuring-activities-based-on-game-structure.html "This chapter provides on overview on how to maximize the potential of PlayStation™Network Activities by creating them based on how you've designed your game.").
