# Kernel Overview – SDK 12.000

Source: https://game.develop.playstation.net/resources/documents/SDK/12.000/Kernel-Overview/scope.html

# About This Document

# Purpose

This document is a manual that provides a comprehensive explanation of the kernel features. It includes information such as an overview of the features provided by the PlayStation®5 kernel and typical usage procedures/notes for the kernel API.

# Scope

This document explains how to use the kernel API but does not cover all interface features. Also, since this document mainly focuses on explaining the usage, it will not provide detailed specifications of each interface feature unless necessary. Refer to [Kernel Reference](../Kernel-Reference/__document_toc.html) for the detailed specifications of each interface feature.

It is assumed that the reader of this document is familiar with general programming concepts and methods such as processes, threads, and mutexes.
