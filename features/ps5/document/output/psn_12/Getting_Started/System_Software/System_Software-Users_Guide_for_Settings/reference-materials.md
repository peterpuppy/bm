# About This Document

This topic provides an overview and the reference materials of the [System Software User's Guide (Settings)](__document_toc.html) document.

This document provides an explanation for game developers regarding the "Settings" application of the system software on Development Kits ("DevKits") and Testing Kits ("TestKits"). The "Settings" application also provides features for end users; cases where game developers will use these features, as well as how information set by end users can be obtained and used in games, are explained in this document.

Refer to the [System Software User's Guide (Application Development Support)](../System_Software-Users_Guide_for_Development_Support/__document_toc.html) document for an explanation on development support features provided by the system software in addition to the "Settings" application.

Note:

DevKits and TestKits are collectively referred to as "development machines" in this document where there is no need to distinguish between the two.
