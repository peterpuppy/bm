# Application Development Support Features

The system software of the Development Kit ("DevKit" hereafter) and Testing Kit ("TestKit" hereafter) provides various features; from among them, this document explains the various features that support application development. For each feature of "Settings" > "★Debug Settings", refer to the [System Software User's Guide (Settings)](../System_Software-Users_Guide_for_Settings/__document_toc.html) document.

Note:

The DevKit and TestKit are collectively referred to as "development machine" in this document where there is no need to distinguish between the two.
