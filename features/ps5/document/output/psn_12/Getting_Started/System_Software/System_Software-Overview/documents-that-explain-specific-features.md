# System Software Documents

# Handling of the System Software in SDK Documents

SDK documents do not fully explain each software comprising the system software. This is because from a software engineering perspective, the system software is designed and implemented so that it is separate and concealed from applications; on the other hand, the purpose of SDK documents is to explain what is required for application development and execution.

# Documents That Explain Specific Features

Of the various system software features, the documents below explain the features that change and configure Development Kit or Testing Kit behavior and features that are used for developing applications.
