# 提示框（message box）手柄确认键无响应

## 结论

**PS5（及所有手柄场景）下 `html_scr_message_box_ui` 从未注册手柄确认键 `"x"`，
只有键盘 `"space"`。** 手柄按 X 时输入系统查映射表，message_box 不认 `"x"`，
事件被丢弃 —— 表现为"提示框按什么键都没用"。

## 证据

`_source/_scripts/client/input/chaos_input_system_ui_callbacks.lua`：

```lua
insert_ui_shortcut_map(STRING_ID("html_scr_ask_box_ui"),    STRING_ID("space"), STRING_ID("x")); -- 有 x
insert_ui_shortcut_map(STRING_ID("html_scr_message_box_ui"), STRING_ID("space"));                -- 只有 space
insert_ui_shortcut_map(STRING_ID("html_scr_shop_quartermaster_ui"), "z", "c", "space", "x");    -- 有 x
insert_ui_shortcut_map(STRING_ID("html_scr_esc_menu_main_ui"), "r", "g", "t", "x");             -- 有 x
```

**先例**：2026-08-13 `beb262253c` 给 ask_box 修过一模一样的问题（补 `"x"`），
message_box 是漏网之鱼。`:109` 已注册 `x` 的 action callback，修复只需加映射。

## 修复

```lua
insert_ui_shortcut_map(STRING_ID("html_scr_message_box_ui"), STRING_ID("space"), STRING_ID("x"));
```

同类隐患（同样只有 space，未修）：`reward_box`、`slot_box`、`battle_pass_purchase_exp` 等 ——
建议批量排查。

## 为什么登录时代"验证过"却没发现

登录功能 DevKit 验证走的是**真实用户 happy path**（SigninDialog 秒过 → 进游戏），
不经过 guest→取消→提示框支线。该支线从未被手柄验证过。

## 排查过程教训

症状"按什么键都没用"曾被过度解读为"手柄输入整体失效"，走了 LoginService/
pad 归属/OIS 等弯路。实际登录页上唯一可交互元素就是这个提示框 —— 单个控件
没绑键 = 看起来"全部失效"。**先确认"哪些控件应该响应、各自输入通路"再下结论。**
