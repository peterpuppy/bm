# In-Game Catalog Web API Reference – WebAPI 1

Source: https://game.develop.playstation.net/resources/documents/WebAPI/1/In_Game_Catalog_WebAPI-Reference/0002.html

# Containers

# getContainer

Get a list of in-game catalog containers

### Description

Returns the in-game catalog root category container and a list of its children containers. The default size of a list is 20 containers.

You can also return a list of specific containers and their children by specifying a containerID. You can specify multiple containerID labels using a colon-separated list. For example, PSALCATEGORY:PSVCCATEGORY.

**Examples**

**Example 1: Get an in-game root category container**

```
curl -X GET 'https://s2s.playstation.net/api/inGameCatalog/v5/container?serviceLabel=0' -H "Content-type:application/json" -H "Authorization: Bearer {Bearer}"
```

| Client | Usable / Not Usable |

| Application server | Usable |

### Request

```
GET /v5/container
```

### Query Parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| containerIds | **string** | false | Colon separated list of containerID labels. For example, PSALCATEGORY:PSVCCATEGORY. |
| offset | **integer(int32)** | false | The starting index value. |
| keepHtmlTag | **boolean** | false | Flag that determines whether to keep or remove HTML from the description. |
| limit | **integer(int32)** | false | The maximum number of results to return. |
| direction | **string** | false | Manner in which results are sorted.  **Possible Values:**  - asc  - desc  **Default Value:** asc |
| sort | **string** | false | The field in which results are sorted by.  **Possible Values:**  - name  - price  - release\_date |
| serviceLabel | **integer** | false | The NP service label.  **Default Value:** 0 |
| serviceName | **string** | false | The ASM Service Name to get linked services from.  **Possible Values:**  - pssdc  - cce  **Default Value:** pssdc |
| useFree | **boolean** | false | Flag to determine whether to use a 'free' text string to represent zero dollar purchases. |
| useCurrencySymbol | **boolean** | false | Use a currency symbol to format SKU display pricing. |

### Header Parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| Accept-Language | **string** | false | Accept Language header. |
| Authorization | **string** | true | Authorization Header for passing in an access token. |
| X-Psn-Trc-Check-IGC | **string** | false | Test various conditions such as an empty store, product discounts, and placeholder SKU and metadata values when calling the In-Game Catalog Web API from the application server.  **Possible Values:**  - FakeSkuAndMetadata  - EmptyStore  - RegularAndPlusBonusDiscountForNonPlus  - PlusDiscountForNonPlus  - PlusDiscountForPlus  - RegularDiscount  - PartnerDiscountForSubscriber  - PartnerDiscountForNonSubscriber  - Off |

| Status | Meaning | Description |

| 200 | [OK](https://tools.ietf.org/html/rfc7231#section-6.3.1) | Returns a list of in-game catalog containers. |
| 400 | [Bad Request](https://tools.ietf.org/html/rfc7231#section-6.5.1) | Error. |
