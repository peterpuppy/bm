# Closed Accounts

# queryClosedAccounts

Get closed account events within a time period

### Description

Given a set of date-times, returns a list of all closed accounts from that period. On receiving an account closure record you must comply with applicable legal requirements once aware that an account is closed.

**Examples:**

These examples show a series of requests to get a list of closed account records. The first example shows a request that specifies no dates, with subsequent requests using the pageToken parameter. The second example shows the use of after and before dates to query a specific time frame. Additionally, a limit per request is set.

On the first run of the API, you should specify a request like Example 1 with no date filtering. In the following examples, pageToken has invalid dummy values used for illustrative purposes only.

### Query Parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| limit | **integer** | false | Limits the number of elements in the response. Valid values are 1 to 1000. If the amount of records returned is equal to the limit, retrieve another set of records. Since the platform typically closes more than 100 accounts in a day, the recommendation is to use 1000 for this value.  **Min Value:** 1  **Max Value:** 1000  **Default Value:** 100 |
| after | **string** | false | The beginning date-time from which to start reporting closed accounts. Not specifying this value returns the oldest closed accounts starting from up to one year in the past. This value is in ISO-8601 extended offset date-time format and must be URL encoded. This value is inclusive.  **Max Length:** 50 |
| before | **string** | false | The end date-time at which to stop reporting closed accounts. Not specifying this value means the before date is the current time. This value is in ISO-8601 extended offset date-time format and must be URL encoded. This value is inclusive.  **Max Length:** 50 |
| pageToken | **string** | false | Token used to specify the next set of results. The pageToken is not required for an initial request, but is required for subsequent requests of closed accounts. Do not modify nor URL encode this value. The max length of this value is 80. Do not use this token for any other purpose. If this value is specified along with after and before, pageToken overrides the date values and they are ignored.  **Max Length:** 80 |
