# Account Closure Web API Reference Summary

Provides closed accounts information.

**Call Rate Limits**

It is recommended that the call rates are kept within the following ranges. Note that there is a possibility of rate limits changing without notice. Use the following information as a reference only.

| Request | Recommended Call Rate |
| --- | --- |
| queryClosedAccounts | Within 1 time/1 day |

The recommended call rate of one call per day is not a hard limit. If you are making daily requests to this API, aim to make between one and five requests per day to stay within rate limits. Keep in mind that, although there are spikes at certain times, SIE does not expect this service to return more than 1000 accounts per day. Most of the time, one call should be sufficient to properly utilize this API.

For more information, see the limit query parameter of [queryClosedAccounts](0002.html).
