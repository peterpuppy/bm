# Friends

# GetFriends

Obtains a friend list

### Description

This request obtains the friend list of the target user. Be aware that you may be unable to obtain the friend list, depending on the target user's privacy settings.

**Response Example**

```
{
  "friends": [
    "1111",
    "2222",
    "3333",
    ...
  ],
  "totalItemCount": 50,
  "nextOffset": 20,
  "previousOffset": 10
}
```

### Use Restrictions

| Client | Usable / Not Usable |
| --- | --- |

| Application server | Usable |
| Application server (client credential) | Not Usable |
| Authorized App Server | Usable |

### Request

```
GET /v1/users/{accountId_or_me}/friends
```

### URI Parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| accountId\_or\_me | **string** | true | Account ID of the target user or me that indicates the current user  **RegEx Pattern:** "^[1-9][0-9]{2,18}$|^me$" |

### Query Parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| offset | **integer(int32)** | false | Relative position from start of list  **Min Value:** 0  **Default Value:** 0 |
| limit | **integer(int32)** | false | Maximum number of items with which to respond at once  **Min Value:** 0  **Max Value:** 2000  **Default Value:** 100 |
| filter | **string** | false | Filter when obtaining a friend list. For example, you can obtain only those friends who are online.  This parameter is optional; if nothing is specified, all friends will be returned.  **Possible Values:**  - online |
| order | **string** | false | Specification of the sort order for friend obtainment  Online IDs will be sorted in the dirctionary order (case-insensitive) when onlineId is specified.  A list of online friends and then a list of offline friends will be the sort order when onlineStatus is specified.  A list of online friends (sorted by Online IDs) and then a list of offline friends (sorted by Online IDs) will be the sort order when onlineStatus+onlineId is specified.  The order of the returned friend lists will be arbitrary if this parameter is not specified.  **Possible Values:**  - onlineId  - onlineStatus  - onlineStatus+onlineId |
