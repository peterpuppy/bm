# Error Codes

| Code (Decimal) | Code (Hex) | Message | Description |
| --- | --- | --- | --- |
| 2281473 | 22D001 | Bad request ('reason') | Request is invalid (a URL parameter is invalid, a query parameter is invalid, a required query parameter is not present, the body is too long, etc.) |
| 2281485 | 22D00D | Resource not found ('reason') | Requested resource could not be found (the specified user or title does not exist, the client ID of the access token is incorrect, etc.) |
| 2281486 | 22D00E | Not permitted by access control | Access was refused (not the resource owner, the resources are those of another title, because of privacy settings, etc.) |
| 2281600 | 22D080 | Bad Request | Invalid request parameter |
| 2281603 | 22D083 | Forbidden | Access was refused (details unknown) |
| 2281604 | 22D084 | Not Found | URL is invalid (an unsupported API version was specified, etc.) |
| 2281629 | 22D09D | Too Many Requests | Request rate limit was exceeded |
| 2281984 | 22D200 | Authentication required | An access token has not been specified |
| 2281985 | 22D201 | Invalid token | The specified access token has an invalid value or is corrupted |
| 2281990 | 22D206 | Insufficient scope | Scope is invalid (authorization has not been obtained, the access token was obtained incorrectly, a parameter that cannot be used with this platform was specified, etc.) |
| 2281998 | 22D20E | Online ID required | Account must be upgraded |
| 2282124 | 22D28C | Expired token | Access token is expired |
| 2282125 | 22D28D | Np Environment not matched | Environment name is invalid |
| 2282368 | 22D380 | Internal server error | Unexpected server-side error occurred |
| 2282371 | 22D383 | Service Unavailable | Service is unavailable (the server is under maintenance, the server is experiencing excessive load, the service has been terminated, authentication/authorization server error, etc.) |
