# Push Notification

# Online status presence update event

Push event sent when there is an online status update

### Description

This Push event is sent when online status, part of presence information, is updated.

Online status is also updated when the user modifies his or her Appear Offline settings, and thus this Push event will be sent. However, no Push event will be sent if Appear Offline settings are modified while offline, or if there is a change in online status while Appear Offline settings are enabled.

### Datatype

```
np:service:presence2:onlineStatus
```

### NP Service Name Required for Receiving

No

### Order Guaranteed

No

### Event Content

### from: Information about a user who modified his or her online status

| Property | Type | Required | Description |
| --- | --- | --- | --- |
| accountId | **string** | true | Account ID  **RegEx Pattern:** "^[1-9][0-9]{2,18}$" |
| onlineId | **string** | true | Online ID  **RegEx Pattern:** "^[a-zA-Z][a-zA-Z0-9-\_]{2,15}$" |

### to: Information about the user who received the notification of a change of online status

| Property | Type | Required | Description |
| --- | --- | --- | --- |
| accountId | **string** | true | Account ID  **RegEx Pattern:** "^[1-9][0-9]{2,18}$" |
| onlineId | **string** | true | Online ID  **RegEx Pattern:** "^[a-zA-Z][a-zA-Z0-9-\_]{2,15}$" |

### data: (Not defined for this Push event)

### extended data: (Not defined for this Push event)

# Presence inContext information update event

Push event sent when presence inContext information is updated

### Description

This Push event is sent when *inContext* that is contained in presence information is updated. The status after the update can be checked using [GetBasicPresences](0002.html).

inContext information is also updated when a user modifies his or her Appear Offline settings, and thus this Push event will be sent. However, users are treated as though they are offline when Appear Offline settings are enabled; therefore, a Push event will not be sent when that setting has been turned on.

During development, this Push event will not be sent to users who are using an environment (DEV or CERT) of the Sandbox network architecture that differs with the environment being used by the current user. (Refer to [Sandbox Network Architecture Guide](../../../SDK/latest/Sandbox_Network_Architecture-Guide/__document_toc.html) for details about Sandbox.)

Regardless of the privacy setting ("Hide your games from other players") for the game, this Push event will be sent to friends who aren't offline (online or standby)

Note a request to use the Presence 2 service must be submitted to obtain this Push event.

### Datatype

```
np:service:presence2:contextChanged
```

### NP Service Name Required for Receiving

presence2

### Order Guaranteed

No

### Event Content

### from: Information about a user who modified presence inContext information

| Property | Type | Required | Description |
| --- | --- | --- | --- |
| accountId | **string** | true | Account ID  **RegEx Pattern:** "^[1-9][0-9]{2,18}$" |
| onlineId | **string** | true | Online ID  **RegEx Pattern:** "^[a-zA-Z][a-zA-Z0-9-\_]{2,15}$" |

### to: Information about a user who received notification of a change to presence inContext information

| Property | Type | Required | Description |
| --- | --- | --- | --- |
| accountId | **string** | true | Account ID  **RegEx Pattern:** "^[1-9][0-9]{2,18}$" |
| onlineId | **string** | true | Online ID  **RegEx Pattern:** "^[a-zA-Z][a-zA-Z0-9-\_]{2,15}$" |

### data: (Not defined for this Push event)

### extended data: (Not defined for this Push event)

# Friend update event

Push event sent when there is an update to a friend list

### Description

This push event is sent when a friend is added to, or deleted from, the current user's friend list.

### Datatype

```
np:service:friendlist:friend
```

### NP Service Name Required for Receiving

No

### Order Guaranteed

No

### Event Content

### from: (Not defined for this Push event)

### to: Information about the current user

| Property | Type | Required | Description |
| --- | --- | --- | --- |
| accountId | **string** | true | Account ID  **RegEx Pattern:** "^[1-9][0-9]{2,18}$" |
| onlineId | **string** | true | Online ID  **RegEx Pattern:** "^[a-zA-Z][a-zA-Z0-9-\_]{2,15}$" |

### data: (Not defined for this Push event)

### extended data:

### Extended Data Key

additionalTrigger

### Extended Data Value

```
{
  "friendAccountId": "1234",
  "event": "add"
}
```

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| » friendAccountId | **string** | false | Information about the friend who was added to, or deleted from, a friend list  **RegEx Pattern:** "^[1-9][0-9]{2,18}$" |
| » event | **string** | false | If added, then add; if deleted, then remove  **Possible Values:**  - add  - remove |
