# Presence

# GetBasicPresences

Obtains presence information

### Description

You can obtain the presence information for multiple users (including the current user).

**Order**

The order in which presence information will be returned in response to this request follows the order in which *accountId* specifications are made.

**Appear Offline Settings**

If the target users have enabled the Appear Offline setting, presence information indicating that those users are offline will be obtained.

**Presence Information Privacy Settings**

Each user can select one of the following options as the scope for publicly releasing his or her presence information.

* Release only to friends
* Release to friends of friends
* Release to everyone

With this request, the current user will obtain presence information as long as he or she is included in the scope for releasing presence information of the target user.

**inContext**

*inContext* indicates whether the current user and the target user are playing a game with the same NP communication ID.

* Even if the target user is playing a game with the same NP communication ID, false will be returned if the target user has the privacy setting ("Hide your games from other players") on for that game.
* During development, even if the target user is playing a game with the same NP communication ID, false will be returned if the environment (DEV or CERT) of the Sandbox network architecture that is being used by the target user differs from the environment being used by the current user. (Refer to [Sandbox Network Architecture Guide](../../../SDK/latest/Sandbox_Network_Architecture-Guide/__document_toc.html) for details about Sandbox.)
* When the same *accountId* as the current user is specified for the target user, *inContext* information of that *accountId* will be returned regardless of the privacy setting for the game.

**Response Example**

```
{
  "basicPresences": [
    {
      "onlineStatus": "online",
      "inContext": true,
      "accountId": "1111"
    },
    {
      "onlineStatus": "online",
      "inContext": true,
      "accountId": "2222"
    },
    {
      "onlineStatus": "offline",
      "inContext": false,
      "accountId": "3333"
    }
  ]
}
```

### Request

```
GET /v1/users/basicPresences
```

### Query Parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| accountIds | **string** | true | Account IDs of users targeted for obtaining resources.  If specifying multiple users, separate account IDs with commas but without inserting spaces.  The maximum number of account IDs that can be specified at once is 100 (based on restrictions on URL length).  400 Bad Request will be returned when over 100 account IDs are specified. |
