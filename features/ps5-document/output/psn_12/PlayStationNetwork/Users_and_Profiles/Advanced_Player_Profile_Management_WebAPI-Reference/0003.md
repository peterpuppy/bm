# Fake Stats

# getFakeStats

Get fake stats

### Description

This request is usable in the development environment only. It retrieves the fake data sorted in ascending alphabetic order.

SIE deprecated the Multiplayer Matchmaking Ranking feature, as well as the mmr parameter and its children, perFranchise and perGenre.

* If fake data is registered, the request returns the fake data.
* If fake data is not registered and the value of includeFields is set to bandwidth, frequentlyMuted, matchCompletionRate, natConnectivity, or playStyle, the request returns responses with 0 as values.
* If fake data is not registered and the value of includeFields is set to connectionQuality, the request returns most responses with 0 as values (jitter response with 0.0 as value).
* If the value of includeFields is set to empty, includeFields, or is not specified, the request returns an empty JSON response ({}).
* If the value of includeFields is set to reputation, regardless of what fake data is stored, the request returns responses with 0 as values.
* If the value of includeFields is set to mmr, the request always returns a response with a value of -1.

**Examples:**

**Example 1: Get advanced player profile fake stats for a user if fake data is registered:**

```
curl -H 'Authorization: Bearer ${Bearer}' 'https://s2s.sp-int.playstation.net/api/advancedPlayerProfile/v1/users/1234/stats/fakes?npServiceLabel=0&includeFields=bandwidth(global)'
```

**Response:**

```
{
 "bandwidth": {
  "global": {
   "downstream": {
    "average": 14,
    "confidenceScore": 15,
    "standardDeviation": 16
   },
   "upstream": {
    "average": 17,

   }
  }
 }
}
```

**Example 2: Get advanced player profile fake stats for a user if fake data is not registered:**


# putFakeStats

Put fake stats

### Description

This request is usable in the development environment only. It registers fake data, but does not override real data.

SIE deprecated the Multiplayer Matchmaking Ranking feature, as well as the mmr parameter and its children, perFranchise and perGenre.

* If a correct pair of the request body and the value of includeFields is not set, the request returns "Bad Request".
* If the value of includeFields is set to empty, includeFields, or is not specified, the request returns "Bad Request".
* If the value of includeFields is set to reputation, the request does not register fake data and returns no error.
* If the value of includeFields is set to mmr, the request does not register fake data and returns no error.

**Examples:**

**Example 1 : PUT advanced player profile fake data for a user:**

```
curl -X PUT -H 'Authorization: Bearer ${Bearer}' -H Content-Type:application/json -d {"npServiceLabel": 0,"bandwidth": {"global": {"downstream": {"average": 14,"confidenceScore": 15,"standardDeviation": 16},"upstream": {"average": 17,"confidenceScore": 18,"standardDeviation": 19}}} 'https://s2s.sp-int.playstation.net/api/advancedPlayerProfile/v1/users/1234/stats/fakes?includeFields=bandwidth(global)'
```

**Response:**

```
N/A
```

# deleteFakeStats

Delete fake stats

### Description

This request is available in the development environment only. It deletes fake data.

SIE deprecated the Multiplayer Matchmaking Ranking feature, as well as the mmr parameter and its children, perFranchise and perGenre.

* If the value of includeFields is set, it is possible to delete the target data by account ID.
* If includeFields is not specified, it is possible to delete all the data by the account ID.
* If the value of includeFields is set to empty, the request returns "Bad Request".
* If the value of includeFields is set to reputation, the request does not delete fake data and returns no error.
* If the value of includeFields is set to mmr, the request does not delete fake data and returns no error.

**Examples :**

**Example 1: Delete advanced player profile fake data:**

```
curl -XDELETE -H 'Authorization: Bearer ${Bearer}' -H 'npServiceLabel: 0' 'https://s2s.sp-int.playstation.net/api/advancedPlayerProfile/v1/users/1234/stats/fakes?includeFields=bandwidth(global)'
```

**Response:**

```
N/A
```
