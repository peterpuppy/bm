# Error Codes

| Code (Decimal) | Code (Hex) | Message | Description |
| --- | --- | --- | --- |
| 1048706 | 100082 | Bad request (invalid parameter provided) | Invalid request parameters (path/query/header) provided |
| 1048840 | 100108 | Unauthorized (access token has expired) | Access token has expired |
| 1048841 | 100109 | Unauthorized (access token is invalid) | Access token is invalid |
| 1052673 | 101001 | Account does not exist | Account being requested could not be found |
| 1052978 | 101132 | Too many requests | Request has been rate limited due to too many requests |
| 1048842 | 10010A | Forbidden (access token does not contain required scopes) | Access token does not contain scopes required to call API |
| 1048843 | 10010B | Unauthorized (access token required but not provided) | Access token is required to call API, but was not provided |
| 1052852 | 1010B4 | Unauthorized (only client credential token is allowed) | Client credential token is required to call API |
