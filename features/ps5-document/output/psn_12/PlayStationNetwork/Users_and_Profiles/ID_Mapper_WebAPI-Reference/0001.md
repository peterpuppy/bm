# ID Mapper Web API Reference Summary

The ID Mapper Web API provides online ID change history and mapping between account IDs and online IDs. It contains subresources that map from online ID to account ID (/map/onlineId2accountId), and account ID to online ID (/map/accountId2onlineId).

**Call Rate Limits**

It is recommended that the call rates are kept within the following ranges. Note that there is a possibility of rate limits changing without notice. Use the following information as a reference only.

| Request | Recommended Call Rate |
| --- | --- |
| listOnlineIdHistory | Within 5 times/1 minute |
| getAccountId2OnlineId | Within 4500 times/1 second per title |
| getOnlineId2AccountId | Within 4500 times/1 second per title |
| getEdgeAccountId2OnlineId | Within 4500 times/1 second per title |
| getEdgeOnlineId2AccountId | Within 4500 times/1 second per title |
| listEdgeAccountId2OnlineIdBatch | Within 4500 times/1 second per title |
| listEdgeOnlineId2AccountIdBatch | Within 4500 times/1 second per title |

### Base URLs

### PlayStation®5 Applications

For PlayStation®5 applications, there is no need to explicitly construct a base URL. Obtaining an appropriate base URL is automatically processed by calling a PlayStation™Network Web API using either the NpWebApi2 library or the NpCppWebApi library.

### Application Servers or Back Office Servers

For application servers or back office servers, construct the base URL as follows.

* https://s2s.sp-int.playstation.net/api/identityMapper (Development environment)
* https://s2s.prod-qa.playstation.net/api/identityMapper (Certification environment)
* https://s2s.np.playstation.net/api/identityMapper (Production environment)
