# ID Mapping (Account to Online)

# getAccountId2OnlineId

Map account ID to online ID

### Description

Map an individual account ID to its currently associated online ID.

**Example:**

```
curl https://s2s.np.playstation.net/api/identityMapper/v3/users/map/accountId2onlineId/4341567943509598007 -H 'Authorization: Bearer <token>'
```

**Response:**

```
{
  "accountId": "4341567943509598007",
  "onlineId": "wvyan850309344"
}
```

### Use Restrictions

| Client | Usable / Not Usable |
| --- | --- |
| Application for PlayStation®4 | Usable |
| Application for PlayStation®5 | Usable |
| Back office server | Usable |
| Application server | Usable |
| Application server (client credential) | Usable |
| Authorized App Server | Not Usable |

### Request

```
GET /v3/users/map/accountId2onlineId/{account_id}
```

# listEdgeAccountId2OnlineIdBatch

Map multiple account IDs to online IDs

### Description

Maps a number of account IDs provided as query parameters to their currently associated online IDs. The maximum number of account IDs that can be specified as query parameters is **20**.

Account IDs that are not mapped are represented by an incomplete object containing only the account ID that was sent in the request.

This end-point takes advantage of the CDN edge cache and is intended to be used by applications running on consoles and devices.

**Example:**

```
curl "https://s2s.np.playstation.net/api/identityMapper/v3/users/map/edge/accountId2onlineId/batch?id=4341567943509598007&id=4223970714646752222&id=2315737850477076902" -H 'Authorization: Bearer <token>'
```

**Response:**

```
[
  {
    "accountId": "4341567943509598007",
    "onlineId": "wvyan850309344"
  },
  {
    "accountId": "4223970714646752222",
    "onlineId": "popsub"
  },
  {
    "accountId": "2315737850477076902",
    "onlineId": "rlsmith"
  }
]
```
