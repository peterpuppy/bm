# ID Mapping (Online to Account)

# getOnlineId2AccountId

Map online ID to account ID

### Description

Map an individual online ID to the latest account ID to which it has been associated.

**Examples:**

**Example 1: Online id that is currently being used by an account:**

```
curl https://s2s.np.playstation.net/api/identityMapper/v3/users/map/onlineId2accountId/wvyan850309344 -H 'Authorization: Bearer <token>'
```

**Response:**

```
{
  "onlineId": "wvyan850309344",
  "accountId": "4341567943509598007",
  "isCurrent": true,
  "isRecycled": false
}
```

**Example 2: Online id that is not currently being used by an account but previously was:**

```
curl https://s2s.np.playstation.net/api/identityMapper/v3/users/map/onlineId2accountId/i1mxjg46us -H 'Authorization: Bearer <token>'
```

**Response:**

```
{
  "onlineId": "i1mxjg46us",
  "accountId": "8532210329123454381",
  "isCurrent": false,
  "isRecycled": false
}
```

# listEdgeOnlineId2AccountIdBatch

Map multiple online IDs to account IDs

### Description

Maps an array of online IDs to their associated account IDs. Where possible, the request provides the account ID that is currently associated with the online ID. If the request finds no current association, it provides the account ID most recently associated with the online ID, if one exists. The request also indicates whether the association is current or not, and whether the online ID has been recycled - that is, associated with other account IDs in the past.

The maximum number of online IDs that can be passed to the mapper at one time is **20**.

Online IDs that are not mapped are represented by an incomplete object containing only the online ID that was sent in the request.

This end-point takes advantage of the CDN edge cache and is intended to be used by applications running on consoles and devices.

**Example:**

```
curl "https://s2s.np.playstation.net/api/identityMapper/v3/users/map/edge/onlineId2accountId/batch?id=wvyan850309344&id=popsub&id=w421sp1a1" -H 'Authorization: Bearer <token>'
```

**Response:**

```
[
  {
    "onlineId": "wvyan850309344",
    "accountId": "4341567943509598007",
    "isCurrent": true,
    "isRecycled": false
  },
  {
    "onlineId": "popsub",
    "accountId": "4223970714646752222",
    "isCurrent": true,
    "isRecycled": false
  },
  {
    "onlineId": "w421sp1a1",
    "accountId": "3013397009957371512",
    "isCurrent": true,
    "isRecycled": false
  }
]
```
