# Profanity Filter Web API Overview – WebAPI 1

Source: https://game.develop.playstation.net/resources/documents/WebAPI/1/Profanity_Filter_WebAPI-Overview/reference-materials.html

# About the Profanity Filter Web API

The Profanity Filter is a PlayStation™Network service for verifying that text input by a user does not contain inappropriate language.

Profanity Filter can also censor profanity with asterisk ("\*") characters.

In situations where text (such as comments and player names) are input by users and that are seen in PlayStation™Network persistently, use the Profanity Filter to ensure that the text does not include inappropriate language.

The dictionaries backing Profanity Filter are maintained by moderators from the Global Safety Operations group.

# Main Features

This topic lists the main features provided by Profanity Filter.

The main features provided by the Profanity Filter are:

* Censors profanity in a given string.
* Detects and marks profanity in a given string.
* Checks profanity in a language and locale specific dictionary.

# When to use this API

Use the Profanity Filter Web API when you are accepting any string generated by a user
that is displayed to other users. For example, user-generated in-game content, messaging,
chat, and forum posts.

Ensure you are not using the Profanity Filter Web API excessively. SIE may throttle clients if traffic levels threaten the stability of other titles.

To reduce server load when calling this API:

* Avoid filtering static text or text that is generated by your title. Only filter text that may contain user profanity.
* You are not required to filter content that has previously been filtered or moderated by other systems. This includes strings from other major game platforms.
* If you are filtering several small strings, you can concatenate them using a separator and submit them in one call. This reduces server load by reducing the number of network transactions.

# Handling API Failures

This topic provides guidance on how to handle Profanity Filter Web API
failures.

Although filtering for profanity is important, failures should not block players from the game experience. As a best practice, ignore errors encountered when calling this API. If an error occurs when calling this API, the application should move forward as if profanity was not detected.
