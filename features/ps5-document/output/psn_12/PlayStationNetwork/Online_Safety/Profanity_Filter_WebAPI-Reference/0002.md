# Profanity Filter

# filterProfanity

Filter profanity in text

### Description

Censors profanity in a user content string. The string is returned in the response and any profanity detected is replaced by "\*" characters.

**Example**

In this example, the user is filtering some user-entered text using en-GB as the locale and a service label of 0. The service label corresponds to the NP Communication ID.

**Request**

```
POST /api/profanityFilter/v2/profanity/filter/en-GB/0
Content-Type: application/json
Accept: application/json
Authorization: Bearer 2161bbb6-21db-4601-819f-2ca5627ac7b6
```

**Body**

```
{
  "text": "The rain in Spain stays mainly in the PROFANITY plain."
}
```

**Response**

```
{
  "message": "The rain in Spain stays mainly in the ******* plain.",
  "status": "200"
}
```

**Example Error Response**

```
{
  "error": {
    "code": 3350785,
    "message": "Bad request - Service label doesn't exist. (0x332101)",
    "status": 400,
    "tid": "32f00b1e-389e-4b83-bd6d-982fbebd8506"
    }
}
```

**Filtering Through Multiple Locales**

You can provide a comma-separated list of locales for the locale parameter to simultaneously filter text in multiple locales. The service filters the string through each dictionary in sequence and returns the result.

SIE recommends that you filter this way only when required. Filtering through multiple locales reduces the advantages of locale-specific filtering such as cultural context and regional differences. Additionally, this may increase response times.

Filtering strings through multiple locales is only compatible with filterProfanity.

### Request

```
POST /v2/profanity/filter/{localeList}/{serviceLabel}
```

### URI Parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| localeList | **string** | true | The locale used to filter the provided string. You may also use a comma-separated list to filter through multiple locales. Only valid values are accepted.  **Possible Values:**  - ar-AE  - cs-CZ  - da-DK  - de-DE  - el-GR  - en-GB  - en-US  - es-ES  - es-419  - fi-FI  - fr-CA  - fr-FR  - hu-HU  - id-ID  - it-IT  - ja-JP  - ko-KR  - nl-NL  - no-NO  - pl-PL  - pt-BR  - pt-PT  - ro-RO  - ru-RU  - sv-SE  - th-TH  - tr-TR  - uk-UA  - vi-VN  - zh-Hans  - zh-Hant |
| serviceLabel | **string** | true | Service label issued by PlayStation™Network. The service label must point at an NP Communication ID. |

### Header Parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| Authorization | **string** | true | Access token required to make calls to the service. The token should be prepended with "Bearer ". |

### Request Body

Content string to be checked for profanity.

**Content-Type:** application/json

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| » text | **string** | true | Up to 4 kilobytes of message content. |

### Responses

| Status | Meaning | Description |
| --- | --- | --- |
| 200 | [OK](https://tools.ietf.org/html/rfc7231#section-6.3.1) | Success. The submitted text will be returned with profanity censored with asterisk "\*" characters. |
| 400 | [Bad Request](https://tools.ietf.org/html/rfc7231#section-6.5.1) | Badly formatted request. |
| 401 | [Unauthorized](https://tools.ietf.org/html/rfc7235#section-3.1) | The given token was expired or invalid. |
| 403 | [Forbidden](https://tools.ietf.org/html/rfc7231#section-6.5.3) | The supplied token was not valid or the matching title was not found. |
| 404 | [Not Found](https://tools.ietf.org/html/rfc7231#section-6.5.4) | A filter matching the given Service Label and locale could not be found. |
| 429 | [Too Many Requests](https://tools.ietf.org/html/rfc6585#section-4) | Limit exceeded or too many requests. |
| 500 | [Internal Server Error](https://tools.ietf.org/html/rfc7231#section-6.6.1) | Unexpected error. |
| 504 | [Gateway Time-out](https://tools.ietf.org/html/rfc7231#section-6.6.5) | Endpoint request timed out. |

### Status Code 200

### Response Body

**Content-Type:** application/json

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| » message | **string** | false | Content returned by the filter and censored for profanity. |
| » status | **string** | false | Status code returned by the operation. Usually 200. |
