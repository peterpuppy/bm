# Profanity Test

# testForProfanity

Check text for profanity

### Description

Checks a user content string for profanity. The string is returned in the response and any profanity is surrounded by square brackets "[]".

Note: If your input text includes square brackets for formatting or other purposes, the output may be difficult to interpret because brackets may appear both from the original text and from profanity marking.

### Request

```
POST /v2/profanity/test/{locale}/{serviceLabel}
```

### URI Parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| locale | **string** | true | The locale used to filter the provided string. Only valid values are accepted.  **Possible Values:**  - ar-AE  - cs-CZ  - da-DK  - de-DE  - el-GR  - en-GB  - en-US  - es-ES  - es-419  - fi-FI  - fr-CA  - fr-FR  - hu-HU  - id-ID  - it-IT  - ja-JP  - ko-KR  - nl-NL  - no-NO  - pl-PL  - pt-BR  - pt-PT  - ro-RO  - ru-RU  - sv-SE  - th-TH  - tr-TR  - uk-UA  - vi-VN  - zh-Hans  - zh-Hant |
| serviceLabel | **string** | true | Service label issued by PlayStation™Network. The service label must point at an NP Communication ID. |

### Header Parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| Authorization | **string** | true | Access token required to make calls to the service. The token should be prepended with "Bearer ". |

### Request Body

Content string to be checked for profanity.

**Content-Type:** application/json

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| » text | **string** | true | Up to 4 kilobytes of message content. |

### Responses

| Status | Meaning | Description |
| --- | --- | --- |
| 200 | [OK](https://tools.ietf.org/html/rfc7231#section-6.3.1) | Success. The submitted text will be returned with profanity marked with square brackets "[]". |
| 400 | [Bad Request](https://tools.ietf.org/html/rfc7231#section-6.5.1) | Badly formatted request. |
| 401 | [Unauthorized](https://tools.ietf.org/html/rfc7235#section-3.1) | The given token was expired or invalid. |
| 403 | [Forbidden](https://tools.ietf.org/html/rfc7231#section-6.5.3) | The supplied token was not valid or the matching title was not found. |
| 404 | [Not Found](https://tools.ietf.org/html/rfc7231#section-6.5.4) | A filter matching the given Service Label and locale could not be found. |
| 429 | [Too Many Requests](https://tools.ietf.org/html/rfc6585#section-4) | Limit exceeded or too many requests. |
| 500 | [Internal Server Error](https://tools.ietf.org/html/rfc7231#section-6.6.1) | Unexpected error. |
| 504 | [Gateway Time-out](https://tools.ietf.org/html/rfc7231#section-6.6.5) | Endpoint request timed out. |

### Response Body
