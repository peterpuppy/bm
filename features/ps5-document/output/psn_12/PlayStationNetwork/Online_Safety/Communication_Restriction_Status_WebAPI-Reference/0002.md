# Communication Restriction Status

# getCommunicationRestrictionStatus

Get account's communication restriction status

### Description

*Scope:* - *user:account.communicationRestrictionStatus.get* - *user:account.console* - *user:account.vsh*

This Web API gets an account's communication restriction status, to indicate whether or not the user is allowed to participate in social activities on the platform.

**Examples:**

**Example 1: Non-restricted account:**

```
GET https://s2s.np.playstation.net/api/communicationRestrictionStatus/v3/users/{account_id}/communication/restriction/status
```

**Response:**

```
{
  "restricted": false
}
```

**Example 2: Account in communication suspension:**

```
GET https://s2s.np.playstation.net/api/communicationRestrictionStatus/v3/users/{account_id}/communication/restriction/status
```

**Response:**

```
{
 "restricted": true
}
```

**Example 3: Account with Communication and User-Generated Content Blocked:**

```
GET https://s2s.np.playstation.net/api/communicationRestrictionStatus/v3/users/{account_id}/communication/restriction/status
```

**Response:**

```
{
 "restricted": true
}
```

**Example 4: Account with Communication and User-Generated Content Blocked but with a whitelisted title (resulting in NOT restricted):**

```
GET https://s2s.np.playstation.net/api/communicationRestrictionStatus/v3/users/{account_id}/communication/restriction/status -H "X-Psn-Np-Title-Id: WHITELISTED_TITLE_ID"
```

**Response:**

```
{
 "restricted": false
}
```
