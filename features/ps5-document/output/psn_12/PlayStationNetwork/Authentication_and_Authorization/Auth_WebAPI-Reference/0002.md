# JWKS Endpoint

# getJwks

Get a JWK set

### Description

Obtain a JSON Web Key (JWK) set with public keys to verify the signature of a JSON Web Token (JWT) issued by SIE authorization server. Use this API to obtain the public key to verify ID tokens. See also [RFC7517](https://tools.ietf.org/html/rfc7517).

**Examples:**

**Example 1: Get a JSON Web Key (JWK) set**

```
curl -X GET \
    'https://s2s.sp-int.playstation.net/api/authz/v3/oauth/jwks'
```

**Response** The following response provides the public key to verify the signature of an ID token that has Key ID (kid) set to key1 in its header. The cache control header indicates that the client may cache the JWK set for 1 hour and must not use a stale cache.

An ID token signed with a key ID other than those in the JWK set must not be trusted.

### Status Code 200

### Response Body (JSON web keyset)

**Content-Type:** application/json

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| » keys | **array[object]** | false | An array of JSON web keys for verifying JWT signature. |
| »» kid | **string** | true | Key ID. |
| »» kty | **string** | true | Key type. The cryptographic algorithm family used with the key. For example, RSA or EC. |
| »» alg | **string** | false | Identifies the algorithm intended for use with the key. For example, RS256. |
| »» use | **string** | true | Intended use of the public key. Value is "sig" for public key used to verify signature of JSON Web Tokens. |
| »» n | **string** | true | Base64Url encoded modulus for RSA public key. |
| »» e | **string** | true | Base64Url encoded exponent for RSA public key. |
