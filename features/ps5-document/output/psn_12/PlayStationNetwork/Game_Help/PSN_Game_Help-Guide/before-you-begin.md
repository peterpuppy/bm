# Before You Begin

This chapter explains who this document is intended for, what you as a reader are already expected to know, and any tasks you should have completed before starting the work described in this document.

## Audience

This document is for game developers and designers who want to learn about Game Help, including how Universal Data System (UDS) activities interact with Game Help, how Community Game Help works, and how to create and customize official hints for Game Help using the Game Help Tool.

## Background Information

Game Help is one of the data-driven experiences that is supported by UDS. In particular, Game Help provides hints that allow players to make progress towards completing activities and earning trophies.

This document introduces some of these concepts, but does not explain them fully.
For more information, see the following documents:

* [Creating Data-Driven Experiences with UDS](../Creating_Data_Driven_Experiences_with_UDS/__document_toc.html) - for an introduction to the concept of
  data-driven experiences and high-level overviews of the data-driven experiences that the
  PlayStation®5 can provide.
* The [PlayStation™Network Activities Guide](../PSN_Activities-Guide/__document_toc.html) - for an introduction to activities.
* The [Trophy System Overview](../Trophy_System-Overview/__document_toc.html) - for an introduction to trophies.

## Prerequisites

Before you start to configure Game Help, you must complete the following steps:

1. Request the UDS service in PlayStation®5 DevNet.
2. Define PlayStation™Network Objects, UDS Events, and UDS Stats.
3. Add instrumentation to your game to send in-game UDS events for activities and trophies.

These steps are described in more detail in [High-Level Workflow for Creating Official Hints](high-level-workflow-for-creating-official.html "This topic describes the high-level process and requirements for creating official hints.").
