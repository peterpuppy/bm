# Streams

# getStreamList

Gets a list of streams.

### Description

Get a list of streams for a given partner.

**Example: Get available streams**

```
curl -X GET 'https://s2s.sp-int.playstation.net/api/partnerEventService/v1/partner-events/PARTNER1' -H "Authorization: Bearer {access_token}"
```

**Response:**

```
{
    "streams": [
        {
            "streamName": "EVENTS-FOR-PARTNER1-TITLES",
            "streamUrl": "/partner-events/PARTNER1/EVENTS-FOR-PARTNER1-TITLES",
        },
        {
            "streamName": "EVENTS-FOR-PARTNER1-TITLE1",
            "streamUrl": "/partner-events/PARTNER1/EVENTS-FOR-PARTNER1-TITLE1",
        },
        {
            "streamName": "REFUND-EVENTS-FOR-PARTNER1-TITLE1",
            "streamUrl": "/partner-events/PARTNER1/REFUND-EVENTS-FOR-PARTNER1-TITLE1",

        {
            "streamName": "CHARGEBACK-EVENTS-FOR-PARTNER1-TITLE1",

    ]
}
```

# getStreamListInDetail

Get list of streams with additional details, such as event counts, Title IDs configured for the stream, and the complete URL of the stream to use while reading events

### Description

Get list of streams for a given partner. This API provides additional details such as event counts, Title IDs configured for the stream, and the complete URL of the stream. Please refer [getStreamEventsV2](0005.html#getstreameventsv2) to read events.

**Note:** Title IDs are available only for title streams which are created using [createStream](0005.html#createstream). *streamUrl* in the response refers to deprecated [getStreamEvents](0005.html#getstreamevents) API for backward compatibility. Please use [getStreamEventsV2](0005.html#getstreameventsv2) API to read events.

**Example: Get a detailed list of available streams**

```
curl -X GET 'https://s2s.sp-int.playstation.net/api/partnerEventService/v1/partner-events/PARTNER1/streams' -H "Authorization: Bearer {access_token}"
```

# getStreamListInDetailV2

Get list of streams with additional details, such as event counts, Title IDs configured for the stream, complete URL of the stream and valid start position details for each stream to use while reading events.

### Description

Get list of streams for a given partner. This API provides additional details such as event counts, Title IDs configured for the stream, the complete URL of the stream and valid start position details for each stream to use while reading events. Please refer [getStreamEventsV2](0006.html#getstreameventsv2) to read events.

Start position for each stream will be updated when event expires after the configured retention period. Please use this API to get valid start position for each stream before using them in [getStreamEventsV2](0006.html#getstreameventsv2) API.

**Note:** Title IDs are available only for title streams which are created using [createStream](0006.html#createstream). *streamUrl* in the response refers to deprecated [getStreamEvents](0006.html#getstreamevents) API for backward compatibility. Please use [getStreamEventsV2](0006.html#getstreameventsv2) API to read events.

```
curl -X GET 'https://s2s.sp-int.playstation.net/api/partnerEventService/v2/partner-events/PARTNER1/streams' -H "Authorization: Bearer {access_token}"
```

# getStreamListInDetailV3

Get a list of streams with additional details, such as event counts, Title IDs configured for the stream, and valid start position details

### Description

This API provides additional stream details such as event counts, Title IDs configured for the stream, the complete URL of the stream, and valid start position details for each stream to use while reading events. To read events, use [getStreamEventsV2](0007.html#getstreameventsv2).

The start position for each stream is updated when an event expires after the configured retention period. Use this API to get a valid start position for each stream before using them in [getStreamEventsV2](0007.html#getstreameventsv2).

Responses include the notificationUrl field and expose SUBSCRIPTION event-type stream metadata. notificationUrl is the webhook endpoint where SIE delivers SUBSCRIPTION events.

Title IDs are available only for title streams that are created using [createStream](0007.html#createstream). streamUrl refers to the deprecated [getStreamEvents](0007.html#getstreamevents) API for backward compatibility.

# createStream

Create a title stream

### Description

Create a title stream with a desired stream name. Only creating the title stream will not capture events in the stream. You must add Title IDs to the stream to get all the events related to the game title. Please use [addTitle](0008.html#addtitle) API to add Title IDs to the newly created stream. Events will be captured in the stream only after adding Title IDs relevant to the game titles to the stream. You can use [getStreamEventsV2](0008.html#getstreameventsv2) API to read the captured events in the stream.

You cannot change a stream's name after creation.

This API also creates four event type level streams (i.e. REFUND, CHARGEBACK, CHARGEBACK REVERSAL, SUBSCRIPTION) for the stream. You can use these event specific streams to get specific events. For example, you can use REFUND specific streams to get REFUND events of the Title IDs you added.

**Example: Create a title stream named STREAM1**

```
curl -X POST 'https://s2s.sp-int.playstation.net/api/partnerEventService/v1/partners/PARTNER1/streams' -H "Authorization: Bearer {access_token}"
```
