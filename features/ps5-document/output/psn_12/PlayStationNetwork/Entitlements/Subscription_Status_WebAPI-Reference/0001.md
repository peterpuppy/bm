# Subscription Status Web API Reference Summary

The Subscription Status Web API allows you to retrieve the status of a PlayStation®Plus subscription for an account for PlayStation™Network. Submit a DevNet support ticket to use this service.

### Base URLs

### Application Servers or Back Office Servers

For application servers or back office servers, construct the base URL as follows.

* https://s2s.sp-int.playstation.net/api/subscriptionsManager (Development environment)
* https://s2s.prod-qa.playstation.net/api/subscriptionsManager (Certification environment)
* https://s2s.np.playstation.net/api/subscriptionsManager (Production environment)

### Authentication

For information about obtaining an access token to authenticate a request, please see [PlayStation™Network Web APIs Overview - Usage - Obtaining Access Tokens](../../../SDK/latest/PSN_WebAPI-Overview/obtaining-access-tokens.html).
