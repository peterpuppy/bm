# The Development Accounts Feature

This topic describes the Development Accounts Feature.

Development Accounts is a feature of PlayStation™Partners. This guide is for those who develop or test games on PlayStation™Network and need to create, manage or update accounts on PlayStation™Network. This includes:

* Game developers and network engineers
* Game planners and designers
* QA and production staff managing configuration and testing of games
* Users not mentioned above who are accessing accounts in a development environment

Development Accounts is used to configure properties of accounts on PlayStation™Network for test purposes. Common use cases are:

* Maintenance of a library of accounts on PlayStation™Network for non-production use
* Configuration of accounts for TRC test cases
* Configuration of Advanced Player Profile in Development environment

# Accessing Development Accounts

This describes how to access the Development Accounts.

The URL for Development Accounts is: <https://tools.partners.playstation.net/accntls>. Development Accounts currently supports Chrome, Firefox, and Microsoft Edge browsers.

Development Accounts can also be reached from the Account Library tab within other account-based features, such as Advanced Player Profile Editor. It can also be access from the global header and the portal hub.

# Functions of Development Accounts

This describes the functions of Development Accounts.

## Developer Account Management

The feature allows a developer to manage a group of test accounts for PlayStation™Network. This includes modifying some attributes such as Communication Suspension.

## Developer Account Editing

Development Accounts allows you to edit attributes for specific accounts, these vary depending on the account and on the access of the user.
