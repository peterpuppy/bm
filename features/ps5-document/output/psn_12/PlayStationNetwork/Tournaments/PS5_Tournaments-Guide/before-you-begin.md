# Before you Begin

This chapter describes the intended audience and provides background information you should know before using the PlayStation®5 Tournaments Guide.

This section explains who this document is intended for, what you as a reader are already expected to know, and any tasks you should have completed before starting the work described in this document.

## Intended Audience

This document is intended for developers and designers who want to add
tournament support to their PlayStation®5 applications. Tournaments are only available for applications on SDK 4.00 or later.
For tournament support on PlayStation®4, see "Tournament Overview - Application Support for Tournaments - Applications That Can Hold Tournaments".
