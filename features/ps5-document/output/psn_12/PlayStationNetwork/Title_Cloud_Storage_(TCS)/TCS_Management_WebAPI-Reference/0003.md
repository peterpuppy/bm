# Variables

# setMultiVariablesByUser

Write TCS variables

### Description

This request writes a TCS variable to a slot owned by the specified user. If the specified user is anyone, the write destination will be a slot owned by the title.

It is possible to write different TCS variables, respectively, to multiple slots at once. If multiple slots are specified, an error will occur if even one write operation fails. If this happens, writing to other slots may have succeeded, and those slots may have been updated. Therefore, re-run the request if an error is returned.

**Example Request**

```
PUT titleCloudStorageBaseUrl/v1/apps/myApp/users/1234567890/variables

{
  "variables": [
    {
      "slotId": 0,
      "value": "0"
    },
    {
      "slotId": 1,
      "value": "1"
    }
  ]
}
```

HTTP status 204 will be returned when the above request example succeeds. There will be no response body.

# getMultiVariablesByUser

Read TCS variables

### Description

This request reads a TCS variable from a slot owned by the specified user. If anyone is specified, this request reads a TCS variable from a slot owned by the title. TCS variables can be read from a maximum of 128 slots at once. Specifying a number of slots above that limit will result in an error.

By default, the results that have been read are sorted in ascending order by slot ID. It is also possible to specify the last update date or the variable value as the sorting condition. If reading from even a single specified slot fails, there will be an error.

**Example Request**

```
GET titleCloudStorageBaseUrl/v1/apps/myApp/users/1234567890/variables?slotIds=0,1
```

**Example Response**

```
{
  "variables": [
    {
      "slotId": 0
      "owner": {
        "accountId": "1234567890",
        "onlineId": "strongJohn"
      },
      "lastUpdatedUser": {
        "accountId": "4567890123",
        "onlineId": "luckyTom"
      },
      "lastUpdatedDateTime": "2020-01-23T04:56:07.00Z",
      "value": 0
    },
    {
      "slotId": 1
      "owner": {
        "accountId": "1234567890",
        "onlineId": "strongJohn"
      },
      "lastUpdatedUser": {
        "accountId": "1234567890",
        "onlineId": "strongJohn"
      },
      "lastUpdatedDateTime": "2020-01-23T04:56:07.00Z",
      "value": 1
    }
  ],
  "totalVariableCount": 2
}
```

# deleteMultiVariablesByUser

Delete TCS variables

### Description

This request deletes a TCS variable from a slot owned by the specified user. If anyone is specified, this request deletes a TCS variable from a slot owned by the title.

A maximum of 128 slots can be specified at once. Specifying a number of slots above that limit will result in an error.

If deletion from even a single specified slot fails in the case of multiple slots specified, there will be an error. If this happens, deletion from other slots may have succeeded. No error will occur if an attempt is made to delete from a slot whose content has already been deleted or that does not exist. Therefore, if an error is returned, it is not a problem to re-run the request without changing slot specifications.

**Example Request**

```
DELETE titleCloudStorageBaseUrl/v1/apps/myApp/users/1234567890/variables?slotIds=0,1
```

HTTP status 204 will be returned when the above request example succeeds. There will be no response body.
