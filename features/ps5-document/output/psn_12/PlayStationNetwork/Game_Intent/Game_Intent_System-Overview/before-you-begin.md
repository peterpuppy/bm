# Before You Learn About the Game Intent System

This topic describes who this document is intended for and what background information is expected from the intended audience.

## Intended Audience

This document is intended for designers and product managers who want an overview of the game intent system, as well as developers who want to know about the methods for supporting game intent events in applications, specifications of each game intent event type, and debugging methods.

## Background Information

This document is written with the assumption that the audience has some background information about the game intent system. Refer to the following documents that provide background information about the game intent system, as necessary.

* [NpGameIntent Library Overview](../NpGameIntent-Overview/__document_toc.html) and [NpGameIntent Library Reference](../NpGameIntent-Reference/__document_toc.html): Information about how to use the NpGameIntent library, which must be used for an application to receive game intent events and to obtain the required information, is provided.
* [Session Manager Service Overview](../Session_Manager_Service-Overview/__document_toc.html) and [Session Manager Web API Overview](../../../WebAPI/latest/Session_Manager_WebAPI-Overview/__document_toc.html): Of the features and services that use the game intent system, an overview of invitations and joining sessions is provided.
* [PlayStation™Network Activities Guide](../PSN_Activities-Guide/__document_toc.html): Of the features and services that use the game intent system, an overview of the purposes and features of activities is provided.
* [Universal Data System Guide](../Universal_Data_System-Guide/__document_toc.html): Of the features and services that use the game intent system, an overview of activity definitions and starting activities is provided.
* [Release Notes - NpGameIntentLibrary](../ReleaseNotes/PlayStation_Network-NpGameIntent-ReleaseNotes.html): Information about bugs, points to note, restrictions, and announcements is provided.
