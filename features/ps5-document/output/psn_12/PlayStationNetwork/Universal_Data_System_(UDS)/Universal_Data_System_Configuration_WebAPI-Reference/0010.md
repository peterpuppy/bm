# listTags

List NP Config Tags

### Description

Returns a list of all currently registered tags for the specified NP Service Label. If no tags exist 404 Not Found is returned.

**Examples**

**Example 1: Get all tags**

```
curl -X GET 'https://s2s.sp-int.playstation.net/api/universalDataSystem/v1/npConfigTags' -H "Content-type:application/json" -H "Authorization:Bearer {Bearer}"
```

**Response**

```
{
  "tags": [
    {
      "name": "tag1",
      "notes": "first tag",
      "status": "inFormatQa",
      "platform": [
        "PS5"
      ],
      "requiresPackageUpdate": false,
      "hasWarning": false,
      "submissionType": "preSubmission",
      "createDateTime": "2020-02-06T08:56:17Z",
      "updateDateTime": "2020-02-06T09:15:25Z"
    },
    {
      "eventName": "tag2",
      "eventType": "second tag",
      "status": "tagged",
      "platform": [
        "PS5"
      ],
      "requiresPackageUpdate": false,
      "hasWarning": false,
      "createDateTime": "2020-02-06T08:56:17Z",
      "updateDateTime": "2020-02-06T09:15:25Z"
    }
  ],
  "totalItemCount": 2
}
```

# createTag

Create an NP Config Tag

### Description

Creates a tag as specified in the request. Integrity check will be run automatically and, if failed, tag creation will not be carried out and the API will return 409 Conflict.

**Examples**

**Example 1: Create a tag**

```
curl -X POST 'https://s2s.sp-int.playstation.net/api/universalDataSystem/v1/npConfigTags' -H "Content-type:application/json" -H "Authorization:Bearer {Bearer}" -d '
{
  "npConfigTagId": "my_tag",
  "name": "tag name",
  "notes": "notes for my tag",
  "platform": [
    "PS5"
  ]
}
```

**Response**

```
204 No Content
```

**Sample Response in case of errors**

```
{
  "error": {
    "code": 1234,
    "message": "Tag creation failed due to integrity check.",
    "referenceId": "9cd89ad1-d28f-4668-a593-f3b22f921f10"
  }
}
```

# promoteTag

Promote an NP Config Tag

### Description

Promotes the tag specified in the path to production environments. Use this API to publish metadata changes.

The type of promotion differs depending on the platform type specified in the NP Config Tag.

| Promotion type | Platform type | Promotion destination |
| --- | --- | --- |
| Promote for PlayStation®5 | Contains PS5 | np |

Successful promotions return a 204 status code, and the status of the tag is updated accordingly. Entities tied to the tag have their statuses and lockedStatuses updated.

Failed promotions return a 403 status code. This can occur when the promotion fails for any reason, for example, if the npConfigTag fails a diagnostic test.
