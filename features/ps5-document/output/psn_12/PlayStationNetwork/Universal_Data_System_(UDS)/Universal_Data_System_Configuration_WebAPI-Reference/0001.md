# Universal Data System Configuration Web API Reference Summary

**Introduction**

The Universal Data System Configuration Web API is a management feature for back office servers. It provides abilities that allow you to configure PlayStation™Network objects, UDS events and UDS stats.

**Note:** The Universal Data System Configuration Web API is not supported in the Sandbox Network Architecture. To configure PlayStation™Network objects in Sandbox, you must use the np-service-config CLI tool or the UDS Management Tool. For more information, see [NP Service Config User's Guide](../../../SDK/latest/NP_Service_Config-Users_Guide/__document_toc.html) and [Universal Data System Guide - Using the UDS Management Tool](../../../SDK/latest/Universal_Data_System-Guide/using-the-uds-management-tool.html).

**Call Rate Limits**

It is recommended that the call rates for the Universal Data System Configuration Web API are kept within the following ranges. Note that there is a possibility of rate limits changing without notice. Use the following information as a reference only.

| Request | Recommended Call Rate |
| --- | --- |
| listObjects | Within 30 times/15 minutes |
| putObjects | Within 30 times/15 minutes |
| deleteObject | Within 30 times/15 minutes |
| deleteObjects | Within 30 times/15 minutes |
| listEvents | Within 30 times/15 minutes |
| putEvents | Within 30 times/15 minutes |
| deleteEvent | Within 30 times/15 minutes |
| deleteEvents | Within 30 times/15 minutes |
| listCustomStatsDefinition | Within 30 times/15 minutes |
| putCustomStatsDefinition | Within 30 times/15 minutes |
| patchCustomStatsDefinition | Within 30 times/15 minutes |
| deleteCustomStatsDefinition | Within 30 times/15 minutes |
| listCustomStatsExtraction | Within 30 times/15 minutes |
| putCustomStatsExtraction | Within 30 times/15 minutes |
| patchCustomStatsExtraction | Within 30 times/15 minutes |
| deleteCustomStatsExtraction | Within 30 times/15 minutes |

### Base URLs

### Application Servers or Back Office Servers

The base URL to specify for application servers and back office servers depends on whether the client-side application uses the Sandbox network architecture or Legacy network architecture.  
(Refer to [Sandbox Network Architecture Guide](../../../SDK/latest/Sandbox_Network_Architecture-Guide/__document_toc.html) for details about Sandbox. Also refer to this technote regarding migration to Sandbox: <https://game.develop.playstation.net/technotes/view/740>. )

Specify the following base URL if the client-side application uses Sandbox:

* https://s2s.np.playstation.net/api/universalDataSystem

Specify the base URL of the applicable environment indicated below if the client-side application uses Legacy:

* Development environment (sp-int): https://s2s.sp-int.playstation.net/api/universalDataSystem
* Certification environment (prod-qa): https://s2s.prod-qa.playstation.net/api/universalDataSystem (to be supported later)
* Production environment (RETAIL): https://s2s.np.playstation.net/api/universalDataSystem (to be supported later)

For the purpose of maintaining backward compatibility, the above base URLs for Legacy can also be specified for application servers and back office servers that have migrated to Sandbox. For application servers and back office servers that serve traffic in both the Sandbox and Legacy network architectures, specify the base URL for Sandbox regarding Sandbox requests and specify the base URLs for Legacy regarding Legacy requests.
