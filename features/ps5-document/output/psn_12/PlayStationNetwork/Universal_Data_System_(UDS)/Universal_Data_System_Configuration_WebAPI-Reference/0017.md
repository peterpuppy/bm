# getAssets

Get a list of uploaded media assets

### Description

List the media assets uploaded for the specified npServiceLabel.

**Example 1: List uploaded media assets:**

```
curl -XGET 'https://s2s.sp-int.playstation.net/api/universalDataSystem/v1/assets' \
  -H "Content-type:application/json" \
  -H "Authorization:Bearer {Bearer}
```

### Use Restrictions

| Client | Usable / Not Usable |
| --- | --- |
| Application for PlayStation®4 | Not Usable |
| Application for PlayStation®5 | Not Usable |
| Back office server | Usable |
| Application server | Not Usable |
| Application server (client credential) | Not Usable |
| Authorized App Server | Not Usable |

### Request

```
GET /v1/assets
```

### Query Parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| assetIds | **string** | false | Asset IDs, listed in comma separated format. Filter to get specific media assets by ID. Maximum of 200 IDs per request. |
| npServiceLabel | **integer(int32)** | false | NP service label.  **Min Value:** 0  **Max Value:** 99  **Default Value:** 0 |
| limit | **integer(int32)** | false | Number of entries to be returned.  **Min Value:** 1 |
| offset | **integer(int32)** | false | Used along with limit to determine which record to start from.  **Min Value:** 0  **Default Value:** 0 |

| 200 | [OK](https://tools.ietf.org/html/rfc7231#section-6.3.1) | OK |

| 429 | [Too Many Requests](https://tools.ietf.org/html/rfc6585#section-4) | Too Many Requests |
| 500 | [Internal Server Error](https://tools.ietf.org/html/rfc7231#section-6.6.1) | An internal server error occurred. |
| 503 | [Service Unavailable](https://tools.ietf.org/html/rfc7231#section-6.6.4) | Service Unavailable |

### Status Code 200

### Response Body

**Content-Type:** application/json

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| » assets | **array[object]** | false | Array of media assets |
| »» assetId | **string** | false | The unique identifier of an asset.  **Min Length:** 1  **Max Length:** 36  **RegEx Pattern:** "^(?!-|\_)[0-9a-zA-Z-\_]{1,36}$" |
| »» originalFileName | **string** | false | The original file name of the uploaded media file. Only applies to uploads through User Bucket for Partners (UBP) and UDS Management Tool. |
| »» types | **array[string]** | false | The type of the media (e.g., 512x512). Only applies to image assets. |
| »» url | **string** | false | Set this URL in object properties (e.g., image URL properties) to associate with objects. |
| »» uploadedAt | **string(date-time)** | false | Date/time the asset was uploaded at |
| »» hash | **string** | false | MD5 hash of the media asset file. Used to prevent uploading duplicate asset files within one npServiceLabel. |
| »» status | **string** | false | The current status of an asset. |
| » nextOffset | **integer(int32)** | false | Start offset for the next page. Not available when no more results are available. |
| » previousOffset | **integer(int32)** | false | End offset for the previous page. Not available when the current result set contains the beginning of the records. |
| » totalItemCount | **integer(int64)** | false | Total number of items matching the filter. |

# putAssetWithoutID

Upload or update a media asset without specifying an asset ID

### Description

Upload a media asset or update an existing one for the specified npServiceLabel. The system generates an assetID automatically.

**Example 1: Add a media asset**

```
curl --location --request PUT 'https://s2s.sp-int.playstation.net/api/universalDataSystem/v1/assets' \
  --data-binary '@/path/to/file/sample-image.png' \
  -H 'Content-Type: image/png' \
  -H "Authorization:Bearer {Bearer}
```

**Response**

```
{
  "assetId": "fa5fca7d-e91b-4ca9-a689-e04bc9e7e991",
  "types": ["512x512"],
  "url": "https://apsnobj.stage.dl.playstation.net/apsnobj_stage/NPWR00000_00/fa5fca7d-e91b-4ca9-a689-e04bc9e7e991.png",
  "uploadedAt": "2021-08-24T14:15:22Z",
  "hash": "0ed05c69843b2782ec1ea3312447cd79"
}
```

Use url in a UDS object's Image URL property to associate with UDS objects.

# putAssetWithID

Upload or update an asset with an asset ID

### Description

Upload a media asset or update an existing one for the specified npServiceLabel. The assetID you provide is used as the unique identifier for that media asset.

**Example 1: Add a media asset**

```
curl --location --request PUT 'https://s2s.sp-int.playstation.net/api/universalDataSystem/v1/assets/rule-example' \
  --data-binary '@/path/to/file/example.text' \
  -H 'Content-Type: text/plain' \
  -H "Authorization:Bearer {Bearer}
```

**Response**

```
{
  "assetId": "rule-example",
  "url": "https://apsnobj.stage.dl.playstation.net/apsnobj_stage/NPWR00000_00/fa5fca7d-e91b-4ca9-a689-e04bc9e7e991.txt",
  "uploadedAt": "2021-08-24T14:15:22Z",
```
