# listCustomStatsExtraction

Get custom stats extractions

### Description

Returns a list of custom stats extractions.

### Examples

**Retrieve a list of stats extractions**

```
GET https://s2s.{env}.playstation.net/api/universalDataSystem/v1/stats/statsExtraction/custom?npServiceLabel={npServiceLabel} Authorization: Bearer {accessToken}
```

**Response:**

```
{
  "schemaVersion": "1.1",
  "statsExtractionRevision": 1,
  "statsExtractionRuleArray": [
    {
      "ruleId": 1,
      "status": "inDevelopment",
      "condition": {
        "eventName": "playerCharacterNameChange"
      },
      "action": {
        "input": "$.playerCharacterName",
        "output": {
          "statId": 1,
          "statName": "playerCharacterName"
        }
      }
    },
    {
      "ruleId": 2,
      "status": "inDevelopment",
      "condition": {
        "eventName": "attacked",
        "property": {
          "path": "$.damage",
          "comparator": ">",
          "value": "1"
        }
      },
      "action": {
        "input": "$.damage",
        "output": {
          "statId": 2,
          "statName": "worstDamage"
        }
      }
    }
  ]
}
```
