# PlayStation™Network Commerce Service Overview – SDK 12.000

Source: https://game.develop.playstation.net/resources/documents/SDK/12.000/PSN_Commerce_Service-Overview/about-this-document.html

# About This Document

This document provides an overview of the commerce service provided by PlayStation™Network. Consult this document during the design of titles that use the commerce service, as it discusses PlayStation®Store features, products sold or distributed through the service, and application development.

PlayStation™Network is a common network platform used by PlayStation®5, PlayStation®4,
PlayStation®3,
PlayStation®Vita, and PSP™ (PlayStation®Portable). This document is for PlayStation®5
licensees. The following general terms are in this document:

* "Developer Network website"

Refers to the PlayStation®5 Developer Network website, the PlayStation®4 Developer
Network website, PlayStation®3 Developer Network website, PlayStation®Vita Developer
Network website, and the PSP™ (PlayStation®Portable) Developer Network website.

* "storage"

Refers to the PlayStation®5/PlayStation®4/PlayStation®3 internal hard disk drive, a
PlayStation®Vita memory card or VC-VC configuration PlayStation®Vita card, and PSP™
Memory Stick™.
