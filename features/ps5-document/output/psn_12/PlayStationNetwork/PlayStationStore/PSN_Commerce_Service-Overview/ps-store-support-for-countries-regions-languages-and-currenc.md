# End-User License Agreement (EULA)

A title that meets all of the following criteria must display within the title an End
User License Agreement (EULA) that includes SIE-specified text that the Technical
Requirements Checklist for PlayStation®5 provides.

* Titles for SIEA/SIEE
* Titles with a function to access the title store
* Titles that display an EULA provided by a publisher within the title

For the required text, see the [Text Required in the EULA](https://p.siedev.net/projects/sdk/dl/dl/192/880/R5049_SIE-specified_text_e.html) document.
