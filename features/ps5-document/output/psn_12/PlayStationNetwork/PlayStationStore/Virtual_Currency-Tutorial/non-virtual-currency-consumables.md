# Non Virtual Currency Consumables

This topic provides guidance on non-virtual currency consumables.

While virtual currencies are a common form of consumable entitlements, the PlayStation™Network also supports non-virtual currency consumables. Unlike virtual currency entitlements these can be consumed directly from the game using the `NpEntitlementAccess` library. For more details see the [NpEntitlementAccess Library Overview](../NpEntitlementAccess-Overview/__document_toc.html) document.
