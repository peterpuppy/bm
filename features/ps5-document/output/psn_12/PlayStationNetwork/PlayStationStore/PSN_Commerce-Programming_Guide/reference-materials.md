# PlayStation™Network Commerce Programming Guide – SDK 12.000

Source: https://game.develop.playstation.net/resources/documents/SDK/12.000/PSN_Commerce-Programming_Guide/reference-materials.html

# Introduction

This document describes the development process of applications that use the commerce service provided on the PlayStation™Network.

The types and attributes of products handled through the PlayStation®Store are described, along with typical examples and the kinds of processing the application uses in handling them. Next, an outline of the products distributed through the PlayStation®Store, and the development of applications that purchase products from the PlayStation®Store, are provided.

Finally, development support features such as wallet charging, Title Store previews, Regional Store preview and promotion code redemption are described.

Note:

To enhance understanding of the overall system, this document may mention features and libraries that are not yet provided. For the latest information, refer to the Release Notes.
