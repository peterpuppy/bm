# PlayStation™Network Game Hub Preview Application Overview

This chapter provides an overview of the Game Hub Preview Application.

You can preview a product's game hub assets and metadata before publishing content to the production environment to identify potential content issues. This allows you to ensure that a product's game hub provides a high-quality, engaging user experience.

PlayStation®5 allows you to update the content of live services frequently, providing the following benefits:

* The ability to preview assets and metadata with ease increases publishers' confidence level when pushing new assets and metadata to customers.
* The Preview Application speeds up the content provisioning process, which may increase the freshness and richness of a product's game hub throughout the lifecycle of a game.
* Fresher, richer game hub content encourages players to purchase, download or stream the game.
* Frequently updated game hub content continues to engage users with the game when they are not playing, and it encourages them to return to the game.
