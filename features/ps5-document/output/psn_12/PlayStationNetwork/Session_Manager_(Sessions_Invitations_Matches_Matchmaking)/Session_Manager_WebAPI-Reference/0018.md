# Information Linked to Player Session Members

# setPlayerSessionMemberSystemProperties

Updates Player Session member information

### Description

This function updates information about the user (PlayStation™Network player or spectator) specified with *accountId*.  
To update information for non-PlayStation™Network users, use patchPlayerSessionsMemberNonPsnPlayer.

For *accountId*, you can specify only either me, indicating the user linked to access token, or the *accountId* of the user linked to the access token.  
It is not possible to update multiple user information items at once, and specifying multiple items will result in an error.

Note that when the request is called from an application server, it is not possible to use an access token obtained using the authentication feature for websites.

**Example Request**

```
{
  "customData1": "TWVtYmVyIEN1c3RvbSBEYXRhMQ=="
}
```

### Request

```
PATCH /v1/playerSessions/{sessionId}/members/{accountId}
```

### URI Parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |

| accountId | **string** | true | Account ID  **RegEx Pattern:** "^me$|^[1-9][0-9]{1,18}$" |

| Parameter | Type | Required | Description |

# patchPlayerSessionsMemberNonPsnPlayer

Updates Player Session member information

### Description

This request updates information about the user specified by*playerId* (a non-PlayStation™Network user). App Server (Client Credential) will be used as the product type.  
If you want to update information for PlayStation™Network users, use setPlayerSessionMemberSystemProperties.  
It is not possible to update multiple items at once, and specifying multiple items will result in an error.

**Example Request**

```
{
  "customData1": "TWVtYmVyIEN1c3RvbSBEYXRhMQ==" 
}
```

### Use Restrictions

| Client | Usable / Not Usable |
| --- | --- |
| Application for PlayStation®4 | Not Usable |
| Application for PlayStation®5 | Not Usable |
| Back office server | Not Usable |
| Application server | Not Usable |
| Application server (client credential) | Usable |
| Authorized App Server | Not Usable |

### Request

```
PATCH /v1/playerSessions/{sessionId}/member/nonPsnPlayers/{playerId}
```

### URI Parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| sessionId | **string** | true | Player Session ID  **RegEx Pattern:** "^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$" |
| playerId | **string** | true | Player ID (must be a unique ID within the same Player Session ID)  **RegEx Pattern:** "^[A-Za-z0-9\_-]{1,64}$" |

### Header Parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| X-PSN-SESSION-MANAGER-NON-PSN-CALLER-ID | **string** | true | If the request is called by a non-PlayStation™Network user, specify the player ID defined by the application (not possible to specify more than one). The specified value is used as the "Player ID of the user who called the request" in push notifications.  **RegEx Pattern:** "^[A-Za-z0-9\_-]{1,64}$" |
| X-Psn-Np-Service-Label | **string** | true | NP service label. It is not possible to specify more than one. |

### Request Body

**Content-Type:** application/json
