# Invitations and Messages to Player Sessions

# sendPlayerSessionMessage

Sends a message to the members of the Player Session

### Description

This request sends arbitrary string data to the specified members (PlayStation™Network players or spectators) participating in the Player Session.

Note that when the request is called from an application server, it is not possible to use an access token obtained using the authentication feature for websites.

**Example Request**

```
{
  "to": [
    {
      "accountId": "1234567890",
      "platform": "PS5"
    }
  ],
  "payload": "sample string"
}
```

```

# sendPlayerSessionInvitations

Sends invitations to the Player Session

### Description

This request sends invitations to the Player Session to the specified PlayStation™Network users.  
If the request would exceed the maximum number of people who can be invited, divide into multiple requests of up to the maximum number that can be invited.

* If the user who called the request (the user linked to the access token) is a PlayStation™Network user, invitations can be sent if all of the following conditions are satisfied. Note that when the request is called from an application server, it is not possible to use an access token obtained using the authentication feature for websites.  
  1. The user calling the request must be a participating member
  2. The user calling the request must satisfy the conditions of *invitableUserType*
  3. No user on the block list of the user calling the request can be specified as an invited user
* If the request is called by a non-PlayStation™Network user, App Server (Client Credential) must be used as the product type and that user's player ID must be specified for the X-PSN-SESSION-MANAGER-NON-PSN-CALLER-ID header parameter. Invitations can only be sent if all of the following conditions are met.  
  1. The user calling the request must be a participating member
  2. The user calling the request must satisfy the conditions of *invitableUserType*

**Example Request**

```
{
  "invitations": [
    {
      "to": {
        "accountId" : "123456789"
      }
    },
    {
      "to": {
        "accountId" : "987654321"
      }
    }
  ]
}
```

**Example Response**

```
{
  "invitations": [
    {
        "invitationId" : "1-396231988968875"
    },
    {
        "invitationId" : "1-396232024212539"
    }
  ]
}
```

# getPlayerSessionInvitations

Obtains a list of invitations to Player Sessions

### Description

This request obtains a list of invitations received by the PlayStation™Network user.

For *accountId*, you can specify only either me, indicating the user linked to access token, or the *accountId* of the user linked to the access token.  
If invitation IDs are specified by the X-PSN-SESSION-MANAGER-INVITATION-IDS header, only the specified invitations are obtained. If there is no specification, a maximum of the 100 most-recent invitations are obtained.  
Invitations for which 30 days have passed since the day they were received (receivedTimestamp) will be automatically deleted, and it will not be possible to respond to them.

Note that when the request is called from an application server, it is not possible to use an access token obtained using the authentication feature for websites.

**Example Response**

```
{
  "invitations": [
    {
      "invitationId": "1-396231988968875",
      "from": {
          "accountId": "123456789",
          "onlineId": "OnlineID_A",
          "platform": "PS5"
      },
      "sessionId": "47664463-1040-4d51-bbcd-10179393896e",
      "supportedPlatforms": [
        "PS5"
      ],
      "receivedTimestamp": "1729831988244",
      "invitationInvalid": false
    },
    {
      "invitationId": "1-396232024212539",
      "fromNonPsnPlayer": {
          "playerId": "nonPsnPlayer01",
          "playerName": "playerName"
      },
      "sessionId": "47664463-1040-4d51-bbcd-10179393896e",
      "supportedPlatforms": [
        "PS5"
      ],
      "receivedTimestamp": "1729831990765",
      "invitationInvalid": true
    }
  ]
}
```

# getPlayerSessionsShareableUrl

Obtains a URL for sharing a Player Session

### Description

This request obtains a URL for sharing a Player Session.

* If a Player Session with the specified sessionId does not exist, 404 Not Found is returned.
* If the request is called by someone who cannot share the Player Session, 403 Forbidden is returned. Confirm whether sharing is possible beforehand by calling getPlayerSessions and checking *shareableTypes*.
* If the request is called by a PlayStation™Network user and is called from an application server, an access token obtained using the authentication feature for websites cannot be used.
* If the request is called by a non-PlayStation™Network user, App Server (Client Credential) must be used as the product type and that user's player ID must be specified for the X-PSN-SESSION-MANAGER-NON-PSN-CALLER-ID header parameter.

**Example Response**

```
{
  "sessionJoinUrl": "https://example.com/join/12cjDwdJ3",
  "sessionShareImageUrl": "https://example.com/image/12cjDwdJ3"
}
