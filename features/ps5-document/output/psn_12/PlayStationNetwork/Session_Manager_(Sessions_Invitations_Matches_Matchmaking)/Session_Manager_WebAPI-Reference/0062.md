# Session Manager Web API Reference – WebAPI 1

Source: https://game.develop.playstation.net/resources/documents/WebAPI/1/Session_Manager_WebAPI-Reference/0062.html

# Player Session Creation Event

Push event sent when a Player Session has been created

### Description

This Push event is sent to the members who joined the Player Session when it was created. To receive "order-guaranteed Push events", be sure to register and use a Push context callback function. Push events cannot be received unless a Push context callback function is used.

### Datatype

```
psn:sessionManager:playerSession:created
```

### NP Service Name Required for Receiving

sessionManager

### Order Guaranteed

Yes

### Event Content

### from: (Not defined for this Push event)

### to: Recipient information

| Property | Type | Required | Description |
| --- | --- | --- | --- |
| accountId | **string** | true | Account ID of the recipient  **RegEx Pattern:** "^[1-9][0-9]{1,18}$" |

### data:

```
{
  "sessionId": "47664463-1040-4d51-bbcd-10179393896e"
}
```

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| » sessionId | **string** | true | Session ID of the created Player Session.  **RegEx Pattern:** "^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$" |

### extended data:

### Extended data key

fromPsn

Specified if the request is called by a PlayStation™Network user

### Extended data value

```
{
  "accountId": "123456789",
  "platform": "PROSPERO"
}
```

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| » accountId | **string** | true | Account ID of the user who called the request  **RegEx Pattern:** "^[1-9][0-9]{1,18}$" |
| » platform | **string** | true | Platform of the user who called the request  **Possible Values:**  - PROSPERO  - PS4 |

### Extended data key

fromNonPsn

Specified if the request is called by a non-PlayStation™Network user

### Extended data value

```
{
  "playerId": "nonPsnPlayer01"
}
```

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| » playerId | **string** | true | Player ID of the user who called the request  **RegEx Pattern:** "^[a-zA-Z0-9\_-]{1,64}$" |
