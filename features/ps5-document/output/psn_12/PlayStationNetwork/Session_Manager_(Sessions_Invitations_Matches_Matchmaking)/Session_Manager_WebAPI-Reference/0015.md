# Changing the Members of a Player Session

# leavePlayerSession

Makes a member leave the Player Session

### Description

This request makes the specified user (PlayStation™Network player or spectator) leave the Player Session.  
Use deletePlayerSessionsMemberNonPsnPlayer to make a non-PlayStation™Network user leave.

**Making a PlayStation™Network User Leave a Session**

* If the request is called by a PlayStation™Network user and me or the *accountId* of the user linked to the access token is specified for *accountId*, the user linked to the access token will leave the Player Session.
* If the request is called by a non-PlayStation™Network user, refer to deletePlayerSessionsMemberNonPsnPlayer.

If no more players are left in the Player Session (the total number of the PlayStation™Network players and non-PlayStation™Network players is 0) as a result of this request, the Player Session will be deleted.  
Note that when the request is called from an application server, it is not possible to use an access token obtained using the authentication feature for websites.

**Kicking Out**

The leader can kick out other users (force them to leave), and users who have been kicked out are afterward unable to rejoin the session.

* If the leader is a PlayStation™Network user, the access token linked to that user must be specified. The user to be kicked out is specified using *accountId*. Note that when the request is called from an application server, it is not possible to use an access token obtained using the authentication feature for websites.
* If the current leader is a non-PlayStation™Network user, App Server (Client Credential) must be used as the product type and that user's player ID must be specified for the X-PSN-SESSION-MANAGER-NON-PSN-CALLER-ID header parameter. The user to be kicked out is specified using *accountId*. <br

**Transferring Leader Privileges**

If the session's leader leaves, leader privileges are transferred to the player who joined at the oldest date and time (whether PlayStation™Network player or non-PlayStation™Network player). If there is more than one applicable player, they will be judged in the following order of priority.

1. The PlayStation™Network player with the lowest account ID number
2. The non-PlayStation™Network player with the lowest player ID number

# joinPlayerSessionAsPlayer

Makes the user join the Player Session as a PlayStation™Network player

### Description

This request makes the user join the specified Player Session as a PlayStation™Network user.  
To make a non-PlayStation™Network user join as a player, use postPlayerSessionsMemberNonPsnPlayers.

For *accountId*, you can specify only either me, indicating the user linked to access token, or the *accountId* of the user linked to the access token.  
For *platform*, you can specify only either me, indicating the platform of the user linked to access token, or the platform of the user linked to the access token.  
If already participating in another Player Session, the user will leave the Player Session in which they are participating and join the specified Player Session.  
An error will occur if the user is already participating in the specified Player Session as a PlayStation™Network player. (Joining is possible, even with the same account ID, if the platforms differ.)  
Note that when the request is called from an application server, it is not possible to use an access token obtained using the authentication feature for websites.

**Join a Session**

The user will join the specified Player Session as a PlayStation™Network player if they haven't already joined it.

The conditions allowing the user to join the Player Session as a PlayStation™Network player are as follows.

* *joinDisabled* for the specified Player Session must be false
* The number of players participating in the specified Player Session (the total number of the PlayStation™Network players and non-PlayStation™Network players) must be fewer than the maximum number of players who can participate
* The user linked to the access token must not have been kicked out of the specified Player Session in the past
* The user linked to the access token must not be included in the block list of a member participating in the specified Player Session
* A member participating in the specified Player Session must not be included in the block list of the user linked to the access token
* The user linked to the access token must fulfill one of the following criteria  
  1. Have the same account ID as the leader of the specified Player Session
  2. Have received an invitation to the specified Player Session
  3. Be allowed to join the session without being notified of an invitation, based on the privacy settings (*joinableUserType*) of the specified Player Session

When the following blocking relationship is present, it is not possible to join the Player Session as a PlayStation™Network player.

* The specified user has blocked a member who has joined the specified Player Session
* The specified user has been blocked by a member who has joined the specified Player Session

**Swapping from Spectator to PlayStation™Network Player**

If the user has already joined the specified Player Session as a spectator, they can swap roles from spectator to PlayStation™Network player.

The conditions under which a swap from a spectator to a PlayStation™Network player in the Player Session is possible are as follows.

* *swapSupported* must be true
* The number of players participating (the total number of PlayStation™Network players and non-PlayStation™Network players) must be fewer than the maximum number of players allowed to participate

```
      "platform": "PS5",

        }
      ],
      "customData1": "TWVtYmVyIEN1c3RvbSBEYXRhMQ=="
    }
  ]
}
```

**Example Response**

```
{
  "players": [
    {
      "accountId": "123456789",
      "platform": "PS5"
    }
  ]
}
```

# joinPlayerSessionAsSpectator

Makes the user join the Player Session as a spectator

### Description

This request makes the user join the specified Player Session as a spectator.  
Non-PlayStation™Network users cannot join as a spectator.

For *accountId*, you can specify only either me, indicating the user linked to access token, or the *accountId* of the user linked to the access token.  
For *platform*, you can specify only either me, indicating the platform of the user linked to access token, or the platform of the user linked to the access token.  
If already participating in another Player Session, the user will leave the Player Session in which they are participating and join the specified Player Session.  
An error will occur if the user is already participating in the specified Player Session as a spectator. (Joining is possible, even with the same account ID, if the platforms differ.)

The user joins the specified Player Session as a spectator if they have not already joined it.

The conditions allowing the user to join the Player Session as a spectator are as follows.

* *joinDisabled* for the specified Player Session must be false
* The number of spectators participating in the specified Player Session must be fewer than the maximum number of spectators who can participate
* The user linked to the access token must not have been kicked out of the specified Player Session in the past
* The user linked to the access token must not be included in the block list of a member participating in the specified Player Session
* A member participating in the specified Player Session must not be included in the block list of the user linked to the access token
* The user linked to the access token must fulfill one of the following criteria

**Swapping from a PlayStation™Network Player to a Spectator**

If the user has already joined the specified Player Session as a PlayStation™Network player, they can swap roles from PlayStation™Network player to spectator.

* The PlayStation™Network user who called the request must not be the leader
* There must be two or more players (PlayStation™Network players or non-PlayStation™Network players), including the PlayStation™Network user who called the request
* The PlayStation™Network user who called the request must not be participating as a PlayStation™Network player in a Game Session that is dependent on the Player Session

# deletePlayerSessionsMemberNonPsnPlayer

Makes the specified member leave the Player Session

### Description

This request makes the specified user (non-PlayStation™Network user) leave the Player Session.  
Use leavePlayerSession if the target member is a PlayStation™Network user.

**Making a Non-PlayStation™Network User Leave the Session**

* If the request is called by a PlayStation™Network user, refer to leavePlayerSession.
* If the request is called by a non-PlayStation™Network user, App Server (Client Credential) must be used as the product type and that user's player ID must be specified for the X-PSN-SESSION-MANAGER-NON-PSN-CALLER-ID header parameter. Specify the target member who is to leave the session using the path parameter *playerId*.  
  If no more players are left in the Player Session (the total number of the PlayStation™Network players and non-PlayStation™Network players is 0) as a result of this request, the Player Session will be deleted.

**Kicking Out**

The leader can kick out other users (force them to leave), and users who have been kicked out are afterward unable to rejoin the session.

* If the leader is a PlayStation™Network user, the access token linked to that user must be specified. The user to be kicked out is specified by the path parameter *playerId*.
* If the current leader is a non-PlayStation™Network user, App Server (Client Credential) must be used as the product type and that user's player ID must be specified for the X-PSN-SESSION-MANAGER-NON-PSN-CALLER-ID header parameter. The user to be kicked out is specified by the path parameter *playerId*.

**Transferring Leader Privileges**

If the session's leader leaves, leader privileges are transferred to the player who joined at the oldest date and time (whether PlayStation™Network player or non-PlayStation™Network player). If there is more than one applicable player, they will be judged in the following order of priority.

1. The PlayStation™Network player with the lowest account ID number
2. The non-PlayStation™Network player with the lowest player ID number

# putPlayerSessionsMemberNonPsnPlayers

Synchronizes information about non-PlayStation™Network players

### Description

This request synchronizes information about non-PlayStation™Network players joined into the specified Player Session with the specified information. App Server (Client Credential) will be used as the product type.

* If the non-PlayStation™Network players specified with the *nonPsnPlayers* array are already joined into the Player Session, information of those users can be overwritten.

  + Whether to overwrite *playerName* can be controlled using the value specified for the *X-PSN-SESSION-MANAGER-PLAYER-NAME-OVERWRITTEN* header parameter. For details, refer to the explanation of the *X-PSN-SESSION-MANAGER-PLAYER-NAME-OVERWRITTEN* header parameter.
  + *customData1* is overwritten with the specified value regardless of the *X-PSN-SESSION-MANAGER-PLAYER-NAME-OVERWRITTEN* header parameter. If there is no specification for *customData1*, it will be overwritten with null.
* If the non-PlayStation™Network players specified with the *nonPsnPlayers* array are not joined into the Player Session, they can be made to join the Player Session.

  The conditions for joining the Player Session are as follows.  
  1. *joinDisabled* for the specified Player Session must be false
  2. The number of players participating in the specified Player Session (the total number of the PlayStation™Network players and non-PlayStation™Network players) must be fewer than the maximum number of players who can participate
  3. The specified user must not have been kicked out of the specified session in the past
  4. *nonPsnSupported* for the specified Player Session must be true
* If non-PlayStation™Network players not specified with the *nonPsnPlayers* array are joined into the Player Session, they can be made to leave the Player Session.

**Example Request 1**  
Assume that non-PlayStation™Network players nonPsnPlayer01 and nonPsnPlayer02 are joined into the specified Player session. In this case, *customData1* information of nonPsnPlayer01 is overwritten with null given the following request. nonPsnPlayer02 leaves the specified Player Session and nonPsnPlayer03 joins the specified Player Session.

```
{
  "nonPsnPlayers": [
    {
      "playerId": "nonPsnPlayer01",
      "playerName": "playerName01"
    }
    {
      "playerId": "nonPsnPlayer03",
      "playerName": "playerName03",
      "customData1": "TWVtYmVyIEN1c3RvbSBEYXRhMQ=="
    }
  ]
}
```

**Example Request 2**  
Assume that non-PlayStation™Network players are joined into the specified Player session. All non-PlayStation™Network players joined into the specified Player Session are made to leave the session given the following request. If no more players are left in the Player Session (the total number of the PlayStation™Network players and non-PlayStation™Network players is 0) as a result, the Player Session will be deleted.

```
{
  "nonPsnPlayers": []
}
```
