# Searching for and Listing Game Sessions

# getGameSessions

Obtains Game Session information

### Description

Obtain the Game Session information specified with the X-PSN-SESSION-MANAGER-SESSION-IDS header.  
If a Game Session with a specified *sessionId* does not exist, information for that session information will not be included in the response.

Note that when the request is called from an application server, it is not possible to use an access token obtained using the authentication feature for websites.

# getJoinedGameSessionsByUser

Obtains a list of Game Sessions in which the user is participating

### Description

This request obtains a list of Game Sessions in which the user is participating.  
For *accountId*, you can specify only either me, indicating the user linked to access token, or the *accountId* of the user linked to the access token.  
If no Game Session in which the user is participating exists, an empty Game Session list will be returned.

Note that when the request is called from an application server, it is not possible to use an access token obtained using the authentication feature for websites.  
If calling from an application for PlayStation®4 using the Cross-Generation SDK, PS4 must be specified for the *platformFilter* query parameter.

**Example Response**

```
{
  "gameSessions": [
    {
      "sessionId": "47664463-1040-4d51-bbcd-10179393896e",
      "platform": "PS5",
      "joinState": "JOINED",
      "usePlayerSession": true
    }
  ]
}
```

# putGameSessionsSearchAttributes

Registers search attributes to Game Session information

### Description

This request overwrites all search attributes used in Game Session searches.  
Search attributes that are not specified will be deleted.  
Because the update of search attributes is intended to be used for search purposes, a Push notification such as an update event is not sent.

Note that when the request is called from an application server, it is not possible to use an access token obtained using the authentication feature for websites.

**Example Request**

```
{
  "string1": "string1",
  "integer1": 1,
  "boolean1": true
}
```
