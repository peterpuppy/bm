# Game Session Messages

# sendGameSessionMessage

Sends a message to members of the Game Session

### Description

This request sends arbitrary string data to the specified members participating in the Game Session.

Note that when the request is called from an application server, it is not possible to use an access token obtained using the authentication feature for websites.

**Example Request**

```
{
  "to": [
    {
      "accountId": "1234567890",
      "platform": "PS5"
    }
  ],
  "payload": "sample string"
}
```

### Use Restrictions

| Client | Usable / Not Usable |
| --- | --- |
| Application for PlayStation®4 | Usable |
| Application for PlayStation®5 | Usable |
| Back office server | Not Usable |
| Application server | Usable |
| Application server (client credential) | Not Usable |
| Authorized App Server | Not Usable |

### Request

```
POST /v1/gameSessions/{sessionId}/sessionMessage
```

### URI Parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| sessionId | **string** | true | Game Session ID  **RegEx Pattern:** "^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$" |

### Request Body

**Content-Type:** application/json

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| » to | **array[object]** | true | Array of pairs of recipients' account IDs and platforms. Must be 32 users or fewer. The sender, him or herself, can also be included.  **Min Items:** 1  **Max Items:** 32 |
| »» accountId | **string** | true | Account ID  **RegEx Pattern:** "^[1-9][0-9]{1,18}$" |
| »» platform | **string** | true | Platform  **RegEx Pattern:** "^PROSPERO$|^PS4$|^PS5$" |
| » payload | **string** | true | Specify an arbitrary string (e.g., in Base64 or JSON). The amount of data must be at least 1 byte and no greater than 8032 bytes.  **Min Length:** 1 |
