# Information Linked to the Members of a Game Session

# setGameSessionMemberSystemProperties

Updates Game Session member information

### Description

This request updates information about the member (a player or spectator) specified with *accountId*.  
For *accountId*, you can specify only either me, indicating the user linked to access token, or the *accountId* of the user linked to the access token.  
Of the member information among the Game Session information, one specified item of information will be updated. It is not possible to update multiple items at once, and specifying multiple items will result in an error.

Note that when the request is called from an application server, it is not possible to use an access token obtained using the authentication feature for websites.

**Example Request**

```
{
  "customData1": "TWVtYmVyIEN1c3RvbSBEYXRhMQ=="
}
```

### Request

```
PATCH /v1/gameSessions/{sessionId}/members/{accountId}
```

### URI Parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| sessionId | **string** | true | Game Session ID  **RegEx Pattern:** "^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$" |
| accountId | **string** | true | Account ID  **RegEx Pattern:** "^me$|^[1-9][0-9]{1,18}$" |

### Request Body

**Content-Type:** application/json

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| » natType | **integer(int32)** | false | NAT type of the member  Set when using whether P2P communications are allowed as a search condition in a Game Session search.  **Min Value:** 1  **Max Value:** 3 |
| » customData1 | **string(byte)** | false | Custom data  The maximum size is the size yielded from encoding 1024 bytes in Base64.  **Min Length:** 1 |
