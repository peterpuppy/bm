# Session Manager Web API Reference Summary

The Session Manager Web API supports multiplayer gameplay where multiple users play games together. This Web API provides features for creating and managing two kinds of sessions, "Player Sessions," which come with invitation features, and "Game Sessions," which do not; features for making users join or leave sessions, features for sending data among the users in a session, features for searching for Game Sessions, and other features.

### Base URLs

### Applications for PlayStation®5

For PlayStation®5 applications, there is no need to explicitly construct a base URL. Obtaining an appropriate base URL is automatically processed by calling a PlayStation™Network Web API using either the NpWebApi2 library or the NpCppWebApi library.

### Application Servers and Back Office Servers

The base URL to specify for application servers and back office servers depends on whether the client-side application uses the Sandbox network architecture or Legacy network architecture.  
(Refer to [Sandbox Network Architecture Guide](../../../SDK/latest/Sandbox_Network_Architecture-Guide/__document_toc.html) for details about Sandbox. Also refer to this technote regarding migration to Sandbox: <https://game.develop.playstation.net/technotes/view/740>.）

Specify the following base URL if the client-side application uses Sandbox:

* https://s2s.np.playstation.net/api/sessionManager

Specify the base URL of the applicable environment indicated below if the client-side application uses Legacy:

* Development environment (sp-int): https://s2s.sp-int.playstation.net/api/sessionManager
* Certification environment (prod-qa): https://s2s.prod-qa.playstation.net/api/sessionManager
* Production environment (RETAIL): https://s2s.np.playstation.net/api/sessionManager

For the purpose of maintaining backward compatibility, the above base URLs for Legacy can also be specified for application servers and back office servers that have migrated to Sandbox. For application servers and back office servers that serve traffic in both the Sandbox and Legacy network architectures, specify the base URL for Sandbox regarding Sandbox requests and specify the base URLs for Legacy regarding Legacy requests.
