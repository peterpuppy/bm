# Changing the Users Who Can Join a Player Session

# addPlayerSessionJoinableSpecifiedUsers

Registers PlayStation™Network users to the list of users who can join the Player Session

### Description

This request registers specified users to the *joinableSpecifiedUsers* list for the Player Session.  
Non-PlayStation™Network users cannot be registered in the *joinableSpecifiedUsers* list.

When the *joinableUserType* setting for the Player Session is SPECIFIED\_USERS, the *joinableSpecifiedUsers* list indicates the users who can join the Player Session.  
No error will occur, even if a user who has already been registered is specified by his or her *accountId*.  
Up to 150 users can be registered to the *joinableSpecifiedUsers* list.

* If the caller of the request (the user linked to the access token) is a PlayStation™Network user, PlayStation™Network users can be registered as long as that user is participating in the Player Session. Note that when the request is called from an application server, it is not possible to use an access token obtained using the authentication feature for websites.
* If the request is called by a non-PlayStation™Network user, App Server (Client Credential) must be used as the product type and that user's player ID must be specified for the X-PSN-SESSION-MANAGER-NON-PSN-CALLER-ID header parameter. As long as that user is participating in the Player Session, PlayStation™Network users can be registered.

**Example Request**

```
{
  "joinableSpecifiedUsers": [
    {
      "accountId": "1234567890"
    },
    {
      "accountId": "2345678901"
    }
  ]
}
```

**Example Response**

```
{
  "joinableSpecifiedUsers": [
    {
      "accountId": "1234567890"
    },
    {
      "accountId": "2345678901"
    }
  ]
}
```

### Request

```

```

| Name | Type | Required | Description |

### Header Parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| X-PSN-SESSION-MANAGER-NON-PSN-CALLER-ID | **string** | false | If the request is called by a non-PlayStation™Network user, specify the player ID defined by the application (not possible to specify more than one).  In such cases, it is necessary to use App Server (Client Credential) as the product type, and it becomes a required parameter. The specified value is used as the "Player ID of the user who called the request" in push notifications.  **RegEx Pattern:** "^[A-Za-z0-9\_-]{1,64}$" |
| X-Psn-Np-Service-Label | **string** | false | NP service label. This is a required parameter if the product type is App Server (Client Credential). It is not possible to specify more than one. |

# deletePlayerSessionJoinableSpecifiedUsers

Deletes PlayStation™Network users from the list of users who can join the Player Session

### Description

Delete the specified users from the *joinableSpecifiedUsers* list for the Player Session.  
This request will succeed even if the specified users are not registered on the *joinableSpecifiedUsers* list.

* If the caller of the request (the user linked to the access token) is a PlayStation™Network user, the specified users can be deleted as long as that user is participating in the Player Session. Note that when the request is called from an application server, it is not possible to use an access token obtained using the authentication feature for websites.
* If the request is called by a non-PlayStation™Network user, App Server (Client Credential) must be used as the product type and that user's player ID must be specified for the X-PSN-SESSION-MANAGER-NON-PSN-CALLER-ID header parameter. As long as that user is participating in that Player Session, the specified users can be deleted.
