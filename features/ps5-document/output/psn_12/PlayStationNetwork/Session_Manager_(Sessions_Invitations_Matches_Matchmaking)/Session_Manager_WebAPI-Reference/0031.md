# Session Manager Web API Reference – WebAPI 1

Source: https://game.develop.playstation.net/resources/documents/WebAPI/1/Session_Manager_WebAPI-Reference/0031.html

# Information Linked to a Game Session

# setGameSessionProperties

Updates Game Session information

### Description

This request modifies one item of information specified, out of all the information concerning the Game Session. (It is not possible to update multiple items, and specifying multiple items will result in an error.)

If *maxPlayers* is being updated, it cannot be modified to a value smaller than the number of players already currently participating.  
If *maxSpectators* is being updated, it cannot be modified to a value smaller than the number of spectators already currently participating.

Note that when the request is called from an application server, it is not possible to use an access token obtained using the authentication feature for websites.

**Example Request**

```
{
  "maxPlayers": 256
}
```

| Client | Usable / Not Usable |

### Request

```
PATCH /v1/gameSessions/{sessionId}
```

### URI Parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| sessionId | **string** | true | Game Session ID  **RegEx Pattern:** "^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$" |

### Request Body

**Content-Type:** application/json

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| » maxPlayers | **integer(int32)** | false | Maximum number of members who can join the Game Session as players  **Min Value:** 1  **Max Value:** 256 |
| » maxSpectators | **integer(int32)** | false | Maximum number of members who can join the Game Session as spectators  **Min Value:** 0  **Max Value:** 50 |
| » joinDisabled | **boolean** | false | Flag for temporarily prohibiting joining the Game Session  When true, the Game Session cannot be joined. |
| » customData1 | **string(byte)** | false | Custom data  The maximum size is the size yielded from encoding 1024 bytes in Base64.  **Min Length:** 1 |
| » customData2 | **string(byte)** | false | Custom data  The maximum size is the size yielded from encoding 1024 bytes in Base64.  **Min Length:** 1 |
| » searchable | **boolean** | false | Flag that controls whether to make the session searchable in a Game Session search or to exclude it temporarily from searches  When true, the session is searchable. |
