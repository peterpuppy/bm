# Session Manager Web API Reference – WebAPI 1

Source: https://game.develop.playstation.net/resources/documents/WebAPI/1/Session_Manager_WebAPI-Reference/0006.html

# Information Linked to a Player Session

# setPlayerSessionProperties

Updates Player Session information

### Description

This request modifies one item of information specified, out of all the information concerning the Player Session. (It is not possible to update multiple items, and specifying multiple items will result in an error.)

* If the caller of the request (the user linked to the access token) is a PlayStation™Network user, information about the Player Session can only be updated when that user is participating in the Player Session. Note that when the request is called from an application server, it is not possible to use an access token obtained using the authentication feature for websites.
* If the request is called by a non-PlayStation™Network user, App Server (Client Credential) must be used as the product type and that user's player ID must be specified for the X-PSN-SESSION-MANAGER-NON-PSN-CALLER-ID header parameter. Information about the Player Session can only be updated when that user is participating in the Player Session.

When *maxPlayers* is updated, it cannot be updated to a value less than the total number of participating PlayStation™Network players and non-PlayStation™Network players.  
If *maxSpectators* is being updated, it cannot be updated to a value smaller than the number of spectators currently participating.  
Only the leader of the Player Session can update *joinableUserType* or *invitableUserType*.

* If the leader is a PlayStation™Network user, the access token linked to that user must be specified. Additionally, when the request is called from an application server, an access token obtained using the authentication feature for websites cannot be used.
* If the current leader is a non-PlayStation™Network user, App Server (Client Credential) must be used as the product type and that user's player ID must be specified for the X-PSN-SESSION-MANAGER-NON-PSN-CALLER-ID header parameter.

**Example Request**

```
{
  "maxPlayers": 100
}
```

| Client | Usable / Not Usable |

### Request

```
PATCH /v1/playerSessions/{sessionId}
```

### URI Parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| sessionId | **string** | true | Player Session ID  **RegEx Pattern:** "^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$" |

### Header Parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| X-PSN-SESSION-MANAGER-NON-PSN-CALLER-ID | **string** | false | If the request is called by a non-PlayStation™Network user, specify the player ID defined by the application (not possible to specify more than one).  In such cases, it is necessary to use App Server (Client Credential) as the product type, and it becomes a required parameter. The specified value is used as the "Player ID of the user who called the request" in push notifications.  **RegEx Pattern:** "^[A-Za-z0-9\_-]{1,64}$" |
| X-Psn-Np-Service-Label | **string** | false | NP service label. This is a required parameter if the product type is App Server (Client Credential). It is not possible to specify more than one. |

### Request Body

**Content-Type:** application/json

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| » maxPlayers | **integer(int32)** | false | Maximum number of members that can participate as players in a Player Session (the total number of the PlayStation™Network players and non-PlayStation™Network players)  **Min Value:** 1  **Max Value:** 100 |
| » maxSpectators | **integer(int32)** | false | Maximum number of members who can join the Player Session as spectators  **Min Value:** 0  **Max Value:** 50 |
| » joinDisabled | **boolean** | false | Flag that temporarily prohibits joining the Player Session  When true, joining is prohibited.  When false, joining is allowed (however, limited to users who have received invitations or users who are allowed to join without invitations based on the set value of *joinableUserType*). |
| » localizedSessionName | **object** | false | Player Session name data object |
| »» defaultLanguage | **string** | true | Default language code  The localizedText corresponding to this language code will be referenced if there is no localizedText corresponding to the language code specified in the Accept-Language header with the referencing API.  One of the language codes specified with *localizedText* can be specified.    **Min Length:** 1 |
| »» localizedText | **object** | true | Multilingual JSON object  Specify combinations of language codes and corresponding messages. Multiple combinations can be specified.  For the language codes that can be specified, refer to the "Language Codes" section of the [Session Manager Web API Overview](../Session_Manager_WebAPI-Overview/__document_toc.html) document.  For messages corresponding to language codes, an arbitrary string with a maximum length of 128 characters can be specified for each language code. |
| » joinableUserType | **string** | false | Users who can join the Player Session without an invitation  - NO\_ONE: No one can join without an invitation  - FRIENDS: Friends of the leader can join without invitations  - FRIENDS\_OF\_FRIENDS: Friends of friends of the leader can join without invitations  - ANYONE: Anyone can join without an invitation  - SPECIFIED\_USERS: Users who have been registered on the *JoinableSpecifiedUsers* list can join without invitations    **Possible Values:**  - NO\_ONE  - FRIENDS  - FRIENDS\_OF\_FRIENDS  - ANYONE  - SPECIFIED\_USERS |
| » invitableUserType | **string** | false | Members who can send invitations to the Player Session  **Possible Values:**  - NO\_ONE  - LEADER  - MEMBER |
| » leaderPrivileges | **array[string]** | false | Information about the privileges possessed by the leader of the Player Session   If a specification is made with this parameter, the leader will have the specified privileges. If nothing is specified, the leader will have KICK and UPDATE\_JOINABLE\_USER\_TYPE privileges. However, it is recommended that *exclusiveLeaderPrivileges*, rather than this parameter, be used to specify the leader's privileges.  **Possible Values:**  - KICK  - UPDATE\_JOINABLE\_USER\_TYPE  **Min Items:** 0 |
| » exclusiveLeaderPrivileges | **array[string]** | false | Items excluded from the privileges that the leader has by default   The specified items will become inoperable from both the system software and the game.  **Possible Values:**  - KICK  - UPDATE\_JOINABLE\_USER\_TYPE  - UPDATE\_INVITABLE\_USER\_TYPE  - PROMOTE\_TO\_LEADER  **Min Items:** 0 |
| » disableSystemUiMenu | **array[string]** | false | Of the privileges that the leader has by default, items whose operation from the system software UI is to be disabled  The specified items will become inoperable from the system software but will remain operable from the game as long as they are not specified in *exclusiveLeaderPrivileges*.  **Possible Values:**  - KICK  - UPDATE\_JOINABLE\_USER\_TYPE  - UPDATE\_INVITABLE\_USER\_TYPE  - PROMOTE\_TO\_LEADER  **Min Items:** 0 |
| » customData1 | **string(byte)** | false | Custom data  The maximum size is the size yielded from encoding 1024 bytes in Base64.  **Min Length:** 1 |
| » customData2 | **string(byte)** | false | Custom data  The maximum size is the size yielded from encoding 1024 bytes in Base64.  **Min Length:** 1 |
| » swapSupported | **boolean** | false | Flag indicating whether swapping from PlayStation™Network player to spectator, or from spectator to PlayStation™Network player, is supported  When true, it is supported. When this is the case, it is also possible to swap from the system software UI.  When false, it is not supported. |
