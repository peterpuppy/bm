# Error Codes

| Code (Decimal) | Code (Hex) | Message | Description |
| --- | --- | --- | --- |
| 2269185 | 22A001 | Bad request ('reason') | The request is invalid (the parameter section of the URL is invalid, a query parameter is invalid, a required parameter is missing, the body is too long, etc.) |
| 2269197 | 22A00D | Resource not found ('reason') | The requested resource could not be found (the specified user or title does not exist, the client ID of the access token is wrong, etc.) |
| 2269198 | 22A00E | Not permitted by access control | Access was denied (not the resource owner, the resource belongs to another title, because of privacy settings, etc.) |
| 2269315 | 22A083 | Forbidden | Access was denied (details unknown) |
| 2269316 | 22A084 | Not Found | Invalid URL (an unsupported API version was specified, etc.) |
| 2269321 | 22A089 | Conflict | The request conflicted with the current state of the target resource |
| 2269341 | 22A09D | Too Many Requests | Request rate limit was exceeded |
| 2269696 | 22A200 | Authentication required | An access token has not been specified |
| 2269697 | 22A201 | Invalid token | The specified access token has an invalid value or is corrupted |
| 2269702 | 22A206 | Insufficient scope | The scope is invalid (authorization has not been obtained, the wrong method of obtaining the access token was used, a parameter that cannot be used with the platform was specified, etc.) |
| 2269710 | 22A20E | Online ID required | The account must be upgraded |
| 2269836 | 22A28C | Expired token | Access token is expired |
| 2269837 | 22A28D | Np Environment not matched | Environment name is invalid |
| 2270080 | 22A380 | Internal server error | An unexpected error occurred on the server side |
| 2270083 | 22A383 | Service Unavailable | Service cannot be used (server is under maintenance, server is overloaded, service has ended, authentication/authorization server error, etc.) |
| 2270208 | 22A400 | Combination check failed | An invalid value was specified as part of the specified combination of parameters |
| 2270209 | 22A401 | Entity not defined | The specified player or team is not on the in-game roster |
| 2270210 | 22A402 | Entity not unique | A duplicated resource was specified |
| 2270211 | 22A403 | Operation not allowed | An operation that cannot be performed while the match has its current status was requested |
| 2270212 | 22A404 | Results already reported | Results for a match whose results were already reported were reported again |
| 2270213 | 22A405 | Service not registered | The service was accessed from an unregistered title |
| 2270214 | 22A406 | Team not supported | A combination of an activity that does not support teams and team information was specified |
| 2270215 | 22A407 | Player not belong to team | A player was specified for whom there is no record that he/she belonged to the target team |
| 2270216 | 22A408 | Activity not supported | An activity that does not support match creation was specified |
| 2270217 | 22A409 | Child activity status cannot reverted | The specified status is in the direction that reverts the status of the child activity (task/sub-task) |
| 2270218 | 22A40A | Child activity illegal status transition combination | Requested to update the status of a sub-task even though the parent task status isn't in a state that can update the sub-task status |
| 2270219 | 22A40B | Child activities not supported | Requested to update the status/availability of a child activity for a match of an activity that doesn't support child activities (task/sub-task) |
| 2270220 | 22A40C | Child activity status not updatable | Requested to update the status of a child activity when the match status isn't PLAYING |
| 2270221 | 22A40D | Zone id not changeable for Tournament match | Requested to update the zone ID of a tournament match |
| 2270222 | 22A40E | Expiration time not changeable for tournament match | Requested to update *expirationTime* of a tournament match |
| 2270223 | 22A40F | On hold status not supported for tournament match | Specified ONHOLD for the status of a tournament match |
| 2270224 | 22A410 | Player addition not allowed for tournament match | Requested to add player(s) to a tournament match |
