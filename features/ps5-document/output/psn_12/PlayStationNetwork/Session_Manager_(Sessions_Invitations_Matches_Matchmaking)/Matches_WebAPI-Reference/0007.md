# Joining and Leaving Matches

# joinMatch

Make players join a match

### Description

Players can be made to join a match with this request. With one request, a maximum of 100 players can be made to join. However, the combined number of currently participating players, previously participating players, and newly joining players cannot exceed 500. An error will occur for the request if 500 is exceeded.  
  
This request can also be used to move players between existing teams and to update the information of already joined in players.  
On the other hand, this request can't be used for updates in which the joining of some players and the leaving of others are handled at the same time and for adding new teams. Use [updateMatchDetail](0004.html) for such cases.

**Match Statuses Supported by This Request**

Match details can only be updated with this request if the match status meets one of the following conditions.

* The match status is *WAITING*
* The match status is *PLAYING*
* The match status is *ONHOLD*

Players can't be added to a match whose status is COMPLETED or CANCELLED.

A usage example for this request is provided below.

* **Case of Allowing a New Player to Join**

  This is the most typical use of this request.  
  Even for TEAM\_MATCH, it's possible to not specify teamId at first so that a player doesn't belong to a team and to assign on later, or to have a player who doesn't belong to a team.  
  Specifying a teamId that does not exist will result in an error. Use [updateMatchDetail](0004.html) if you would like to add a new team and to have a player join it.

  In-game Roster Before the Change

  ```
  {
    "inGameRoster": {
      "players": [
        {
          "playerId": "1",
          "playerType": "PSN_PLAYER",
          "playerName": "Tank 1",
          "accountId": "1234567891",
          "joinFlag": true
        }
      ],
      "teams": [
        {
          "teamId": "1",
          "teamName": "Team Fang",
          "members": [
            {
              "playerId": "1",
              "joinFlag": true
            }
          ]
        }
      ]
    }
  }
  ```

  Example Request

  ```
  POST {baseUrl}/v1/matches/{matchId}/players/actions/add
  {
    "players": [
      {
        "playerId": "2",
  ```

# leaveMatch

Make a player leave a match

### Description

Players can be made to leave a match with this request. The players who leave are not deleted from the match; their status will change to not joined in (*joinFlag*=false) and they will remain as players who once participated in the match.

**Match Statuses Supported by This Request**

Match details can only be updated with this request if the match status meets one of the following conditions.

* The match status is *WAITING*
* The match status is *PLAYING*
* The match status is *ONHOLD*

Players can't leave a match whose status is COMPLETED or CANCELLED.

**Reason for Leaving**

When a player leaves a match, the reason for leaving can be recorded. This record is aggregated on the PlayStation™Network for players whose *playerType* is PSN\_PLAYER and provided as statistical data.

**Example Request**

```
POST {baseUrl}/v1/matches/{matchId}/players/actions/remove
{
  "npServiceLabel": "0",
  "players": [
    {
      "playerId": "6",
      "reason": "QUIT"
    }
  ]
}
```
