# Match Results

# reportResults

Report the results of a match

### Description

You can report the final results of a match with this request.  
Given the final results reported with this request, all previously reported interim progress and additional stats will be overwritten and replaced.  
The match won't transition to the completed status when this request results in an error, and it will be displayed on the system software UI as being played.

**Match Statuses Supported by This Request**

Match results can only be reported with this request if the match status meets one of the following conditions.

* When the *status* of the match is PLAYING:  
  In this case, the match will terminate and its *status* will become COMPLETED. In addition, a *matchEndTimestamp* is recorded.
* When the *status* of the match is CANCELLED and neither interim progress nor the results have been reported yet:  
  In this case, the *status* of the match will remain CANCELLED without changing.

Executing this request in all other cases will result in an error.  
If the match's *status* is WAITING or ONHOLD, make it transition first to PLAYING using [updateMatchStatus](0005.html) before executing this request.

**Match Results**

The format in which results should be reported differs depending on the match's *competitionType*.

* *cooperativeResult* must be specified if *competitionType* is COOPERATIVE. For *cooperativeResult*, specifiy the final status of cooperative play (SUCCESS, FAILED, or UNFINISHED).
* *competitiveResult* must be specified if *competitionType* is COMPETITIVE. With *competitiveResult*, the format for results further differs depending on the *groupingType*.

  + *playerResults* must be specified if *groupingType* is NON\_TEAM\_MATCH. Specify player rankings in *playerResults*. If the match's *resultType* is SCORE, player scores must also be specified.
  + *teamResults* must be specified if *groupingType* is TEAM\_MATCH. Specify team rankings in *teamResults*. If the match's *resultType* is SCORE, team scores must also be specified. You can also specify each player's score (degree of contribution to the team) as an option.

Specify a value as follows for score when *scoreStatistics* is defined in the activity that corresponds to the match.

* Specify a positive integer value in milliseconds when *displayFormat* of *scoreStatistics* is time.
* Specify an integer value when *displayFormat* of *scoreStatistics* is numeric. Note that by specifying the number of digits after the decimal point in *decimalPlaces* of scoreStatistics, it is possible to display decimal scores on the system software.

**In-Game Rosters**

The players/teams to include in the results must be registered in advance with the in-game roster. Results of players/teams that have left the match can also be included.  
It's not necessary to include the results of all players/teams registered in the in-game roster; however, all interim progress results registered in the past of players/teams that aren't specified will be overwritten and deleted.  
Only the results of the players and teams reported in this request will be displayed on the system software screen for displaying match results.

**How to Specify Rankings**

Rankings are specified as follows, based on the type of competitive play.

* For a many vs many match: Specify each player or team's ranking as-is, as in 1, 2, 3... It is also possible to specify the same ranking to multiple players/teams as in 1, 1, 3, and so forth.
* For a one vs one match: Specify first place for the winning player/team and second place for the losing player/team in the rankings. In the case of a tie, give first place to both.

**Additional Stats**

The final results of additional stats can be reported by specifying *matchStatistics*.  
Additional stats reported in the past will all be overwritten. In other words, specific additional stats can be deleted by removing those stats from *playerStatistics*, *teamStatistics*, and *teamMemberStatistics*.  
An error won't occur even if you report stats that aren't defined in *additionalStatistics* of an activity linked to the match, but the undefined stats will not be displayed in the system software.  
The format of additional stats that can be reported differs depending on the match's *competitionType* and *groupingType*.

* Only *playerStatistics* can be specified if the match's *competitionType* is COOPERATIVE or if the match's *competitionType* is COMPETITIVE and *groupingType* is NON\_TEAM\_MATCH.
* Only *teamStatistics* can be specified if the match's *competitionType* is COMPETITIVE and *groupingType* is TEAM\_MATCH.

**Example Request**

* Example of "COOPERATIVE"

  ```
  POST {baseUrl}/v1/matches/{matchId}/results
  {
    "npServiceLabel": "0",
    "matchResults": {
      "version": "1",
      "cooperativeResult": "SUCCESS"
    }
  }
  ```
