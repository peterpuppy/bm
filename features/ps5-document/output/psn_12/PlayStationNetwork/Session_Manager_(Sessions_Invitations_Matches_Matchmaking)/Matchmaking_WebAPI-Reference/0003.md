# Matchmaking

# submitTicket

Create a matchmaking ticket

### Description

This request creates a matchmaking ticket and submits it to the server.

Multiple players with whom the requester would like to play can be specified in the ticket. An error will occur if the user who executed the request is not included among the players.

If other players cannot be added because of the conditions set forth in the ruleset, no error will occur if this API request is used to create a ticket. The ticket that is created will time out after the ticket timeout time has elapsed.

**Activate a Ruleset**

A ruleset specified in a ticket must already be defined and activated. An error will occur if the ruleset does not exist or is not ACTIVE. Activate rulesets using the **Matchmaking Tool**.

**Number of Tickets Per Ruleset**

Only one ticket per ruleset can be created at a time. If another ticket is created for a ruleset for which a ticket already exists, the old ticket will be automatically canceled.

**Default Values of Attributes**

It is not necessary to specify in a ticket all the values for the player attributes to be used as conditions for matchmaking or for ticket attributes. If a value is not specified, the default value set in the ruleset will be used.

**Specify Teams**

The intended teams to join can be specified for each player. However, one of the following conditions must be met:  
- A team is specified for every player  
- No team is specified for any player

If teams are not specified, the teams that players will join will be determined by the server. However, multiple players specified with a given ticket will always end up on the same team.

**Ticket Status**

When a ticket is created, its status will be QUEUED. When matchmaking begins on the server, this status will change to SEARCHING.

**Backfilling**

Empty slots in an existing Game Session can be filled with supplemental players. In such cases, specify the target Game Session ID and the information of the players already participating in the Game Session in the ticket.

# getTicket

Obtain a matchmaking ticket

### Description

This request obtains the on-server status of a matchmaking ticket that has been created. An error will occur if the ticket specified with ticketId does not exist.

```
  "status": "SEARCHING",
  "createdDateTime": "2018-10-04T12:34:56.000Z",
```

# cancelTicket

Delete a matchmaking ticket

### Description

This request deletes a matchmaking ticket that has already been created. An error will occur if the ticket specified with ticketId does not exist.

The conditions under which a ticket can be deleted are as follows:  
- It must be a ticket that the user who executes the request has joined  
- The status of the ticket must not be COMPLETED (offer created)

# getOffer

Obtain a matchmaking offer

### Description

This request obtains the data of a matchmaking offer.  
An error will occur if the ticket specified with offerId does not exist.

Location information (location) is included only in offers that satisfy one of the following conditions.  
- Offers containing tickets for backfilling purposes  
- Offers with the COMPLETED status

Cause of failure (cause) is included only in offers with the FAILED status.  
When an offer failure event has been received via Push notification, cause can be obtained by specifying view=with\_cause.

# listUserTickets

Obtain a list of matchmaking tickets that a user has joined

### Description

This request obtains a list of matchmaking tickets that the specified user has joined. A blank ticket list will be returned if no applicable tickets exist.

Only me, indicating the user linked to the access token, can be specified for accountId.

Tickets that meet the following conditions will be included in the list:  
- Tickets created within the past 24 hours  
- The most recently created ticket for each ruleset and platform

If the most recently created ticket has been deleted, it will not be included in the list.

**Example Response**

```
  {
    "tickets": [
      {
        "ticketId": "47664463-1040-4d51-bbcd-10179393896e",
        "status": "SEARCHING",
        "rulesetName": "Team_Deathmatch",
        "platform": "PS5"
      }
    ]
  }
```
