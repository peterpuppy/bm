# Push Notification

# Ticket Submission Event

Push event sent when a matchmaking ticket is submitted

### Description

This Push event is sent to all players included in a matchmaking ticket when the ticket is submitted.

### Datatype

```
psn:matchmaking:ticket:submitted
```

### NP Service Name Required for Receiving

sessionManager

### Order Guaranteed

No

### Event Content

### from: Information About the User Who Executed the Request

| Property | Type | Required | Description |
| --- | --- | --- | --- |
| accountId | **integer** | true | Account ID of the user who executed the request |
| onlineId | **string** | true | Online ID of the user who executed the request  **RegEx Pattern:** "^[a-zA-Z][a-zA-Z0-9\_-]{2,15}$" |
| platform | **string** | true | Platform of the user who executed the request  **Possible Values:**  - PS4  - PS5 |

### to: Recipient Information

| Property | Type | Required | Description |
| --- | --- | --- | --- |
| accountId | **integer** | true | Account ID of the recipient |
| onlineId | **string** | true | Online ID of the recipient  **RegEx Pattern:** "^[a-zA-Z][a-zA-Z0-9\_-]{2,15}$" |

### data: Data Sent During a Ticket Submission Event

```
{
  "rulesetName": "string",
  "ticketId": "string",
  "submitter": {
    "accountId": "string",
    "onlineId": "string",
    "platform": "PS4"
  }
}
```

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| » rulesetName | **string** | true | Ruleset name. Maximum of 64 characters.  **RegEx Pattern:** "^[a-zA-Z0-9][a-zA-Z0-9\-\.\_~]{0,63}$" |
| » ticketId | **string** | true | Ticket ID. The format is UUID Version 4.  **RegEx Pattern:** "^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$" |
| » submitter | **object** | true | Ticket submitter information |
| »» accountId | **string** | true | Account ID  **RegEx Pattern:** "^[1-9][0-9]{1,18}$" |
| »» onlineId | **string** | true | Online ID  **RegEx Pattern:** "^[a-zA-Z\_][a-zA-Z0-9\_-]{2,15}$" |
| »» platform | **string** | true | Platform  **Possible Values:**  - PS4  - PROSPERO |

### extended data: (Not Defined in This Push Event)

| »» onlineId | **string** | true | Online ID  **RegEx Pattern:** "^[a-zA-Z\_][a-zA-Z0-9\_-]{2,15}$" |
| »» platform | **string** | true | Platform  **Possible Values:**  - PS4  - PROSPERO |

# Offer Failure Event

Push event sent when a matchmaking offer fails

### Description

This Push event is sent to all players included in a matchmaking offer when the offer fails. The cause of the failure can be checked by issuing getOffer.

### Datatype

```
psn:matchmaking:offer:failed
```

### NP Service Name Required for Receiving

sessionManager

### Order Guaranteed

No

### from: (Not Defined in This Push Event)
