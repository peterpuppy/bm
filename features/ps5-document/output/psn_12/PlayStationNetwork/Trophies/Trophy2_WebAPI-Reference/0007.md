# Trophy Information

# getTrophyTitle

Obtains information on trophies unlocked by the specified user

### Description

Obtains the number of trophies and completion rate for trophies unlocked by a certain user for a certain title.

The target title is determined by the access token assigned to the request and the npServiceLabel query parameter. If npServiceLabel is not specified, information about the title with the npServiceLabel: 0 setting will be returned to the trophy2 service for the title resolved from the access token.

The target user is the user with the accountId specified for the path parameter.

If the account of accountId differs from the account resolved from the access token, the privacy settings will be used to determine whether or not the user of accountId is sharing their trophy records with the user resolved from the access token. If this information is not being shared, a response with the 2240526 error code will be returned.

However, if the request is called using an App Server (Client Credential) client ID, trophy records will be returned regardless of the privacy settings of the target user.

**Example Request**

```
GET trophyBaseUrl/v1/users/1234567890/apps/myApp/trophyTitle
Authorization: Bearer 13e3a918-e820-42b3-8f49-c84eac601679
```

**Example Response**

```
{
  "progress": 82,
  "earnedTrophies": {
    "bronze": 15,
    "silver": 10,
    "gold": 4,
    "platinum": 0
  },
  "lastUpdatedDateTime": "2020-11-11T01:23:45Z"
}
```

# listTrophyGroups

Obtains information about trophies unlocked by the specified user on a group basis

### Description

Obtains the number of trophies and completion rate for trophies unlocked by a certain user for each trophy group of a certain title.

The target title is determined by the access token assigned to the request and the npServiceLabel query parameter. If npServiceLabel is not specified, information about the title with the npServiceLabel: 0 setting will be returned to the trophy2 service for the title resolved from the access token.

The target user is the user with the accountId specified for the path parameter.

If the account of accountId differs from the account resolved from the access token, the privacy settings will be used to determine whether or not the user of accountId is sharing their trophy records with the user resolved from the access token. If this information is not being shared, a response with the 2240526 error code will be returned.

However, if the request is called using an App Server (Client Credential) client ID, trophy records will be returned regardless of the privacy settings of the target user.

The trophyGroups array included in the response will be sorted in ascending order of trophyGroupId, starting with the trophy group whose trophyGroupId is default.

```
GET trophyBaseUrl/v1/users/1234567890/apps/myApp/trophyGroups?offset=0&limit=3

```

# listTrophies

Obtains information about trophies unlocked by the specified user on a trophy basis

### Description

Obtains the number of trophies and completion rate for trophies unlocked by a certain user for each trophy group of a certain title.

The target title is determined by the access token assigned to the request and the npServiceLabel query parameter. If npServiceLabel is not specified, information about the title with the npServiceLabel: 0 setting will be returned to the trophy2 service for the title resolved from the access token.

The target user is the user with the accountId specified for the path parameter.
