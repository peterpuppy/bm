# Title Statistics

# getTrophyTitleStatistics

Obtains statistical information for a certain title

### Description

Obtains statistical information representing the number of users who have unlocked each trophy for a certain title.

The target title is determined by the access token assigned to the request and the npServiceLabel query parameter. If npServiceLabel is not specified, information about the title with the npServiceLabel: 0 setting will be returned to the trophy2 service for the title resolved from the access token.

The number of players who have unlocked each trophy will be included in the response for all trophies set for the target title. In short, trophies no one has unlocked will also be included in the response.

Do not show users the obtained trophy statistical information.

**Example Request**

```
GET trophyBaseUrl/v1/apps/myApp/statistics?npServiceName=trophy2&npServiceLabel=0
Authorization: Bearer 13e3a918-e820-42b3-8f49-c84eac601679
```

**Example Response**

```
{
  "player": 10000,
  "trophyStatistics": [
    {
      "trophyId": 1,
      "holder": 1234
    },
    {
      "trophyId": 2,
      "holder": 2345
    },
    {
      "trophyId": 3,
      "holder": 100
    },
    {
      "trophyId": 4,
      "holder": 50
    },
    {
      "trophyId": 5,
      "holder": 10
    }
  ],
  "totalItemCount": 5
}
```

### Request

```
GET /v1/apps/myApp/statistics
```

### Query Parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| npServiceLabel | **integer** | false | Specify the NP service label. Will be treated as 0 if not specified.  **Default Value:** 0 |
| offset | **integer** | false | Specify the starting position for elements included in the response. Will be treated as 0 if not specified.  **Min Value:** 0 |
| limit | **integer** | false | Specify the maximum number of array elements included in the response. All elements after "offset" will be returned if not specified.  **Min Value:** 1 |

### Status Code 200

### Response Header

| Header | Type | Format | Description |
| --- | --- | --- | --- |
| Cache-Control | string |  | Header storing the directive (instruction) to cache with both the request and the response |

### Response Body (Trophy Statistical Information)

**Content-Type:** application/json

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| » player | **integer** | true | Number of players (must not be shown to users)  **Min Value:** 0 |
| » trophyStatistics | **array[object]** | true | List of statistical information on individual trophies  **Min Items:** 0  **Max Items:** 1000 |
| »» trophyId | **integer** | true | Trophy ID [0 to 999] (must not be shown to users)  **Min Value:** 0  **Max Value:** 999 |
| »» holder | **integer** | true | Number of players who have unlocked this trophy (must not be shown to users)  **Min Value:** 0 |
| » totalItemCount | **integer** | true | Total number of elements, including elements not included in response  Refers to the total number of array elements if Offset/Limit was not applied |
| » nextOffset | **integer** | false | Value representing the starting position of the next page  This parameter does not exist on the final page |
| » previousOffset | **integer** | false | Value representing the ending position of the previous page  This parameter does not exist on the first page |
