# Error Codes

# Error Codes

| Code (Decimal) | Code (Hex) | Message | Description |
| --- | --- | --- | --- |
| 2240513 | 223001 | Bad request ('reason') | Request is invalid (the parameters section of the URL is invalid, a query parameter is invalid, a required query parameter is not present, the body is too long, etc.) |
| 2240644 | 223084 | Not Found | URL is invalid (an unsupported API version was specified, etc.) |
| 2241024 | 223200 | Authentication required | An access token has not been specified |
| 2241025 | 223201 | Invalid token | Specified access token is an invalid value or is corrupted |
| 2241030 | 223206 | Insufficient scope | Scope is invalid (authorization has not been obtained, the wrong access token obtainment method was used, a parameter that cannot be used on this platform was specified, etc.) |
| 2241408 | 223380 | Internal server error | An unforeseen error occurred on the server |
| 2241411 | 223383 | Service Unavailable | Service cannot be used (the server is under maintenance, the server is overloaded, the service is no longer being offered, an authentication or authorization server error occurred, etc.) |
| 2241537 | 223401 | Invalid trophy definition. | Invalid trophy definition |
| 2240525 | 22300D | Resource not found ('reason') | Requested resource could not be found (the specified user or title does not exist, the access token client ID is incorrect, etc.) |
| 2240526 | 22300E | Not permitted by access control | Access was denied (not the owner of the resource, the resource belongs to another title, due to privacy settings, etc.) |
| 2240669 | 22309D | Too Many Requests | Request rate limit has been exceeded |
| 2241038 | 22320E | Online ID required | Account must be upgraded |
| 2241164 | 22328C | Expired token | Access token is expired |
| 2241165 | 22328D | Np Environment not matched | Environment name is invalid |
