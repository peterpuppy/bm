# Leaderboards Web API Reference Summary

By using the Leaderboards Web API, you can record each player's game scores on a leaderboard and obtain rankings of the players. Rankings are calculated based on prior settings for each leaderboard, including score updating conditions and whether to display in ascending or descending order. The following types of rankings are included: Highest Ranking (with the player who scored first ahead if there is a tie in terms of points), Highest Ranking (with players tied if there is a tie in terms of points), and Highest Ranking Ever. Text information, called comments, and small amounts of binary data can be attached to scores. Additionally, you can attach large amounts of data, such as screenshots and gameplay videos.

**Call Rate Limits**

It is recommended that the call rates for the Leaderboards Web API are kept within the following ranges. Note that there is a possibility of rate limits changing without notice. Use the following information as a reference only.

| Request | Recommended Call Rate |
| --- | --- |
| getBoardDefinition | Within 30 times/15 minutes |
| getLargeDataByObjectId | Within 300 times/15 minutes |
| getRanking | Within 300 times/15 minutes |
| recordLargeData | Within 300 times/15 minutes |
| recordScore | Within 300 times/15 minutes |

### Base URLs

### Applications for PlayStation®5

With applications for PlayStation®5, there is no need to explicitly construct a base URL. Obtaining an appropriate base URL is automatically processed by calling a PlayStation™Network Web API using either the NpWebApi2 library or the NpCppWebApi library.

### Application Servers and Back Office Servers

The base URL to specify for application servers and back office servers depends on whether the client-side application uses the Sandbox network architecture or Legacy network architecture.  
(Refer to [Sandbox Network Architecture Guide](../../../SDK/latest/Sandbox_Network_Architecture-Guide/__document_toc.html) for details about Sandbox. Also refer to this technote regarding migration to Sandbox: <https://game.develop.playstation.net/technotes/view/740>.)

Specify the following base URL if the client-side application uses Sandbox:

* https://s2s.np.playstation.net/api/leaderboards

Specify the base URL of the applicable environment indicated below if the client-side application uses Legacy:

* Development environment (sp-int): https://s2s.sp-int.playstation.net/api/leaderboards
* Certification environment (prod-qa): https://s2s.prod-qa.playstation.net/api/leaderboards
* Production environment (RETAIL): https://s2s.np.playstation.net/api/leaderboards

For the purpose of maintaining backward compatibility, the above base URLs for Legacy can also be specified for application servers and back office servers that have migrated to Sandbox. For application servers and back office servers that serve traffic in both the Sandbox and Legacy network architectures, specify the base URL for Sandbox regarding Sandbox requests and specify the base URLs for Legacy regarding Legacy requests.
