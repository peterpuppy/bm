# Leaderboards Management Web API Reference Summary

The Leaderboards Management Web API is a management feature for back-office servers. It can be used to provide self-management of the Leaderboards service of PlayStation™Network. It provides features for recording multiple instances of score data simultaneously, uploading attachment data, deleting scores, and obtaining ranking snapshots in the development environment The feature for deleting scores and the feature for obtaining ranking snapshots can also be used in the production environment.

**Call Rate Limits**

It is recommended that the call rates for the Leaderboards Management Web API are kept within the following ranges. Note that there is a possibility of rate limits changing without notice. Use the following information as a reference only.

| Request | Recommended Call Rate |
| --- | --- |
| getSnapshotList | Within 50 times/15 minutes |
| deleteScores | Within 50 times/15 minutes |
| downloadSnapshot | Within 50 times/15 minutes |
| recordLargeData | Within 50 times/15 minutes |
| recordScores | Within 50 times/15 minutes |

### Base URLs

### Application Servers and Back Office Servers

The base URL to specify for application servers and back office servers depends on whether the client-side application uses the Sandbox network architecture or Legacy network architecture.  
(Refer to [Sandbox Network Architecture Guide](../../../SDK/latest/Sandbox_Network_Architecture-Guide/__document_toc.html) for details about Sandbox. Also refer to this technote regarding migration to Sandbox: <https://game.develop.playstation.net/technotes/view/740>.)

Specify the following base URL if the client-side application uses Sandbox:

* https://s2s.np.playstation.net/api/leaderboards

Specify the base URL of the applicable environment indicated below if the client-side application uses Legacy:

* Development environment (sp-int): https://s2s.sp-int.playstation.net/api/leaderboards
* Certification environment (prod-qa): https://s2s.prod-qa.playstation.net/api/leaderboards (to be supported later)
* Production environment (RETAIL): https://s2s.np.playstation.net/api/leaderboards

For the purpose of maintaining backward compatibility, the above base URLs for Legacy can also be specified for application servers and back office servers that have migrated to Sandbox. For application servers and back office servers that serve traffic in both the Sandbox and Legacy network architectures, specify the base URL for Sandbox regarding Sandbox requests and specify the base URLs for Legacy regarding Legacy requests.
