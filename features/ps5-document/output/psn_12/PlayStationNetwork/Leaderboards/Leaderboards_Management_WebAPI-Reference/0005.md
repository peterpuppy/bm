# Snapshot

# getSnapshotList

Obtain a list of ranking snapshots from the development environment and the production environment

### Description

Obtain a list of ranking snapshots created by setting schedules using the Leaderboards Tool from the target leaderboard. Up to 10 ranking snapshot results (file entries) can be obtained at once. This request can be used in both the development environment (DEV or sp-int) and the production environment (RETAIL).

A ranking snapshot is composed of file entries (*fileEntries*), and each entry's name (*fileName*), size (*fileSize*), and file identifier (*objectId*) can be checked. In addition to file entries, the snapshot format (*fileFormat*), set schedule name (*name*), scheduled output time (*scheduledDateTime*), output completion time (*completedDateTime*), and the snapshot identifier (*snapshotId*) can be checked.

The file entry name (*fileName*) includes the following elements connected in order by a hyphen (-).

* Fixed string "leaderboards"
* Set schedule name (value of *name*)
* Reserved character "0"
* NP Communication ID of the applicable title
* ID of the target leaderboard
* Scheduled output time (value of *scheduledDateTime*)
* Time that the rankings of the target leaderboard were calculated
* Total number of scores of the target leaderboard
* (Optional) fixed string "binary": added when the file only contains large-volume attachment data registered to the target leaderboard.
* (Optional) fixed string "missing\_binary": added when a part of the large-volume attachment data registered to the target leaderboard couldn't be correctly output to the file (due to server corruption, for example).

When it's not even possible to create a single ranking snapshot using the Leaderboards Tool for the target leaderboard, the HTTP status 200 will be returned and an empty list will be obtained for *snapshots* in the response body.

**Example Request**

```
GET leaderboardsBaseUrl/v1/apps/myApp/boards/0/snapshots
```

# downloadSnapshot

Obtain ranking snapshot file from the development environment and the production environment

### Description

Obtain a ranking snapshot file (zip) by specifying the snapshot identifier (*snapshotId*) and file identifier (*objectId*). This request can be used in both the development environment (DEV or sp-int) and the production environment (RETAIL). The snapshot identifier (*snapshotId*) and file identifier (*objectId*) are included in the list of ranking snapshot results obtained by [getSnapshotList](0004.html).

**Example Request**

```
GET leaderboardsBaseUrl/v1/apps/myApp/snapshots/0-ABCD00000_00-d58577b8-214e-4300-b85c-6e74702c3eec/fileEntries/f9ffa9a6-9d99-44ec-a4e0-c9aec368dd89
```

**Example Response**

```
Content-Type:application/octet-stream

XXXXXXXXXXXXXXXXX(Binary Data)
```
