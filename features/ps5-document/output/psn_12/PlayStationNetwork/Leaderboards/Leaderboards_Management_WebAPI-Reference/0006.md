# LargeData

# recordLargeData

Record attachment data from the development environment

### Description

Record large-volume attachment data. This request can only be used in the development environment (DEV or sp-int). Large-volume attachment data may only be recorded for scores that are ranked higher than the floor rank (*largeDataNumLimit*) set for the leaderboard that determines whether large-volume attachment data can be recorded. If you try to record large-volume attachment data for a score below the floor rank, HTTP status 400 will be returned.

**Example Request**

```
POST leaderboardsBaseUrl/v1/apps/myApp/boards/0/users/1234567890/largeData
Content-Length: 1024
X-Psn-Leaderboards-Player-Character-Id: 1

XXXXXXXXXXXXXXXXX (Binary Data)
```

**Example Response**

```
{
  "objectId": "046b6c7f-0b8a-43b9-b35d-6489e6daee91"
}
```

### Request

```
POST /v1/apps/myApp/boards/{boardId}/users/{accountId}/largeData
```
