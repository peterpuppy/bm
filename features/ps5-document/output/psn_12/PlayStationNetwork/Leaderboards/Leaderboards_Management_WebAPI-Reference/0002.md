# Score

# recordScores

Record scores from the development environment

### Description

Record multiple scores to a target leaderboard at once. This request can only be used in the development environment (DEV or sp-int).

A maximum of 1000 scores can be recorded at once. Optionally, a comment (*comment*) and/or small-volume attached data (*smallData*) can be recorded to each respective score.

The content of the comment will be checked on the server side; if any inappropriate words are included, they will be masked automatically. The official ranking of the score will not be calculated or made public until checking and masking of the comment is complete. Although the official ranking is calculated at the point when any comment has finished being checked and masked, that calculation will be based on the time when the score finished being recorded, not on the time when the comment is finished being checked and masked.

Input for small-volume attached data must be encoded in Base64.

If even a single invalid account ID is specified, none of the scores will be recorded, and HTTP status 400 will be returned. If a number of scores exceeding EntryLimit are loaded, HTTP status 400 will be returned. Also, any scores that you tried to add via that request will not be added.

**Example Request**

```
POST leaderboardsBaseUrl/v1/apps/myApp/boards/0/scores

{
  "entries": [
    {
      "accountId": "1234567890",
      "score": "100",
      "comment": "This is a test sample.",
      "smallData": "c3BlY2lhbCB0aWNrZXQgd2FzIHVzZWQ="
    },
    {
      "accountId": "2345678901",
      "score": "95"
    }
}
```

HTTP status 204 will be returned when the request example above succeeds. There will be no response body.

# deleteScores

Delete scores from the development environment and the production environment

### Description

Delete multiple scores from a target leaderboard at once. This request can be used in both the development environment (DEV or sp-int) and the production environment (RETAIL).

Individually specify players (*players*=1234567890) to delete their registered scores. A maximum of 32 players can be specified at once. If the deletion of even a single score fails, there will be an error. If this happens, the deletion of other scores may have succeeded. No error will occur if an attempt is made to delete the score(s) of a deleted or nonexistent player. Therefore, it is not a problem to re-run the request without changing the targets for deletion if an error is returned.

It's also possible to specify all players (*players*=all) to delete the registered scores of all players. Be careful when using this feature as deleting the scores of alll players can't be undone.

**Example Request**

```
DELETE leaderboardsBaseUrl/v1/apps/myApp/boards/0/scores?players=1234567890,2345678901:1
```

HTTP status 204 will be returned when the request example above succeeds. There will be no response body.

| --- | --- | --- | --- |
| npServiceLabel | **integer(int32)** | false | NP service label  **Min Value:** 0  **Default Value:** 0 |
| players | **string** | true | Query parameter for specifying a target player.  Use a colon (:) to indicate a single player, and enter in the form {account ID}:{player character ID}. If the player character ID is 0, the colon and the player character ID can be omitted. Multiple players can be specified by separating with commas.  It's also possible to specify all players using all.  **RegEx Pattern:** "(\d+:\d+|\d+)(,\d+:\d+|,\d+)\*|all" |
