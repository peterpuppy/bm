# Sandbox Management

# listSystemSandboxes

Get a list of all sandboxes

### Description

Returns the sandboxId and sandboxName for all known sandboxes.

**Example Request**

```
curl -X GET "https://s2s.np.playstation.net/api/sandboxManagement/v1/sandboxes/system"
  -H "accept: application/json"
```

**Example Response**

```
{
  "systemSandboxes": [
    {
      "sandboxId": "q1w2e3r4",
      "sandboxName": "DEV"
    },
    {
      "sandboxId": "a1s2d3f4",
      "sandboxName": "CERT"
    }
  ]
}
```

**Content-Type:** application/json

| »» sandboxName | **string** | true | The name of the sandbox. |
