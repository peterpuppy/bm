# Social Platform

The Social Platform on PlayStation® enables players to make their gaming experience more fun and fulfilling on PlayStation® by connecting with:

* Other players
* Games and gaming content
* The gaming community

# User Profiles

A user profile provides the most basic element of a player's gamer identity. It allows players to express themselves through the lens of games, and helps players to get connected to other players.

With the integration of the data platform, players are able to understand the gamer identity more than ever, leading to more engagement with a game and players of a game.

## User Profile Web API

The User Profile Web API can obtain user profiles, friend lists, block lists, and set and obtain presence information. It also provides an interface for receiving push events. For details, refer to the following documents:

* [User Profile Overview](../../../WebAPI/latest/User_Profile-Overview/__document_toc.html)

# User Safety

User safety is the foundation of creating safe, non-toxic, and fun environments to play games. When used, user safety tools can make users aware that there are blocked players in the same game match, and partially disable player's communication.

## Profanity Filter Web API

The Profanity Filter Web API can verify that text input by a user does not contain inappropriate language. The service can also censor profanity with "\*" characters. For details, refer to the following documents:

* [Profanity Filter Web API Overview](../../../WebAPI/latest/Profanity_Filter_WebAPI-Overview/__document_toc.html)
* [Profanity Filter Web API Reference](../../../WebAPI/latest/Profanity_Filter_WebAPI-Reference/__document_toc.html)

The Communication Restriction Status Web API tells an application whether or not the social features should be allowed for a particular user, identified by an account ID. For details, refer to the following documents:

# Shared Media

Shared Media features enable users to capture, edit, and share gaming experience with other players and the gaming community. Shared Media keeps players engaged with games while they are not playing, and motivates players to go back to games.

Data Platform further enables players to engage with game media without the risk of seeing
spoilers.

## Share Library

The Share library provides APIs that enable sharing from game applications. It also provides functions for game applications to take screenshots or video clips. For details, refer to the following documents:
