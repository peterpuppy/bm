# Overview of PlayStation™Network

The PlayStation™Network provides network services for PlayStation® platforms. It supports PlayStation®3, PSP™ (PlayStation®Portable), PlayStation®Vita, PlayStation®4, and PlayStation®5 game consoles.

It also provides specialized application servers, an authentication service for websites,
and various APIs.

The following types of software provide PlayStation™Network services to users:

* System software applications on the console.
* PlayStation™Network website and each region's portal sites.
* PlayStation®App on smart phones/tablets.

Also, the following types of software use the libraries included in the PlayStation® SDK and PlayStation™Network Web APIs to access PlayStation™Network services:

* Applications on the console.
* Specialized application servers and websites.

Note: This document focuses on PlayStation®5-specific PlayStation™Network. Refer to the [PlayStation™Network Overview](__document_toc.html) in the appropriate DevNet for other platforms such as PlayStation®4 and PlayStation®Vita.
