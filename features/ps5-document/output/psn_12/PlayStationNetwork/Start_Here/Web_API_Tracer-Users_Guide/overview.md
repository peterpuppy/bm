# Web API Tracer User's Guide Overview

This chapter provides an overview of the Web API Tracer service.

This guide is for those that need to test, debug, and verify Web API implementations. This includes:

* Game developers - engineers implementing PlayStation™Network Web API.
* Production and QA staff that are testing games.

The Web API Tracer allows a developer to see detailed information about PlayStation™Network Web API calls including the header and body of the request and response in the development environment. This feature assists with debugging, testing, and validating Web API implementations on game clients or game servers.

A debug setting on the Console (PlayStation®4/PlayStation®5) is provided to enable or disable the API logging of Web API calls which will appear in the Web API Tracer. A debug setting is also provided to attach an optional tag to Web API calls to assist in detailed debugging efforts.

## Supported Browsers

The Web API Tracer currently supports Chrome and Firefox.
