# Introduction

This document describes how to request PlayStation™Network services. The PlayStation™Network is a shared network platform for PlayStation®5, PlayStation®4, PlayStation®3, PlayStation®Vita, and PSP™ (PlayStation®Portable).

Although PlayStation™Network services are common to multiple PlayStation® platforms, you must use the PlayStation®5 Developer Network (DevNet) site to request PlayStation®5 PlayStation™Network services. Currently, the PlayStation®5 DevNet site is independent from other SIE DevNet sites, as Title Management on DevNet.
