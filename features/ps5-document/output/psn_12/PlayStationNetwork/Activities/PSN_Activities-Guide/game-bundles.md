# Configuring Activities for Game Bundles

This topic provides guidance on configuring activities for games that are packaged together in bundles.

If your game is a compilation or bundle that includes multiple games in a single package, configure activities for each game following the most applicable guidance for each game’s content.

If each game has its own campaign or story mode, you may be required to configure at least one progress type activity for each campaign. See [TRC R5301 Requirements for Games with Campaigns](trc-requirements-r5301.html "This topic provides information on the TRC requirements you must follow if your game has a campaign or story mode.") for more information.

If each game has its own competitive multiplayer modes, you may be required to configure at least one competitive multiplayer activity for mode, in each game. See [TRC R5302 Requirements for Competitive Multiplayer Games](trc-requirements-r5302.html "This topic provides information on the TRC requirements you must follow if your game has competitive multiplayer modes.") for more information.
