# Web API Overview

This chapter provides an overview of the Active Activities Web API.

# Purpose and Characteristics

The Active Activities Web API allows you to obtain information about activities that a user is playing.

It can be used within a game to obtain and display the activities in which friends who are playing the same game are engaged.

The Active Activities Web API can be used from an application server, as well as from an application for PlayStation®5. To use the Web API from an application server, you must have a client ID issued. To have this done, contact SIE through the "Post new issue" page (<https://p.siedev.net/support/newissue>) on Private Support.

# Main Features

The features provided by the Web Activities Web API are provided below:

* Feature for obtaining information about activities that a user is playing
